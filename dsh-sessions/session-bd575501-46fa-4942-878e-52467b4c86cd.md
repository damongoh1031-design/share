## 一句话结论

八成 galgame 属于 **Kirikiri(KRKR) / ONScripter / Artemis / Tyrano** 这几类，在 Pixel 9 上**不用装 Windows 模拟器**，装一个多引擎播放器就能直接跑；只有 **YU-RIS / CatSystem2 / 部分自研引擎** 才需要 Winlator 或串流。

**最短路径：** 装 [Tyranor-Next](https://github.com/Weiss-UltimateSavior/Tyranor-Next)（开源、GPL-2.0、仍在高频更新）→ 用 SAF 选游戏目录 → 它会自动识别引擎并启动。

## 三条主线方案

### A. 安卓原生播放器（覆盖 80% 的 galgame，首选）

**① Tyranor-Next** — 目前最省心的一个
- 原生支持 Kirikiri/KRKR、ONScripter、Artemis、Siglus、RealLive、AVG32、UK2、FVP、System3.x/4、Tyrano Web
- Ren'Py 和 RPG Maker XP/VX/VX Ace 走**外置 APK 模块**（在引擎页会提示下载安装）
- 要求：Android 8.0+、**arm64-v8a**（Pixel 9 完全符合）；游戏目录必须在本地存储并通过系统文件选择器授权
- 注意：所有 release 都带 `beta-` 前缀，属于活跃开发中，遇到怪异表现先更新版本

**② ika** — Tyranor 的现代化外壳重写
- 关键价值：把老 Tyranor 里**在 Android 15/16 上会崩的原生引擎换掉了**（krkrsdl3 替代 cocos2d-x 版 Kirikiroid2，ONScripter-EN 替代 ONScripter-Yuri）
- 引擎跑在独立进程，崩溃不会带走整个 App
- 首次启动大游戏会先复制到内部存储（有进度条），中断的复制不会被误认为完整

**③ 原版 Tyranor v2.3.4**（包名 `com.akira.tyranoemu`）
- 免费无广告，但内置的 Kirikiroid2 / ONScripter 库在新系统上大概率初始化失败——**除非你用老系统，否则优先前两个**

**④ Kirikiroid2**（老牌 KRKR 专用）
- 已多年不更新，targetSdk 太老，**在 Pixel 9 上直接点 APK 会装不上**（见下方 Pixel 9 坑点第 1 条），只作为最后备选

### B. JoiPlay（Ren'Py / RPG Maker 专用）

Ren'Py 引擎的 galgame 很多（欧美系、部分日系同人），JoiPlay + 对应插件是这条路的标准答案。装完主程序后要在设置里装 **Ren'Py Plugin**（注意选对 Ren'Py 版本：老游戏 Python2 / 新游戏 Python3），RPG Maker 则需要 **RPG Maker Plugin**。

### C. Winlator（真正的 Windows 程序，如 YU-RIS / CatSystem2）

能跑，但 Pixel 9 是 **Mali-G715**，情况特殊：
- Winlator 常用的 **Turnip 驱动是 Adreno 专用，Mali 用不了**
- 只能走 **VirGL（兼容性好、慢）/ Vortek（实验性）/ bannerlator**
- 实测参考：同代 Mali 设备跑 3A 大概 20–27fps；galgame 是 2D 轻量，实际可玩，但**启动折腾度高**（要配容器、DXVK 版本、Box64 参数）
- 版本选择：Winlator 9.0+ / Cmod 分支对中文和 Steam 支持更好

如果只是为了玩一两部 YU-RIS 作品，**性价比不如直接串流**。

### D. 串流（兼容性 100% 的保底方案）

PC 上原版跑，手机当屏幕：**Moonlight + Sunshine**（局域网、延迟最低、免费）、**Steam Link**、**Parsec**（外网）。galgame 是静态画面为主，串流体验几乎无损，还能顺便解决存档、汉化补丁、mod 一致性问题。

## Pixel 9 专属的 5 个坑

**1. Android 16/17 的 targetSdk 安装门槛（最常见）**
系统会直接拒绝安装 `targetSdkVersion < 24` 的 APK，报错：
```
INSTALL_FAILED_DEPRECATED_SDK_VERSION: App package must target at least SDK version 24, but found 22
```
唯一解法是走 ADB（手机开「开发者选项 → USB 调试」）：
```bash
adb install --bypass-low-target-sdk-block "路径\老播放器.apk"
```
没有第二条绕过途径——改 targetSdk 重打包属于另一回事。

**2. 别开 16 KB page size**
Pixel 9 的开发者选项里有 `Boot with 16 KB page size` 开关（默认关闭）。**保持关闭**：老播放器里的 cocos2d-x / SDL2 原生库是按 4KB 页对齐编译的，开了会直接崩。

**3. Mali GPU → Winlator 别指望 Turnip**
见上面 C 方案。Mali 用户遇到「画面黑屏/花屏」时，第一反应应该是换渲染后端，而不是怀疑游戏本身。

**4. 没有 microSD，128GB 起步**
一部 galgame 通常 2–10GB，`xp3` 封包的尤其大。方案：USB-C OTG U 盘（SAF 能直接授权读取）+ 玩完就删/归档到电脑。

**5. 6.3 寸 20:9 长屏**
4:3 / 16:9 的老游戏会出黑边。在播放器显示设置里选「保持原始比例 / 居中」，**不要拉伸**，否则立绘会变形。另外 120Hz 屏上部分老 KRKR 游戏动画速度会异常，把刷新率锁 60Hz 通常就好了。

## 装机实操（10 分钟）

1. 设置 → 关于手机 → 连点「版本号」7 次 → 开启开发者选项 → 打开 **USB 调试**
2. 下载 Tyranor-Next 的 APK，`adb install` 或直接传到手机用文件管理器安装（首次会要求「允许安装未知来源应用」，按 App 逐个授权）
3. 把游戏整个文件夹拷到 `内部存储\Games\游戏名\`（**不要放在 `Android/data/` 下**，SAF 读不到）
4. 打开 App → 添加游戏目录 → 用系统文件选择器授权该目录
5. 如果引擎提示需要「所有文件访问权限」，去设置里给（部分引擎要读真实路径）
6. 启动，进游戏设置调窗口比例 / 字体 / 语音
