## 3. 关键点：Google 官方 API 支持按电话搜索吗？

**支持，Google 当前 Text Search（New）文档明确说明了电话号码查询。**

官方建议：
- 包含国家码；
- 国家码后加空格；
- 将 `regionCode` 设为对应国家；
- 支持 E.164 电话格式。

所以你的样本适合尝试：

```text
查询号码：+60 167238684
地区：MY
```

来源：[Google 官方 Text Search（New）文档](https://developers.google.com/maps/documentation/places/web-service/text-search)。

但这里有一个选型细节：**底层 Google API 支持某参数，不代表每个 MCP 都暴露了它。** 例如 cablate 当前工具文档中的 `maps_search_places` 有 `query`，但列出的参数里没有 `regionCode`。因此它可以尝试把完整国际号码作为文本查询；若需要严格设置马来西亚地区参数，应进一步检查实现或补一个薄封装。

可靠的处理链应当是：

```text
输入完整号码
→ 统一为国际格式
→ 搜索 Google Places
→ 获取候选商家详情
→ 对比详情中的完整电话号码
→ 一致才输出“号码 + 商家名称 + 来源链接”
```

不能因为搜索返回了第一家店，就认定它与目标号码匹配。
