## 一句话结论

中国报雪隆版无 sitemap、无 REST API、分类页无分页，唯一全量通道是站内搜索的 Elasticsearch 代理 `search.chinapress.com.my/full-search-kl`。用关键词分片扫出 **73,700+ 篇文章**、去重保留 **22,088 篇**（含电话的 5,447 篇全部命中），提取 **9,010 条「姓名/电话」记录**（3,999 条带姓名、4,938 个唯一号码）。

## 站点侦察结果

| 探测项 | 结果 | 结论 |
|---|---|---|
| 平台 | WordPress（`/wp-content/`、`?p=` 短链有效） | 但做了深度定制 |
| `/wp-json/wp/v2/posts` | 404 | REST API 已关闭 |
| `/sitemap_index.xml`、`/wp-sitemap.xml` | 404（robots.txt 里却写了） | sitemap 不可用 |
| `/category/{slug}/` | 200，但只有 20 篇、**无分页** | 分类页不可翻页 |
| `/category/社会/`（简体） | 404 | 分类 slug 是**繁体**（`社會`），URL 编码为 `%e7%a4%be%e6%9c%83` |
| `/page/2/`、`?paged=2` | 404 / 无效 | 无标准分页 |
| `/?s=关键词` | 200，但结果由 JS 异步加载 | 只是壳 |
| **`POST https://search.chinapress.com.my/full-search-kl`** | **200，返回全文 JSON** | **唯一可用全量通道** |

## 搜索 API 用法（核心）

```bash
curl -s -X POST "https://search.chinapress.com.my/full-search-kl" \
  -H "Content-Type: application/json; charset=utf-8" \
  -H "Origin: https://kl.chinapress.com.my" \
  -d '{"id":"a1","params":{"query_string":"联络","query_from":0}}'
```

| 参数 | 说明 |
|---|---|
| `query_string` | 搜索词，单字/多字均可（`的`、`电话`、`WhatsApp`） |
| `query_from` | 偏移量，**步长固定 10**，上限 **9990**（ES `max_result_window=10000`），超过返回 400 |
| `size` / `per_page` | 传了也无效，每页恒为 10 条 |
| 返回字段 | `post_id / post_date / post_title / post_content(全文纯文本) / tax(分类数组) / post_img_ori` |

多站点后缀：`-kl`（雪隆）、`-jhr`（柔佛）、`-png`（槟城）、`-perak`（霹雳）、`-n9`（森美兰）、`-ec`（东海岸）、`-mk`（马六甲）。同一个搜索服务覆盖全马各版。

文章页可用 `https://kl.chinapress.com.my/?p={post_id}` 直达（实测标题一致，无需拼 slug）。

## 抓取策略与实证

单查询最多 10,000 条，必须用关键词分片并集。两轮实测：

| 轮次 | 关键词类型 | 词数 | 请求数 | 新看到文章 | 其中含电话 |
|---|---|---|---|---|---|
| 1 | 联系方式词（电话/联络/洽询/报名/WhatsApp…） | 27 | 4,116 | 22,023 | 5,382 |
| 2 | 高频单字（的/一/是/在/年/马/华…） | 20 | 20,000 | 41,551 | **62** |
| 3 | 活动通告词（晚宴/义卖/法会/联办/主办…） | 28 | 2,853 | 10,120 | **3** |

**关键实证**：第 2、3 轮共新扫 51,671 篇非联系方式命中的文章，只新增 65 篇含电话（0.13%）。说明第 1 轮已覆盖全站含电话文章的 ~99%，继续扩词的边际收益趋零 —— 这是判断"是否已遍历完"的量化依据，不要靠感觉停。

吞吐：24 并发下约 **56 请求/秒**，20,000 请求 8 分钟。第一轮 4,116 请求 73 秒。

## 姓名提取：新闻文本比寺院通告难一个量级

寺院通告的格式是 `洽询：张三 012-3456789`，标签清晰。新闻正文是自然语言，姓名直接嵌在句子里，踩过的坑：

1. **动词粘连**。`可联络张秀珍012-202 5996` 会取到 `络张秀珍`；`总策划蔡玟旭` 会取到 `划蔡玟旭`。解法：对电话前窗口反复做**尾部动词剥离**（`TAIL_STRIP`），再匹配姓名。
2. **勋衔前缀**。`拿督郭智強` 取到 `督郭智強`、`拿督斯里黄家泉` 取到 5 字超长。`TITLE_PREFIX` 必须显式吃掉 `拿督/拿督斯里/丹斯里/准拿督/太平局绅`。
3. **繁体混排**。同一站点简繁并存，`聯絡邱于真` 的 `絡` 不在简体剥离表里就会污染。剥离表必须简繁双写。
4. **职务后缀被截断**。`许达卿副校长` 取到 `许达卿副`。`ROLE` 要收 `副校长/警监/警曹长/警长`，且长词排在短词前面（正则交替顺序敏感）。
5. **机构名冒充人名**。`关怀之家`、`八打灵`、`社警熱線`、`明幼兒園`。`BAD_SUFFIX` 要覆盖 `人士/事件/情报/行动室/太平间/入场/工作天/细则`。
6. **马来/英文名**。`Fatin Shuhaila binti Mohd Thowila 女士`、`Rohaizal Azali`、`Steve Ng` 需要独立正则，且要排除 `TEL/CALL/WHATSAPP/PBB` 这类全大写缩写。
7. **`inherited` 是双刃剑**。同句内 `杨金意（019-263 9639）、叶来庆（013-335 2397）` 各自有姓名；但 `可联络 03-xxx、012-yyy` 无姓名时继承上一人是对的。565 条 inherited 误差率高于 adjacent。

## 号码过滤

```python
# 区号 1 位(03/04/05/06/07/09) 与 2 位(082/088) 都要吃
r"(?<![\d/.\-])(?:\+?60[\s\-]?|0)(?:1[0-9]|[2-9])(?:[\s\-]?\d{3,4}){1,2}[\s\-]?\d{3,4}(?![\d])"
```
排除：8 位且以 19xx/20xx 结尾（`03042011` 是日期）、不以 `0`/`+60` 开头（银行账号 `3107034621`）。

## 坑与反直觉

- **`?p={id}` 比构造 slug 可靠**。中国报 URL 是 `/YYYYMMDD/中文slug/`，slug 无法反推，但 `?p=` 短链实测直达。
- **分类 slug 是繁体**。用简体"社会"拼 `/category/社会/` 一定 404，正确是 `%e7%a4%be%e6%9c%83`（社會）。这个坑浪费了一轮排查。
- **robots.txt 里的 sitemap 是死链**。别信 robots，直接试。
- **搜索结果是相关度排序，不是时间倒序**。`的` 的第一条可能是 4 月的文章。所以深翻 `query_from` 能拿到不同文章，但**不能**用"翻到某日期就停"来判断结束。
- **ES total 封顶 10000**。`total=10000` 只代表"超过一万"，不代表正好一万。判断覆盖度只能靠"新词是否还能带来新的含电话文章"。

## 未核实项

- 全站真实文章总量未知（ES total 封顶 + 无法遍历），估计 20–40 万篇；未扫描部分按 0.13% 命中率推算，可能遗漏 200–400 篇含电话文章。
- 姓名准确率 76–80% 基于 25 条抽样，未做全量人工校验。
- `inherited`（565 条）与马来名截断（如 `依沙警长` 应为 `XX依沙`）误差偏高，建议使用时优先采信 `name_source=adjacent`。
- 未处理图片型通告（正文纯图片）与 PDF 附件中的电话。
