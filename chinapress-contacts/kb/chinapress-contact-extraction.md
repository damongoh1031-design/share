## 一句话结论

中国报各地方版无 sitemap、无 REST API、分类页无分页，唯一全量通道是站内搜索的 Elasticsearch 代理 `search.chinapress.com.my/full-search-{site}`。同一套方法已跑通三个分站：雪隆版（kl）**9,010 条**、马六甲版（mk）**5,061 条**、霹雳版（perak）**9,253 条**，合计 **23,324 条**记录。

## 搜索 API（核心）

```bash
curl -s -X POST "https://search.chinapress.com.my/full-search-mk" \
  -H "Content-Type: application/json; charset=utf-8" \
  -H "Origin: https://mk.chinapress.com.my" \
  -d '{"id":"a1","params":{"query_string":"联络","query_from":0}}'
```

| 参数 | 说明 |
|---|---|
| `query_string` | 单字/多字均可（`的`、`电话`、`WhatsApp`） |
| `query_from` | 偏移，步长固定 **10**，上限 **9990**（ES `max_result_window=10000`），超限 400 |
| `size` / `per_page` | 传了无效，每页恒 10 条 |
| 返回 | `post_id / post_date / post_title / post_content(全文纯文本) / tax(分类数组)` |

文章页用 `https://{site}.chinapress.com.my/?p={post_id}` 直达（实测标题一致，无需拼中文 slug）。

## 姓名提取：新闻文本比寺院通告难一个量级

寺院通告格式是 `洽询：张三 012-3456789`，标签清晰。新闻正文姓名嵌在自然语言里，踩过的坑：

1. **动词粘连**。`可联络张秀珍012-202 5996` → `络张秀珍`；`总策划蔡玟旭` → `划蔡玟旭`。解法：对电话前窗口反复做**尾部动词剥离**（`TAIL_STRIP`），再匹配姓名。
2. **勋衔/职务前缀**。`拿督郭智強` → `督郭智強`、`董事长陈宝全` → `长陈宝全`、`活动执行官王儒吉` → `官王儒吉`、`财政許慶華` → `政許慶華`。`TITLE_PREFIX` 必须显式吃掉这些词，且**长词排在短词前面**（正则交替顺序敏感）。
3. **简繁混排**。同站简繁并存，`聯絡邱于真` 的 `絡` 不在简体剥离表里就污染。剥离表必须简繁双写（`聯繫|聯絡|連絡|連繫|致電|撥打|查詢|詢問|詳情|報名|電話|號碼`）。
4. **职务后缀被截断**。`许达卿副校长` → `许达卿副`。`ROLE` 要收 `副校长/警监/警曹长/警长/总领队`，且长词优先。
5. **机构/名词冒充人名**。`关怀之家`、`八打灵`、`社警熱線`、`峇章慈善`、`酸种欧包`、`销售团队`。`BAD_SUFFIX` 覆盖 `单位/团队/人士/事件/情报/行动室/太平间/商家/业者`。
6. **马来/英文名**。`Fatin Shuhaila binti Mohd Thowila 女士`、`Rohaizal Azali`、`Steve Ng` 需独立正则；同时排除 `TEL/CALL/WHATSAPP/HOTLINE/MALAYSIA/SDN/BHD` 等全大写缩写。
7. **`inherited` 是双刃剑**。同句 `杨金意（019-263 9639）、叶来庆（013-335 2397）` 各有姓名；但 `可联络 03-xxx、012-yyy` 无姓名时继承上一人是对的。误差率高于 `adjacent`，使用时优先采信 `adjacent`。

## 号码过滤

```python
# 区号 1 位(03/04/05/06/07/09) 与 2 位(082/088) 都要吃
r"(?<![\d/.\-])(?:\+?60[\s\-]?|0)(?:1[0-9]|[2-9])(?:[\s\-]?\d{3,4}){1,2}[\s\-]?\d{3,4}(?![\d])"
```
排除：8 位且以 19xx/20xx 结尾（`03042011` 是日期）、不以 `0`/`+60` 开头（银行账号 `3107034621`）。

## 坑与反直觉

- **`?p={id}` 比构造 slug 可靠**。URL 是 `/YYYYMMDD/中文slug/`，slug 无法反推，但 `?p=` 短链实测直达。
- **分类 slug 是繁体**。用简体拼 `/category/社会/` 一定 404，正确是 `%e7%a4%be%e6%9c%83`（社會）。这个坑浪费一轮排查。
- **robots.txt 里的 sitemap 是死链**。别信 robots，直接试。
- **搜索结果是相关度排序，不是时间倒序**。`的` 的第一条可能是 4 月的文章。深翻 `query_from` 能拿到不同文章，但**不能**用"翻到某日期就停"判断结束。
- **ES total 封顶 10000**。`total=10000` 只代表"超过一万"。判断覆盖只能靠"新词是否还能带来新的含电话文章"。
- **同一套脚本可直接复用到其余 5 个分站**，只需改 `SITE` 环境变量，无需重新侦察。

## 未核实项

- 全站真实文章总量未知（ES total 封顶 + 无法遍历）。kl 估计 20–40 万篇，按 0.13% 命中率推算可能遗漏 200–400 篇含电话文章；mk 已实测饱和（第三轮 0 命中）。
- 姓名准确率基于 20–25 条抽样，非全量人工校验。
- 马来名截断（`依沙警长` 实际是 `XX依沙`）与 `inherited` 类误差偏高。
- 未处理图片型通告与 PDF 附件中的电话。
