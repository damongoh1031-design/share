〇结论速览

六个最重要的判断，每一条后面都有展开。

① 星数最高的"MCP 仓库"其实不是 MCP Server

microsoft/markitdown 有 190,122★——但它是"任意文档 → Markdown"的转换库本体，MCP 服务只是随包捆绑。同理 microsoft/playwright（97,679★）是浏览器库，MCP 在 playwright-mcp（38,117★）。引用星数时必须区分"库本体"与"MCP 服务"——这是本次调研发现的最普遍误引。

② 官方参考服务器只剩 7 个还活着

modelcontextprotocol/servers（91,238★）里，GitHub / Google Drive / Google Maps / Slack / Puppeteer / Postgres / SQLite / Brave Search / Sentry / GitLab / EverArt 全部已归档，移入 servers-archived。现在活跃的只有：Filesystem · Memory · Sequential Thinking · Time · Fetch · Git · Everything。

③ 有 5 个"热门"仓库已归档（archived）

browserbase/mcp-server-browserbase（3,401★）· supermemoryai/apple-mcp（3,123★）· semgrep/mcp（687★）· e2b-dev/mcp-server（393★）· oxylabs/oxylabs-mcp（104★）。按老教程装这些会装到一个死项目。

④ 高星但已停更的陷阱

BrowserMCP/mcp 有 7,182★ 却停更 18 个月；飞书官方 larksuite/lark-openapi-mcp 停更 14 个月；JetBrains/mcp-jetbrains 停更 9 个月；jerhadf/linear-mcp-server 停更 17 个月（Linear 官方明确说不要用）。

⑤ 办公场景的胜负手不是星数，而是"厂商官方 + 远程 OAuth"

办公类 MCP 的 star 普遍只有几千（Notion 4,666★），但价值在免本地安装、OAuth 授权、企业级权限。Notion、Atlassian、Slack、Linear、Google、Microsoft、飞书、钉钉走的都是 Streamable HTTP + OAuth 托管路线。不要用 star 数给办公类排序。

⑥ 星数只是"关注度"，不是"使用量"

真正反映使用量的 npm/PyPI 下载量本次未取得。本报告的"最常用"判断建立在 star 数 + 官方目录收录 + 厂商文档推荐 三个代理指标上。另注意：各家 MCP 目录站的服务器总数互相矛盾（官方 Registry 约 3 万 / Glama 约 6.6 万 / mcptoplist 称 13.5 万），不要引用任何单一总数。

办公场景的三个结构性特征

① 官方走托管，社区走本地
厂商官方 MCP（Notion / Atlassian / Slack / Linear / Google / Microsoft / 飞书 / 钉钉）普遍是 https://mcp.xxx.com/mcp + OAuth；社区方案是本地 stdio + API Key。选型优先官方。
② 中国与海外是两套体系
飞书 open.feishu.cn（国内）与 open.larksuite.com（国际）区域锁定、应用互不通用；钉钉需企业内建应用 + 组织管理员；腾讯文档 / 语雀 / 石墨 / WPS 无强势官方 MCP
③ 办公类 star 低 ≠ 不重要
编程类 Context7 有 63,010★，办公类 Notion 只有 4,666★。办公 MCP 的价值在厂商信任 + 免安装，不在社区热度
本场景最需要注意的一条

飞书官方 MCP 已停更 14 个月（2025-08-14）——官方仓库却处于停滞状态。中国办公场景目前缺乏活跃的一手方案。

选型三条铁律

① 先看最后提交时间
至少 6 个高星项目停更超 9 个月，5 个已归档。停更的再热门也不用。
② 优先厂商一手维护
官方服务器在协议跟进、安全修复、认证规范上都有保障；社区服务器容易在 MCP 规范升级后失修。
③ 能用远程 OAuth 就别用长效 PAT
远程 Streamable HTTP + OAuth 是 2026 主流形态，权限可回收、可审计；长效 PAT 一旦泄露后果严重。

明确标注的不确定项

  • 各家 MCP 目录站的服务器总数互相矛盾（官方 Registry 约 3 万 / Glama 约 6.6 万 / mcptoplist 称 13.5 万），且约 80% 的服务器只出现在一个目录里——不要引用任何单一总数。
  • 免费额度与定价（Brave 2,000/月、Tavily 1,000 credits、Firecrawl 500 credits 等）来自文档与二手来源，未在官方定价页逐一核实，会变动。
  • 办公类的中国生态：腾讯文档 / 语雀 / 石墨 / WPS / 企业微信 / 百度地图 / 富途 / moomoo 的官方 MCP 状态未能一手核实。
  • 已核实的仓库改名：getsentry/sentry-mcp → getsentry/toolkit；ppl-ai/modelcontextprotocol → perplexityai/modelcontextprotocol；dhravya/apple-mcp → supermemoryai/apple-mcp；apify/actors-mcp-server → apify/apify-mcp-server；googleapis/genai-toolbox → googleapis/mcp-toolbox。
  • 部分子代理报告中的 star 数为估算值（如曾出现"Chrome DevTools MCP 44.6K"的第三方博客说法），本报告已全部替换为 API 实测值 53,500。
