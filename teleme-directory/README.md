## 方法要点

- 列表入口 `GET /doctors/search?page=N`，12 条/页，共 142 页；`sitemap.xml` 停在 2017 年只含 102 条，不可作为全集依据。
- 列表页无电话，须二次请求 `GET /doctors/profile/{slug}`。
- 必须带浏览器 UA，默认 curl UA 返回 403（Cloudflare）。
- 分页排序不稳定，约 2% 重复/漏项，用 set 合并去重。

## 已知局限

- 该目录已不维护：费率全为 `RM 0.00`，营业时间与诊所官网不符（例：Dr Samuel Wong 显示 18:00–03:00，官网为 10:00–19:00）。**时间字段不可信，使用前须向诊所核实。**
- 64 条号码为占位/截断脏值（`+60`、`60`、`none`、`NA`），已剔除，故明细行数为 1,636 而非 1,652。
- 号码均为诊所/药房对外公开的接诊电话，非个人私人号码。
- Teleme 服务条款禁止「下载、转载、向公众传播站内任何材料」，并禁止绕过平台联系医生做远程问诊。**请勿用于群发营销或二次分发。**
