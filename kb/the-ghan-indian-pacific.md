## TL;DR

The Ghan 与 Indian Pacific 同属 **Journey Beyond Rail**，是澳大利亚两大跨大陆观光列车：前者**纵贯南北**（Adelaide↔Darwin，2,979km，3–4 天，约 3–11 月运营），后者**横贯东西**（Sydney↔Perth，4,352km，4–5 天，全年每周三发车）。两车**共用同一套六档舱型**（Gold Single / Gold Twin / Gold Premium Twin / Platinum / Aurora Suite / Australis Suite），Gold Twin 60kg、Platinum 90kg、套房无限行李额。票价 A$2,290 起，顶配 Australis Suite 达 A$22,490/人（每人单程）。**2026 年 4 月**同步上线由 **Woods Bagot** 设计的 Aurora / Australis Suite。三种票价类型（Advance / Everyday / Flexible）同舱价差可达 **40%**。

## 一、两车核心区别（一张表记住）

| 维度 | The Ghan | Indian Pacific |
|---|---|---|
| 走向 | 南北纵贯 | 东西横贯 |
| 起终点 | Adelaide ↔ Darwin | Sydney ↔ Perth |
| 距离 | 2,979 km | **4,352 km** |
| 时长 | 3天2晚（Legendary）/ 4天3晚（Expedition）/ 2天1晚（短线） | 4天3晚（Syd→Perth）/ 5天4晚（Perth→Syd） |
| 首航 | **1929**（Afghan Express，纪念阿富汗驼队向导） | **1970**（标准轨距 1917 打通） |
| 运营期 | **约 3–11 月**（季节性） | **全年**，每周三 |
| 发车时刻 | Legendary Sun/Wed 12:15；Expedition Wed 10:00 / Sat 09:00 | Sydney 14:15 |
| 红土/内陆招牌 | Nitmiluk 峡谷、Marla/Manguri 星空、Coober Pedy 地下城 | 蓝山、Broken Hill、Rawlinna 星空晚宴、Nullarbor |
| 起步价 | A$2,290（Gold Single Advance） | A$2,990（Syd→Perth Gold Twin Advance） |
| 顶配价 | A$20,390（Expedition 5-8月 Australis） | **A$22,490**（Perth→Syd 旺季 Australis） |

> **选择逻辑**：想看**红土中心 + 热带北端**（含 Katherine 峡谷、爱丽斯泉）→ The Ghan；想看**横贯大陆 + 世界最长直线铁路 + 蓝山**→ Indian Pacific。**12 月–2 月出行只能选 Indian Pacific**（The Ghan 冬季停运）。

## 二、舱型体系（两车通用，六档）

| 舱型 | 相对面积 | 行李额 | 专属权益 |
|---|---|---|---|
| Gold Single | 最紧凑 | — | Queen Adelaide 餐车 + Outback Explorer 休息车 |
| **Gold Twin**（最热销） | 基准 | 60kg（2×30kg） | 同上；上下铺白天转为三座沙发 |
| Gold Premium Twin（2024 新增） | 略大 | — | 同上 + 升级权益 |
| Platinum（Twin/Double） | **≈ Gold Twin × 2** | 90kg（3×30kg） | **Platinum Club** 专属餐车/休息室 + 起止 60km 接送 + 双程观景窗 + 房内欧陆早餐 |
| **Aurora Suite**（2026.4 新） | **≈ Platinum × 2** | **无限额**（每件 ≤32kg） | 管家、开箱整理、枕头菜单、房内酒吧、房内用餐、私人司机、Champagne Bollinger La Grande Année |
| **Australis Suite**（2026.4 新） | **≈ Platinum × 3** | **无限额**（每件 ≤32kg） | 同 Aurora；另含独立卧室 + 双台盆卫浴 + 书写桌 |

**关键事实**：
- 官方**从不公布具体㎡**，只给相对倍数。第三方给出的具体数字**不可信**。
- Aurora / Australis 由**澳大利亚事务所 Woods Bagot** 设计，2026 年 4 月启用，南澳 Journey Beyond 车辆工场手工打造。
- 套房权益最抢眼的是**私人司机接送（车站 60km 内）**与**无限行李额**。

## 三、票价体系（决定实际花费的关键）

| 票价类型 | 规则 | 价格 |
|---|---|---|
| **Advance Purchase** | 提前 **≥6 个月**预订 + **全款付清**，每班限量 | **最低** |
| **Everyday** | 订金 Gold A$1,000/人、Platinum A$1,500/人（2026 起）；出发前 2 个月付清 | 中 |
| **Flexible** | 下单时全款 | **最高** |

- 同舱位 Advance vs Flexible 价差可达 **30–40%**。
- **儿童**：4–15 岁成人票 **8 折**；0–3 岁**免费**（用现有床位）。
- 所有价格为 **A$/人 单程**。

## 六、坑与反直觉

| 坑 | 说明 |
|---|---|
| **面积数字造假** | 官网只说「≈ Platinum × 3」，第三方站点却给出具体㎡ —— 那些数字是自己编的 |
| **The Ghan 冬季无班** | 约 3–11 月运营，**12 月–2 月可能完全无班次**；不要以为「全年都有」 |
| **同程反方向更贵** | Perth→Sydney 是 5 天（比 Syd→Perth 的 4 天多一晚），价格高约 15–20% |
| **套装价不含 Uluru 飞行** | Uluru 观光飞行为**加购升级**，不是一价全含 |
| **Advance 需全款 + 6 个月** | 不是「早鸟折扣」，是**硬性付款条件**；临时改期会损失 |
| **着装 ≠ Rovos** | 这里是 **smart casual**，不是正装；但也不是「随便穿」 |
| **Off Train Experiences 会变** | 官方明确声明可能调整，别把某个具体活动当成必然 |
| **Gold Twin 才是性价比** | 首次体验建议 Gold Twin；Platinum 起价约为其 2 倍 |
| **Rawlinna 星空晚宴季节性** | 通常 9–5 月，冬季改篝火酒会 |
