# 把 Google Drive 当知识库

## TL;DR

**先分清你要的是哪一种"知识库"**：个人档只能拿到 **实时连接**（浏览/搜索/`@提及`，无索引）；真正的"索引式知识库"是 **管理员管理的同步（admin-managed sync）**，仅 Business/Enterprise 工作区 + 管理员可开，且**个人授权版同步已停止提供**。
个人档想当知识库用，靠的是 **Drive 侧的文件组织 + 项目（Projects）+ 项目指令 + 资料库** 四件套拼出来。

---

## 1. 三种机制，别混为一谈

| 机制 | 本质 | 谁能用 | 有索引吗 | 写入 |
|---|---|---|---|---|
| **实时应用连接** | ChatGPT 按需去 Drive 取文件 | 个人付费档（网页版） | ❌ 每次实时取 | 可（受授权限制） |
| **项目 Projects** | 持久工作区 + 持久记忆 + 挂载文件 | 全档（文件数按档位） | ❌ 靠上下文 | 项目内产出 |
| **管理员管理的同步** | 管理员连接 Drive 并为**已核准内容建索引** | Business / Enterprise 工作区（需管理员 + 支持的数据驻留地区） | ✅ 预建索引 | 索引只读检索 |
| ~~个人授权版同步~~ | — | **已停止提供**，旧连接无法恢复或升级 | — | — |

> 官方原文要点：*"由个人授权的应用程序同步功能已不再提供。现有的个人同步连接无法恢复或升级。"* 也就是说，**个人账号拿不到 Drive 的索引式知识库**。

---

## 2. 管理员管理的同步（真正的"知识库"）

| 项 | 说明 |
|---|---|
| 支持来源 | **Google Drive、SharePoint、Microsoft Teams**（并非所有应用/工作区都支持建索引） |
| 设置者 | 必须由**工作区拥有者或有权限的管理员**设置，成员无法自行开启 |
| 路径 | 管理控制台 → 选工作区 → **插件** → 打开含目标应用的插件 → **索引搜索** → 按供应商流程连接 → 批准 Google Workspace 管理员权限 → 选纳入的**来源范围** → 等初次索引完成 |
| 数据驻留地区（Google Drive） | 澳洲、加拿大、欧洲（EEA+瑞士）、印度、日本、新加坡、南韩、阿联酋、英国、美国 |
| 权限模型 | **不会**让成员看到他们在 Drive 里本来就看不到的内容；管理员选的来源范围可再收窄 |
| 时效 | 初次索引需时间；来源更新后，新内容与权限变更也需时间才生效 |
| 即时操作 | 即使索引可用，**实时应用操作仍可能需另外连接供应商账号** |

**典型问法**："总结我们团队的 XX 计划""找出关于我们最新发布的文件"。

---

## 3. 个人档怎么做（四件套拼装）

### 第 1 层：Drive 侧——先把它变成"可检索的语料"

知识库好不好用，**八成取决于 Drive 怎么摆**，不取决于 ChatGPT。

| 规则 | 做法 |
|---|---|
| 单一事实来源 | 同一内容只保留一份；旧版移入 `_archive/`，不要留 v1/v2 并存 |
| 命名规范 | 前缀编号 + 稳定 slug：`012-第三章-雪夜.md`；避免"最终版_真最终版" |
| 章节级分块 | 一文件一章（或一节），**不要一个 30 万字的巨型文件** |
| 索引文件 | 根目录放 `00-INDEX.md`（目录 + 每文件一句话摘要）+ `01-术语表.md`（人名/地名/称谓）+ `02-世界观设定.md` |
| 格式 | 用 `.md` / `.docx`；**别用 Google Docs 原生格式**（智能引号、自动更正会污染标点） |
| 目录 | `设定/` `正文/` `素材/` `_archive/`；**初期不支持「共享云端硬盘」**，必须放「我的云端硬盘」或直接分享给自己 |

### 第 2 层：常驻设定——放进"指令"，别每次重贴

- **项目指令（Project instructions）**：世界观、人物设定、文风要求、禁用词、称谓表。项目内指令**优先于**全局自定义指令。
- **全局自定义指令**：跨项目的通用习惯（语言、口吻、输出格式偏好）。
- **记忆（Memory）**：跨对话的长期事实。**记忆的来源包含"资料库中的文件"和"来自已连接应用（如 Gmail）的内容"** —— 也就是说挂了 Drive 之后，记忆可以直接引用其中的内容。建议项目设为**仅项目访问自身记忆**，避免上下文污染导致规则冲突。详见 [chatgpt-memory-and-scheduled-messaging.md](chatgpt-memory-and-scheduled-messaging.md)。

### 第 3 层：资料库 / 项目文件——把 Drive 挂进来

- `设置 > 插件 > 连接 Google Drive`（需授予浏览权限）→ 资料库中即可**浏览/搜索** Drive 文件与文件夹。
- 用法：输入框 `@文件名` 把文件加入对话；或**选中文件夹**要求综合处理。
- 项目（Projects）内可挂常驻文件；免费档每项目文件数有限（社区数据：约 5 个，档位越高越多）。
- 资料库容量：Free 500 MB｜Go 4 GB｜Plus·Business 20 GB｜Pro 100 GB。
- 必要公开动作（管理员侧）：`fetch / get_file_metadata / list_folder / recent_documents / search`。

### 第 4 层：调用——Work / Chat / Deep Research

- **Work**：跨文件综合、一致性检查、批量格式统一、导出成品。
- **Chat**：`@Drive 文件` 也能用，适合逐章打磨（不占周额度）。
- **Deep Research**：可把已连接应用作为**信息来源**（只读/抓取）。
- **公司知识（company knowledge）**：仅包含具备搜索/抓取功能的应用，**带交互式 UI 的应用不支持**。

## 4. 四层架构

```
Google Drive（原文，单一事实来源）
  ├─ 00-INDEX.md / 01-术语表 / 02-世界观
  ├─ 正文/012-第三章.md ...
  └─ _archive/
        │  实时连接（无索引）｜企业：管理员建索引
        ▼
ChatGPT 资料库 Library（浏览 / 搜索 / @提及 / 选文件夹）
        │
        ▼
常驻层：项目指令 + 全局自定义指令 + 记忆（世界观 / 文风 / 称谓）
        │
        ▼
执行层：Chat（逐章打磨）｜Work（跨章 / 成品）｜Deep Research（只读调研）
```

## 可复用操作

**A. 接 Drive**
1. `设置 > 插件 > Google Drive > 连接`，授予浏览权限
2. 资料库中确认能搜到目标文件夹 → 说明权限齐了
3. 提示词用 `@文件名` 或"处理 @文件夹 里的全部文件"

**B. 建项目知识库**
1. 新建项目，命名如《书名》创作
2. 项目指令写入：世界观 / 人物 / 文风 / 称谓 / 禁用词 / 输出格式
3. 设置 → 记忆 → 选**仅项目访问自身记忆**
4. 挂载 `00-INDEX.md`、`01-术语表.md` 等常驻文件
5. 之后每次直接提任务，不必重贴设定

**C. 当知识库查询（个人档）**
```
用 @00-INDEX.md 判断该读哪些文件，再用 @对应文件 回答：
<问题>
只依据这些文件作答，找不到就直说找不到，不要推测。
```

**D. 企业档开启索引（管理员）**
管理控制台 → 工作区 → 插件 → 打开含 Google Drive 的插件 → **索引搜索 → 设置** → 批准 Google Workspace 管理员权限 → 选来源范围 → 等索引完成 → 让成员验证只能检索到自己有权的文件

## 坑与反直觉

1. **个人授权版同步已停止提供** —— 个人账号不要指望"Drive 自动建索引"，只能实时取。
2. **管理员同步 ≠ 成员能自行开启**，且部分工作区/地区根本不支持建索引，别假设一定有。
3. **索引不是即时的**：初次索引要等；来源更新、权限变更也要等。
4. **项目内创建的定时任务无法访问项目上传的文件**（官方明确）。
5. **「共享云端硬盘」（Shared Drives）初期不支持**，只支持「我的云端硬盘」+ 直接分享给你的项目。
6. **Drive 文件是链接不是副本**：ChatGPT 里改的就是 Drive 上那个文件，且**无法从 ChatGPT 删除 Drive 文件**。
7. **个人档训练开关**：Free/Plus/Go/Pro 开启「为所有人改进模型」时，通过应用访问的信息可能被用于训练；Business/Enterprise/Edu 默认不训练。未发表作品注意。
8. **索引只解决"找得到"，不解决"答得准"**：没有索引文件（术语表/世界观）时，跨文件答案很容易前后矛盾。
9. **交互式 UI 应用不能进公司知识**。
10. **不要用"整理我整个 Drive"这类指令** —— 范围失控，且写操作会直接落到原文件。

## 未核实 / 存疑

1. **Projects 各档位的文件数上限**：仅见社区数据（免费约 5 个），未找到官方页面确认当前数值。
2. **Drive 文件是否占用资料库容量**：官方容量表针对"上传和创建的文件"；Drive 为链接，推测不占，**未见官方明确说明**。
3. **移动端 Drive 支持时间**：官方表述为"稍后推出"，无日期。
4. **管理员同步对 Google Drive 的索引粒度/刷新延迟**：官方只说"需要一些时间"，无具体 SLA。
5. **个人档能否通过 API/第三方自建 RAG 替代索引**：可行方向，但已超出 ChatGPT 原生能力范围，未在本次核实。
