一句话结论

openSUSE Tumbleweed 是六者中"官方仓库能力"最完整的之一——sched-ext 调度器、Gamemode/MangoHud/Steam 全在官方仓库，Btrfs+snapper 快照更是默认自带。它比 CachyOS 差的只有编译层（v2 vs v3/v4 + LTO/PGO/BOLT）和 BORE 内核。

4. 差异"没突出"的原因

  1. openSUSE 已是 v2 基线：相对 CachyOS 的编译层劣势小于 Arch/Fedora（它们是 v1）。v2→v3 的收益本就比 v1→v3 小。
  2. 内核版本接近：Tumbleweed 滚动更新，内核与 Arch/CachyOS 基本同步——"内核红利"共享。
  3. 瓶颈不在 CPU（Amdahl 定律）：4K 游戏 GPU 受限、桌面受 IO/网络限制。
  4. openSUSE 官方仓库的"配置能力"很强：sched-ext、Gamemode、MangoHud、Btrfs 快照都能官方拿到——它不需要靠"重编译"来拉性能。
  5. snapper/Btrfs 的额外开销很小：定时快照与 CoW 的运行时开销通常 <1%，且换来完整回滚能力。
  6. AppArmor 开销通常很小（<1–2%）。
  7. 测量噪声同量级：run-to-run 方差常有 1–3%。
  8. 部分"优化"是取舍：max_performance、激进电源档是用功耗/续航换响应。

前提界定："第三方仓库"指 Packman / OBS（非 Factory）/ NVIDIA 官方仓库等外部仓库。

5.3 直接回答你的问题

openSUSE Tumbleweed 在"没有第三方仓库"的前提下，能复现 CachyOS 约 13 项优化——而且其中三项含金量很高：

  1. sched-ext 可插拔调度器（zypper install scx，官方仓库）
  2. Gamemode / MangoHud / Steam / Lutris（全在官方仓库）
  3. Btrfs + snapper 快照回滚（默认自带，与 GRUB 集成）

唯一无法复现的仍是那两项：全仓库 v3/v4 重编译 + LTO/PGO/BOLT，以及 BORE / BMQ 内核（需 OBS/第三方）。
