# CC CRM · 界面规范（UI Kit）

> 依据：公司 logo（等距 CC 标记，橙→黄渐变 + 黑色投影）与参考稿（Telco CRM）的浅色简洁版。
> 实现：`prototype/crm-prototype.html` 顶部 `:root` 变量 + 组件规则；改一处全站生效。

## 1. 色彩

### 主色（来自 logo）

| 名称 | 值 | 用途 |
|---|---|---|
| `--brand` | `#e8622a` | 主按钮、导航选中、关键数字、强调描边 |
| `--brand-soft` | `#fff3ec` | 选中态背景、主色浅底 |
| `--brand2` | `#f5c518` | 仅用于 logo 渐变与极少数强调，不做大面积 |

> 主色只出现在「用户现在在这里」和「主要动作」两处。一屏里橙色面积不超过 10%，否则失去指示作用。

### 中性色

| 名称 | 值 | 用途 |
|---|---|---|
| `--bg` | `#f2f4f7` | 页面底色 |

| `--panel2` | `#f7f9fc` | 输入框、次级按钮、表头 |
| `--line` | `#e8ecf2` | 分隔线、卡片描边 |
| `--line2` | `#d9e0ea` | 输入框描边 |

## 2. 字体与字号

- 字体：`"Microsoft YaHei", "PingFang SC", system-ui`；数字用 `tabular-nums` 对齐。
- 基准 14px，全站字号写 `calc(Npx * var(--fs))`，四档系数 `0.92 / 1 / 1.12 / 1.26`。

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 页面标题（面包屑） | 13 | 500 | 顶栏左侧 |
| 卡片标题 | 13.5 | 500 | `card-hd h3` |
| KPI 数值 | 27 | 600 | 看板四宫格 |
| 正文 / 表格 | 13 | 400 | 列表、表单 |
| 辅助说明 | 11.5 | 400 | `help` / `tiny dim` |
| 徽章 | 11.5 | 400 | 状态标签 |

---

## 3. 间距与圆角

- 间距基数 **4px**：4 / 8 / 12 / 16 / 20 / 24。
- 页面内容内边距 `18px 20px 90px`（底部留出批量操作条）。
- 圆角：卡片 10、按钮 8、输入框 8、徽章 5、头像 50%、logo 容器 9。
- 卡片阴影只用一层极淡的 `0 1px 2px rgba(16,32,56,.04)`，靠描边而不是阴影分层。

## 4. 组件规则

### 按钮

| 类型 | 样式 | 用法 |
|---|---|---|
| 主按钮 | 橙底白字 | 一屏最多 1 个（保存、提交、登录） |
| 次按钮 | 白底 + `--line2` 描边 | 常规操作 |
| 文字按钮 | 无底无边，主色文字 | 表格行内「详情 / 写跟进」 |
| 危险按钮 | 红字浅底 | 删除、禁用、退回 |

高度：默认 32，小号 26，顶栏 30。**同一行里不要出现两个主按钮。**

### 导航

- 侧栏 212px，白底，图标 16px 线性 + 13.5px 文字。
- 选中态：`--brand-soft` 底 + 左侧 3px 橙色条 + 橙色文字。
- 按角色生成，无权限的项**不出现在菜单里**（不是 `display:none`）。

### 卡片

- 白底 + 1px `--line` + 10px 圆角。
- 头部：标题左、操作右，底部 1px 分隔线。
- 一屏内卡片不超过 6 个；超过就说明该合并。

### 表格

- 表头 `--th` 底、11.5px、`--tx2`。
- 行高 44，分隔线 1px `--cellline`，悬停 `--hover`。
- 状态一律用徽章，不用纯色文字；一列只放一种语义。

### 徽章

- 浅底 + 同色文字 + 同色 20% 描边。
- 一屏徽章种类不超过 5 种颜色；超过说明状态模型太碎。

### 弹窗 / 抽屉

- 遮罩 `rgba(17,24,39,.55)`，不用模糊（低端机与无头环境会丢底色）。
- 弹窗最大 540px，圆角 12，头 46 高，底右对齐按钮。
- 抽屉从右侧 560px，用于「当天安排 / 任务详情」这类不需要全屏的内容。

## 5. Logo 使用

| 场景 | 尺寸 | 处理 |
|---|---|---|
| 侧栏品牌 | 34×34 | 白底圆角 9，内边距 2，`object-fit: contain` |
| 登录页 | 46×46 | 同上，圆角 11 |
| 浏览器图标 | 128×128 | 同一张 PNG，运行时注入 `<link rel=icon>` |

- 因为原图带白色背景，**所有容器都必须是白色或浅色**；不要放在深色块上直接压。
- 深色主题下同样用白色圆角容器承载，看起来像应用图标，不违和。
- 单文件原型把 logo 以 base64 内联（128px / 23KB），不产生任何外部请求。

## 6. 交互约定

| 行为 | 规则 |
|---|---|
| 全局搜索 | 顶栏搜索框，`/` 聚焦，回车跳到客户列表并带上关键词 |
| 呼叫台快捷键 | `1–5` 选结果、`Enter` 保存并下一位、`Ctrl+→` 跳过 |
| 关闭 | `Esc` 关弹窗 → 关抽屉（逐层） |
| 反馈 | 每个写操作结束都有 toast：成功绿色、警告黄色、失败红色，2.6 秒消失 |
| 危险操作 | 必须二次确认或填写原因（标记无效、退回公海、禁用账号） |

---

## 7. 不要做的事

- 不要给每个数字配一种颜色。颜色是语义，不是装饰。
- 不要在表格行里放超过 2 个按钮；第三个动作收进「更多」或详情页。
- 不要用纯色文字表示状态（红字「逾期」），用徽章，保证色盲用户也能靠文字区分。
- 不要在浅色主题里用纯黑（#000）文字，用 `#1f2d3d`，对比度足够且不刺眼。
- 不要让主色承担「信息」职责，信息用蓝色，主色只表示「当前 / 主操作」。
