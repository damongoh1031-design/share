## 已知缺口（重要）

1. **62 个分类首页永久缺失** —— 这些分类首页被源站 B 型坏缓存锁死（响应截断、缺 `</html>`），
   2026-10-12 决策跳过，其子页从未入队。这部分数据不可回收。
2. **1218 页源站缺陷** —— 集中在 automotive / apparel-textiles / agricultural / amusement 深层分页，
   表现为 HTTP 200 + 0 字节或 `Content-Length: 32768` 截断，恢复周期约 24 小时，由 25 小时延期阶梯复检。
3. **覆盖率口径** —— `5.80%` 是「已完成 / 已入队」；`5.58%` 是剔除源站缺陷后的真实覆盖率。两者都远未到 100%。

## 复现方式

断点数据库、分片（`.parts`）与任务状态文件体积较大且持续变动，未纳入本仓库。
如需续跑，在工作目录执行：

```bash
python prioritize.py --apply      # 未索引分类首页提到队首
python defer_defects.py --apply   # 缺陷页分层延期（+30min / +6h / +25h）
python supervise.py --status      # 只读状态报告
python export_deliverable.py --quiet  # 刷新本目录 CSV
```
