# 吉隆坡谷中城 500 米内天桥可步行公寓全档案

## 可复用操作

### EdgeProp 项目页 ID 的批量拿法（本次最关键的方法）

EdgeProp 没有 condo sitemap，但**一个「outlook」sitemap 里含全部项目页 URL**：

```bash
curl -sL -A "<UA>" "https://www.edgeprop.my/sitemap.xml"            # 索引
curl -sL -A "<UA>" "https://www.edgeprop.my/sitemaps/sitemap-outlook-1.xml" -o o.xml
grep -o '<loc>[^<]*</loc>' o.xml | sed 's/<[^>]*>//g' | grep -i 'vogue\|viia\|gardens'
# → /condo/vogue-suites-1-kl-eco-city-45653 等，id 直接可读
```
拿到 URL 后 **用 WebFetch 抓**（curl 会被 Cloudflare 拦）。项目页给：48 个月中位 psf + IQR、中位总价、隐含租金回报、历史最高/最低（带面积与月份）、要价季度趋势、按面积段的租金回报表、**1 公里邻近项目对比表**。

### brickz 近 8 个月成交（补 EdgeProp 的窗口偏差）

```bash
curl -sL -A "Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7) ..." \
  -H "Referer: https://www.brickz.my/" \
  "https://www.brickz.my/transactions/residential/kuala-lumpur/<area>/<project-slug>/" -o b.html
```

### 用「邻近项目表」做完整性反查

EdgeProp 项目页的 `Price Comparison with Nearby Properties` 表列出 1 km 内最多 50 个项目，**带距离、psf 三分位、总价三分位、回报**。这是发现「门户漏掉的供给」最快的入口——本次据此发现 7 个项目，其中 4 个在 500 m 带内。

## 坑与反直觉

1. **EdgeProp「48 个月中位」会把新盘高估 40–60%。** 对 2021 年后交付的项目，这个数字包含 2022–23 投机高点。Vogue One：48m 中位 1,622 vs 近 8 月成交 1,016。**中介报「中位 psf」时，用的是两年前的价格。**
2. **MyRumahBaru 的中位 psf 是分区回退值。** Vogue One / Vogue Two / ViiA 三栋全显示 `RM1,282.43` / 中位总价 `RM1M` / 样本 `4 笔`。三栋不同楼不可能同价同笔数 → 全部弃用。
3. **「历史最高 psf」是判断「被炒过没有」的最快指标。** 3,036–4,157 psf 的项目（Vogue One / Southpoint）说明曾被投机资金推到远超租金支撑的位置；1,285–1,384（Setia Sky Seputeh）说明没被炒。前者跌起来没有底。
4. **户数会被门户写错一半。** Vogue Suites Two：mudah 344 vs EdgeProp 739。判别法：找**两个独立登记源**（EdgeProp 另给出开发商 Setia Promenade Sdn Bhd，可交叉验证）。
5. **同名不同项目会污染整个清单。** brickz 的「Boulevard, Mid Valley City」其实是 Southpoint Residences——判据是**中位 psf 与中位总价完全一致**（1,447 / 2,221,706）。
6. **「零成交」比「低价」更重要。** The Gardens Residences：151 户、永久地契、商场正上方，近 48 个月零申报成交。这不是「稀缺」，是「没有市场」——买入即锁定。
7. **步行距离 ≠ 直线距离，且新盘的桥更长。** KL Eco City 三栋直线 370–450 m，实际天桥步程 550–750 m（跨河 + 穿两个商场）。Northpoint 直线 313 m，连廊约 300–350 m。
8. **大户型 psf 低于小户型 25–35%。** Northpoint 2,637 sf 挂牌 RM683 psf vs 1,367 sf RM710–1,097。按 psf 找便宜要买大户型，按总价找便宜要买小户型——方向相反。
9. **外国人门槛 RM1,000,000 会砍掉半份名单。** Vogue One 近 8 月成交中位 RM930K，中位以下单位外籍买不了。
