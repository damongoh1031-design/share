## 可复用操作

### EdgeProp 项目页 ID 的批量拿法（本次最关键的方法）

EdgeProp 没有 condo sitemap，但**一个「outlook」sitemap 里含全部项目页 URL**：

```bash
curl -sL -A "<UA>" "https://www.edgeprop.my/sitemap.xml"            # 索引
curl -sL -A "<UA>" "https://www.edgeprop.my/sitemaps/sitemap-outlook-1.xml" -o o.xml
grep -o '<loc>[^<]*</loc>' o.xml | sed 's/<[^>]*>//g' | grep -i 'vogue\|viia\|gardens'
# → /condo/vogue-suites-1-kl-eco-city-45653 等，id 直接可读
```
拿到 URL 后 **用 WebFetch 抓**（curl 会被 Cloudflare 拦）。项目页给：48 个月中位 psf + IQR、中位总价、隐含租金回报、历史最高/最低（带面积与月份）、要价季度趋势、按面积段的租金回报表、**1 公里邻近项目对比表**。

```bash
curl -sL -A "Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7) ..." \
```

EdgeProp 项目页的 `Price Comparison with Nearby Properties` 表列出 1 km 内最多 50 个项目，**带距离、psf 三分位、总价三分位、回报**。这是发现「门户漏掉的供给」最快的入口——本次据此发现 7 个项目，其中 4 个在 500 m 带内。

**② 开发商旧站图片 → Wayback 必须带真实时间戳，不能只写年份**

```bash
# 错：https://web.archive.org/web/2016id_/http://...   → 返回 HTML 包装页
# 对：先查 CDX 拿 timestamp
curl -s "http://web.archive.org/cdx/search/cdx?url=klecocity.com/images/rt1/&matchType=prefix&output=text&fl=timestamp,original&collapse=urlkey&limit=100"
# → 20160601014415 http://klecocity.com/images/rt1/floorplan_club7.png
curl -s "https://web.archive.org/web/20160601014415if_/http://klecocity.com/images/rt1/floorplan_club7.png" -o club7.png
```

**⑥ CDN 缺图 → 从官方 PDF 手册按坐标裁切（补齐 ViiA C1/C2/C4/D1 的方法）**

```python
import pymupdf

for b in d[19].get_text('blocks'):
    print(round(b[0]), round(b[1]), ' '.join(b[4].split()))
```

```bash
curl -s "https://southpointresidences.com/wp-json/wp/v2/media?per_page=100&page=1&_fields=id,source_url" \
```

## 坑与反直觉

1. **EdgeProp「48 个月中位」会把新盘高估 40–60%。** 对 2021 年后交付的项目，这个数字包含 2022–23 投机高点。Vogue One：48m 中位 1,622 vs 近 8 月成交 1,016。**中介报「中位 psf」时，用的是两年前的价格。**
2. **MyRumahBaru 的中位 psf 是分区回退值。** Vogue One / Vogue Two / ViiA 三栋全显示 `RM1,282.43` / 中位总价 `RM1M` / 样本 `4 笔`。三栋不同楼不可能同价同笔数 → 全部弃用。
3. **「历史最高 psf」是判断「被炒过没有」的最快指标。** 3,036–4,157 psf 的项目（Vogue One / Southpoint）说明曾被投机资金推到远超租金支撑的位置；1,285–1,384（Setia Sky Seputeh）说明没被炒。前者跌起来没有底。
4. **户数会被门户写错一半。** Vogue Suites Two：mudah 344 vs EdgeProp 739。判别法：找**两个独立登记源**（EdgeProp 另给出开发商 Setia Promenade Sdn Bhd，可交叉验证）。
5. **同名不同项目会污染整个清单。** brickz 的「Boulevard, Mid Valley City」其实是 Southpoint Residences——判据是**中位 psf 与中位总价完全一致**（1,447 / 2,221,706）。
6. **「零成交」比「低价」更重要。** The Gardens Residences：151 户、永久地契、商场正上方，近 48 个月零申报成交。这不是「稀缺」，是「没有市场」——买入即锁定。
7. **步行距离 ≠ 直线距离，且新盘的桥更长。** KL Eco City 三栋直线 370–450 m，实际天桥步程 550–750 m（跨河 + 穿两个商场）。Northpoint 直线 313 m，连廊约 300–350 m。
8. **大户型 psf 低于小户型 25–35%。** Northpoint 2,637 sf 挂牌 RM683 psf vs 1,367 sf RM710–1,097。按 psf 找便宜要买大户型，按总价找便宜要买小户型——方向相反。
9. **外国人门槛 RM1,000,000 会砍掉半份名单。** Vogue One 近 8 月成交中位 RM930K，中位以下单位外籍买不了。
10. **「CDN 上 404」不等于「从未发布」。** ViiA 的 C1 / C2 / C4 / D1 在官方 CDN 两条路径上都 404，一度被判定为「从未公开」。实际它们一直在同一官网的 PDF 手册 P19/P21 里。**先找 PDF，再下「不存在」的结论。**
11. **同一开发商两本手册的面积可以差 21 sf。** ViiA Master Brochure 2023 与 Simplified Brochure V3 对 A2 给出 689 与 710、D2 给出 1,245 与 1,259。CDN 的 JPG 用的是 Simplified 版（即对外口径），但 Master 版才是建筑图。**谈单价时按 psf，面积差 3% 就是 3% 的钱。**
12. **「建成即售罄」的项目，户型图在互联网上根本不存在。** Vogue Two / Northpoint / The Gardens / Southpoint 四家一张都没有——不是没找到，是开发商从未公开。搜索时会跳出大量「看起来像」的图，逐一核对后没有一张能确认归属。**唯一可靠来源是 SPA 的附图（Schedule of Building），法律上必须附平面图。**
13. **同一栋楼同面积可以有 3–4 种平面。** ViiA 的 B3 与 B4 都是 807 sf、都是 1+1，但平面不同；A2（710）与 A5（635）都是 1 房，面积差 12%。**「ViiA 均价 RM1,669 psf」这种项目级数字不能用来谈具体单位。**
14. **开发商官网的销售状态图比任何门户都准。** S P Setia 2025-04 的 KLEC 总平面剖面直接标了每个塔楼 `Completed & Sold Out` / `Open for Sale` / `Open for Leasing` / `FUTURE LAUNCHES`。这张图上**没有单独标注 Vogue Suites Two**，与 EdgeProp RM0、brickz 无项目页互相印证。
15. **A 系列 6 种全部无阳台，B/C/D 系列 10 种全部有阳台。** 热带气候下这是硬差异，但门户的户型表里两档都写「有」或都写「未标注」。
16. **法拍价才是这个片区的真实价。** ViiA 710 sf 法拍成交 RM690K（RM972 psf）、Vogue One 710 sf 法拍 RM770K（RM1,085 psf）、Vogue One 969 sf 法拍 RM792K（RM817 psf）。三笔都在 RM800–1,100 psf，而 EdgeProp 中位在 RM1,622–1,669。**法拍市场没被营销污染。**
17. **「售出 60%」和「入住 20%」可以同时为真。** 投资客持有但不出租，等于整栋楼空着。这会压低管理费收缴率、拉低租金，并让你未来出租时面对大量同栋竞品。**问开发商「售出率」没有意义，要问管理处「入住率 / 门禁活跃户数」。**
18. **文件名里的缩写会骗人。** 在 spsetia 媒体库里 `OL_Setia-SV2_Floor-Plan_Type-A1…C4` 看着极像「Vogue Suites 2」，实际 `SV2` = **Setia Sky Ville 2**（槟城），属于 township 35044，与 KLEC 无关。**判据：查媒体项的 `wp:attached-to` 拿到 parent township id，再解析 slug**，别靠文件名猜。
19. **「门户上没有」≠「不存在」，先找项目自己的域名。** Southpoint 在 EdgeProp / mudah / brickz 上全都查不到连廊描述，一度被写成「需穿越道路」。真相是它有独立官网 `southpointresidences.com`，手册 P5/P6 整页在讲连廊。**顺序应该是：门户 → 开发商主站 → 项目独立域名 → Wayback → 论坛。**
20. **老盘的「原始开盘价」比任何中位数都有用。** Northpoint 2005-08 开盘：住宅 RM496,000 起、1,400–1,900 sf → RM261–354 psf；办公 RM549,000 起；Leasehold；代理是 Tan & Tan Property Showcase。对今天 RM732 psf 中位 → 21 年 2.1–2.8 倍、年化 3.7–5.0%，**跟通胀同步，没有投机溢价**。这个数据只在 `midvalleycity.com` 的 2005 年存档页里。
21. **同一栋楼，不同人的「有没有天桥」说法会相反。** Vogue One 业主坚持「没有像样的步行道」，ViiA 住客说「不用走到户外」。差别在于 Vogue One 要先穿园区到 RT-1 侧接驳点，且去 LRT 要过一处露天马路。**「有盖天桥」必须问清：从哪个门出、走几步、过不过马路。**
