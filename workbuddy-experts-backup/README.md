## 三、文件清单

- dist/：134 个 zip，命名 `<市场>__<插件名>.zip`，内容为该插件目录完整原样打包
- manifest.json：逐插件元数据（类型、来源、体积、角色/skill 数）
- my-experts-marketplace.json：我的专家注册清单快照
- backup_all.py：重新生成本备份（覆盖式，全量重打）；backup_experts.py 为旧版脚本
- install_experts.py / install_builtin_experts.py：安装专家到 my-experts（幂等）

## 四、敏感数据提示

- experts 与 my-experts 下的 malaysia-* 系列专家（hr-admin/legal/finance-tax/marketing）含商业电话号数据集（CSV/duckdb，源自 OSINT 项目），推送 public 仓库已获用户确认。
- 删除超过 50 个文件的操作会被沙箱安全策略拦截（fail-closed），更新备份用覆盖式，不要整目录 rm。
