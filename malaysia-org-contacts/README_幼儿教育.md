## 采集方法

### 1. 机构清单：Facebook 专页搜索（两轮，1,300+ 个专页）

| 轮次 | 关键词 | 命中 |
|---|---|---|
| 第一轮 | 城市 × 类型（幼儿园 吉隆坡 / 幼稚园 槟城 / 托儿所 新山 / 安亲班 巴生 …） | 46 |
| 第二轮 | **单类型词**（幼儿园 / 幼稚园 / 托儿所 / 安亲班 / 才艺班 / 特殊教育 / tadika / taska / kindergarten / preschool / montessori …） | 1,321 |

**关键经验**：城市限定词几乎没用——`幼儿园 吉隆坡` 平均只多 1.6 个结果，
因为绝大多数幼儿园的专页名里不带城市。改成**只用类型词**后，单条查询能出 30–54 个结果。
城市信息后来从 About 地址补回来，比硬塞进搜索词有效得多。

### 2. 三层筛选：把「全球搜索结果」压成「马来西亚机构」

单类型词会把台湾、印尼、泰国、印度、欧美的同类机构一起捞回来。用三层过滤：

1. **硬排除**：日文假名、泰文、阿拉伯文、天城文；台湾县市与「職場教保 / 教保服務中心 / 準公共」等台湾专用词；
   印尼 `PAUD / Kecamatan / Yayasan`；泰国、菲律宾、港、澳、新、中国城市。
2. **本地特征打分**：名称含马来西亚地名/州名 +3；含马来语常用园名（Bintang / Cahaya / Bestari / Tadika / Taska…）+2；
   中英混排 +1；含简体「幼儿园 / 托儿所 / 安亲班」+2；纯繁体 −1。得分 ≤ −3 直接丢弃。
3. **采集后验证**：抓到含 `Jalan / Lorong / Taman` + 五位邮编的地址，或 +60 电话，才算「已核」。

最终 **222 家已核**（有本地地址或电话）、48 家「待核」（名称带本地特征），
另有 **788 个未核实候选**单列一张表——它们大多是纯英文的 "XX Enrichment Centre"，
无法从名称判断国别，没有硬塞进主表。

### 3. 专页采集：轻量版，两个并发标签页

FB 商户页把「联系方式」整块（地址 + 电话 + 电邮）印在主页面里，
开 About 页只多 4–6 秒、信息几乎一样。所以另写了 `edu_harvest.js`：
只滚 6 屏、不开 About、不抓图，**20 秒/页**，两个标签页并发 → 实际 **9.5 秒/页**。
315 个页面 51 分钟跑完。

### 4. 负责人抽取

从贴文正文按「职务 + 姓名 + 电话」三元组抽，支持四种写法：

| 写法 | 例 |
|---|---|
| 职务在前 + 中文名 | `院长 陈美玲 012-345 6789` |
| 职务在前 + 英文名 | `院长 Ms. Tan 03-1234 5678` / `Teacher Apple 011-2222 3333` |
| 姓名在前 | `联络人：陈美玲老师 012-345 6789` / `（林园长）` |
| 只有英文称谓 | `Ms Lim 012-345 6789` |

单字姓（`陈老师`、`林园长`）允许，但要求它处在姓名起点（前面不是汉字），
并且首字必须在百家姓表内——否则「请老师协助」会被当成「请老师」。

## 关键发现（如实记录）

### 幼儿园的电话覆盖率是所有辑里最高的，但人名最少

| 辑 | 主题 | 有电话比例 | 有姓名人数 |
|---|---|---|---|
| 第一辑 | 寺庙 / 德教会 / 佛教 | 中 | 多（靠个人手机运转） |
| 第四辑 | 商会 / 工商团体 | 中 | 1,180（名表齐全） |
| 第五辑 | 宗亲会馆 / 同学会 | 13.5% | 518 |
| **第六辑** | **幼儿教育** | **78.5%** | **13** |

原因很直接：幼儿园是**生意**，必须让家长找得到——电话、地址、电邮全放在页面最显眼处；
但**院长是谁不对外公布**。315 个专页里，只有 2 个在贴文里提到「院长」，
而且只是「恭贺本校园长获奖」，没有姓名。

### 行业结构：一个园 = 一个手机号

幼儿园和托儿所绝大多数是**单店经营**，联络方式就是一个手机（01x）或一个座机，
配一个 Gmail / Yahoo 邮箱。212 个有电话的机构里，45 个有 2 个以上号码——
通常是「手机 + 座机」或「总校 + 分校」。

这跟宗亲会馆（秘书处座机）、寺庙（负责人个人手机）都不同：
幼儿园的号码既是机构号也是老板号，打过去通常就是园长本人接。

### 「全马来西亚」的边界在哪

FB 的专页搜索是**全球**的，不带地理约束。搜 `kindergarten` 会同时返回
美国、英国、印度、印尼、菲律宾的幼儿园。本辑的做法是：
**先全收，再用「本地地址 / +60 电话」做验证**，验证不过的进「未核实候选」表，不进主表。
所以主表 270 家可以认为基本是马来西亚的，但**不保证覆盖全马每一家**——
只覆盖「在 Facebook 上有专页、且专页名带类型词」的那部分。

## 已知局限

1. **人名只有 13 位**：幼儿园普遍不公布院长姓名，这是行业习惯，不是抓取失败。
   需要人名的话，只能靠「到店 / 打电话问」或教育局注册资料（不公开）。
2. **788 个未核实候选未做国别判定**：多为纯英文名的 Enrichment Centre，需逐个人工确认。
3. **州属 126 家未判定**：专页名与地址都没写地名（如「小太阳幼儿园」），无法归州。
4. **未做 OCR**：本轮没抓图（省时间），海报里的号码未纳入。
5. **补习中心不在范围**：学科补习（tuition）按口径排除，只收兴趣才艺类。
