## 三、英文名：这一轮最关键的方法

马来西亚华人普遍不使用完整中文名，报章与 Facebook 上多用英文名（例：吉打中总会长「拿督洪锡倡」= `Dato' Ang Saik Cheong`）。
只拿中文名去检索，命中率接近零。因此本轮专门建立了**中英双语姓名对照**。

### 3.1 官方双语人员页（最可靠）

中总为每位理事/名誉会长/历届会长建了中英两套页面，顺序一致：

- 英文：`acccim.org.my/en/pic-member/datuk-ng-yih-pyng/`
- 中文：`acccim.org.my/pic-member/拿督吴逸平硕士/`

通过 WordPress REST API 拉取 `pic-member` / `honorary-president` / `past-presidents` 三种自定义类型的**中英两份列表，按序号配对**，得到 84 对官方中英姓名（见工作簿「中英姓名对照」表）。

### 3.2 名表本身自带双语

- **登嘉楼中总**董事会：`Gan Raymond / 颜林茂`、`Teo Swee Phin / 张瑞平` —— 逐人双语。
- **吉打中总**董事名表：`拿督洪锡倡` + `DATO' ANG SAIK CHEONG, DSDK., SDK., BKM.`

### 3.3 双语对照的实际用途

| 用途 | 做法 |
|---|---|
| 查报章 | 用英文名搜 The Star / The Edge / NST；用中文名搜中国报 / 星洲 / 南洋 |
| 查 Facebook | 用英文名，FB 上的社团贴文几乎都用英文名 |
| 查公司 | 英文名 + 公司英文名，可定位到企业官网的管理层页 |

## 四、号码：实测结论（重要）

按「姓名 → 全网搜号码」的思路做了实测，结论必须如实说明：

| 尝试 | 结果 |
|---|---|
| DuckDuckGo 检索「姓名 + 联络/电话」 | 12 人样本命中 **0**；随后被限流，返回空结果页 |
| Bing 检索「英文名 + 州属」 | 返回的是泛化结果（搜 `Ang Saik Cheong Kedah` 出来的是所有姓 Ang 的网站），`site:` 查询直接空 |
| Bing 检索「公司名 + contact」 | 摘要里**不含电话号码**，只有一句简介 |

**原因**：搜索引擎并不索引这类社团领袖的**个人手机号**。个人手机只出现在两种地方——① 商会自己发布的**名表**（带 `Mobile:` 栏），② Facebook 贴文里的**名片/海报照片**。

**所以真正有效的路径是**：

1. **名表直取**（本版主力）——吉打中总的董事名表带 `Mobile / Office Tel / Home Tel / Fax / Email`，42 人全部拿到手机；KLSCCCI 理事会 8 页带直属电话，39 人拿到座机。这是唯一稳定可复现的来源。
2. **企业官网管理层页** —— 有公司名的 363 人，可进一步抓公司官网的 Contact/Management 页（下一步）。
3. **Facebook 海报 OCR** —— 上一轮对寺庙/宗教团体有效，商会同理，但需要登录态与逐页翻相册，成本高。

## 五、仍缺什么

- **182 个机构还没有人名**。这些多数只有 Facebook 专页、没有官网名表；其中大量是地方中华商会与行业商会。
- **个人手机只有 42 个**。除吉打中总外，其余机构的名表只登办公室电话。
- **州属判定不全**：人名表的州属是按所属机构推的，机构本身有 59 个未判定州属。

## 六、下一步建议（按性价比排序）

1. **补齐 17 个州中华总商会的名表**——马六甲、彭亨、砂拉越、沙巴、玻璃市、巴生、新山、北霹雳。这批是「中总属会」，名表通常带电话。
2. **用公司名抓企业官网**——363 人有公司名，抓官网 Contact 页可得办公室电话与电邮。
3. **Facebook 相册 OCR**——针对已有登录态的 cookie，翻各会「理事就职」相册，名片照上的手机号是唯一来源。
4. **报章交叉核对英文名**——中国报/The Star 的社团新闻可补全英文名与职务，间接提高检索命中。
