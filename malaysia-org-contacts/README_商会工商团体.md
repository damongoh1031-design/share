### 英文名从哪来

1. **中总官方双语人员页**（最可靠）：每位理事有 `acccim.org.my/en/pic-member/<slug>/` 与中文页两套，经 WP REST API 按序号配对，得 84 对。
2. **名表自带双语**：登嘉楼中总逐人 `Gan Raymond / 颜林茂`；吉打中总 `拿督洪锡倡` + `DATO' ANG SAIK CHEONG, DSDK., SDK., BKM.`。

### 「姓名→全网搜号码」的实测结论

搜索引擎（DDG / Bing）**不索引**这类社团领袖的个人手机：12 人样本命中 0；Bing 对中文姓名查询返回泛化结果，`site:` 查询为空。
个人手机只出现在 ① 商会自己发布的**名表**（带 `Mobile:` 栏）、② Facebook 贴文里的**名片/海报照片**。
因此本版把力气放在名表直取——吉打中总 42 人全部拿到手机，KLSCCCI 39 人拿到直属座机。

## 本轮新踩的坑（已写进 skill）

1. **「搜索词别名」会污染合并**：用宽泛关键词（如「马来西亚中华总商会」）搜到的页面若一律视作该机构，会把笨珍、古来、麻坡、关丹等地方商会全部并进 ACCCIM 总会。改为严格名称相似度（token Jaccard ≥ 0.7 / 中文主体包含且长度比 ≥ 0.75）。
2. **「中华总商会」里含「华总」二字**：分类正则若先匹配 `华总`，所有中华总商会都会被归到「华总体系」。商会判定必须排在华总之前。
3. **缩写撞车**：吉打与吉兰丹中总的英文缩写都是 KCCCI，仅凭缩写相同会误合并。缩写必须配合中文主体一致才生效。
4. **母会与分会不能合并**：`REHDA`、`FMM` 的 12/9 个州分会若按「包含关系」合并，会全部塌成一条。带 `分会/属会/青商团/妇女组` 的记录一律独立成条。
5. **FB 页名解析要跳过界面文案**：`发消息`、`联系我们`、`详细了解`、`在线状态` 会被当成机构名；`1.1 万位粉丝` 的「万」字会让 `[\d\.]+\s*位粉丝` 匹配失败，进而回退到错误行。
6. **境外同名机构大量混入**：`Chinese Chamber of Commerce of Guam / Mauritius / Tampa Bay` 等与马来西亚机构 token 高度重合，需按中文国名、`.bd/.ch/.us` 等 TLD、`Guam|Mauritius|Tampa` 等词逐层剔除。
7. **两字职务被当成人名**：`主席`、`财政`、`董事`、`顾问`、`查账` 都只有两个字，会通过「中文名 2–6 字」的校验。职务判定必须**排在姓名判定之前**，否则整份名表会被解析成一堆叫「主席」的人。
8. **职务行带全角冒号**：`顾问：`、`查账：` 与 `顾问`、`查账` 是两回事；`主任：蔡常辉` 还会把职务与姓名挤在同一行。需先剥尾部冒号，再按冒号切分同行姓名。
9. **起始标记撞上页面标题**：用 `名誉会长` 作区域起点，会命中 `<title>` 里的同名文字，把整段导航（含「青商团」等分组名）吞进来，导致每个人的职务都被加上错误前缀。用第 N 次出现（`occ`）定位正文标题。
10. **分组前缀只该给小组职务**：`会务规划与策略委员会 主任` 正确，但 `青商团 永久名誉会长` 就是错的。只在职务以 `主任/委员/组长` 结尾时拼接分组名。
11. **结束标记可能早于起始标记**：`其他委员会`（导航）在前、`历届理事会`（导航）也在前，取到的区域是空的。区域为负时须退化为「到文件末尾」。
12. **英文名里的弯引号**：`Dato’` 用的是 U+2019，不是 ASCII `'`。正则字符类里漏了它，吉打 42 人里有 23 人的英文名会掉到 `company_en` 字段。

## 使用提醒

- 理事会名单随届次变动，引用前请核对官网最新公告。
- 座机停用率高，建议优先使用「手机联络」表。
- 负责人名录中的个人电话/电邮来自机构官网公开的理事会名录页，用于会务联络，请勿用于商业推销。
