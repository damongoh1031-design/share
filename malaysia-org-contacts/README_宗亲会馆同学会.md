## 关键发现（如实记录）

### 「贴文里找人名 + 手机号」的产出率很低

71 个专页里，只有 22 个成功采到内容，从中仅抽出 **8 条**「职务 + 姓名 + 电话」三元组。原因是宗亲会馆的 FB 贴文以活动通告、祭祖、奖助学金为主，**很少把会长的手机号写进正文**；号码通常只在两种地方出现：

1. 会馆官网的名表或联络页（机构电话）
2. 海报 / 名片照片里（需 OCR，本次因模型加载与处理耗时未展开）

反例是马来西亚伍氏宗亲会——它的换届贴文直接列出「主席 伍志祥 019-337 2798 / 秘书 伍福祥 012-206 9155」，这种是最高价值的样本。

### 马来西亚社团的实际联络方式

宗亲会馆不像寺庙那样靠个人手机运转，而是靠**会所秘书处**：一个固定座机 + 一个 Gmail。所以本辑的重心放在「机构电话 + 理事名单」，而不是硬凑个人手机。这也是为什么 483 位负责人里，绝大多数只有姓名与职务。

### 官网域名是最大的瓶颈

950 个机构里只有 25 个能确认官网。大量地方性会馆（尤其东马与小镇）只有 Facebook 专页，甚至只有实体会所。域名靠猜（`xxx.org.my`）命中率不足 20%，必须靠搜索或友链发现。

## 已知局限

1. **电话覆盖率 8.7%**：主要来自官网联络页与属会名录，FB 贴文贡献很小。
2. **个人手机仅 2 个**：与上一辑（商会）吉打中总那种「每人一栏 Mobile」的名表相比，宗亲会名表普遍不含个人电话。
3. **机构名未经实地核验**：huatuan.asia 的属会名录存在少量命名不一致（如「吉玻惠安公会」与「吉玻惠安泉港公会」），已保留原始写法并在备注中标注。
4. **未做 OCR**：71 个专页下载了 92 张图，rapidocr 单张 2× 放大后处理约 6 秒，模型加载另需时间，本轮未跑完。

## 下一步建议

1. **补官网**：对 950 个机构逐个用搜索引擎确认域名，再抓「理事会 / 联络我们」。这是提升电话覆盖率最直接的办法。
2. **补东马**：砂拉越 93、沙巴 67 个机构里多数只有 FB，需按「古晋 / 诗巫 / 美里 / 亚庇 / 山打根」逐城检索。
3. **OCR 名片照**：把 92 张图跑完，再扩到全部专页的相册。
4. **报章交叉验证**：中国报、星洲的社团版常写「会长 XXX 表示……」，可补人名与职务，但号码仍需从名表取。
