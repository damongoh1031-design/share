### 3. Facebook 贴文遍历（90 个专页，全部跑完）

对 90 个专页逐个滚动加载贴文（每页 12–14 屏），抓正文 + About 区 + 大图，
从正文正则提取电话、电邮，并取号码前后 70 字上下文反推「职务 + 姓名」。

- 91 个页面记录、**568 张**海报图落盘
- 抽出 **43 条**人员记录，其中 20 条带明确职务，**4 条带个人手机**
- 手机样本：马来西亚伍氏宗亲会换届贴文「主席 伍志祥 019-337 2798 / 秘书 伍福祥 012-206 9155」

### 4. 按机构名反查 FB 专页（本轮新增）

机构名录只给名字、不给链接，所以另写一支 `fb_resolve.js`：
拿机构名去 FB 搜专页 → 按中文名相似度取最像的一个 → 抓正文 + About 的电话/电邮/地址。

- 试跑 38 家（全国级宗亲总会优先），**命中 9 家**，新增 9 个电话 + 9 个电邮
- 命中样本：马来西亚林氏宗亲总会 `03-3331 95xx`、马来西亚吴氏宗亲总会 `03-4042 5063`、
  马来西亚黄氏登进家族会 `019-599 5992`、马来西亚永春鸿榜陈氏公会 `017-363 7123`
- 命中率约 **25%**：小家族会、地方小会馆往往根本没有专页；命中者约 8 成带电话

## 关键发现（如实记录）

### 「遍历贴文找人名 + 手机号」的产出率很低，但遍历本身值得做

90 个专页全部跑完，只抽出 43 条人员、4 个手机。原因不是抓取不行，是**这类组织不发这种内容**：
宗亲会馆的贴文以活动通告、祭祖、奖助学金、会庆为主，会长的手机号几乎不写进正文。

真正有号码的地方是 **About 区 / 联络我们页**——那是秘书处的座机 + Gmail，不是个人手机。

### 宗亲会馆靠「会所秘书处」运转，不像寺庙靠个人手机

| | 寺庙 / 德教会 / 青年团 | 宗亲会馆 / 同学会 |
|---|---|---|
| 联络方式 | 负责人**个人手机** | 会所**秘书处**：一个座机 + 一个 Gmail |
| 号码在哪 | FB 贴文、海报图 | 官网「联络我们」、名表页眉 |
| 理事会规模 | 3–7 人 | 25–40 人（含当然理事、后补） |

所以本辑的重心放在「机构电话 + 理事名单」，而不是硬凑个人手机。
518 位负责人里 162 位能对上机构座机，只有 9 位有个人手机——这就是这类组织的真实结构。

### 官网域名是最大的瓶颈

965 个机构里只有 25 个能确认官网。大量地方性会馆（尤其东马与小镇）只有 Facebook 专页，
甚至只有实体会所。域名靠猜（`xxx.org.my`）命中率不足 20%——试了 25 个猜测域名，只 5 个有效。

## 已知局限

1. **电话覆盖率 13.5%**：主要来自官网联络页、属会名录与 FB About 区；FB 贴文贡献很小。
2. **个人手机仅 9 个**：宗亲会名表普遍不含个人电话，与上一辑（商会）吉打中总那种「每人一栏 Mobile」的名表完全不同。
3. **反查只跑了 38 家**：全国级优先，州级/地方级尚未跑。按 25% 命中率、每家约 1 分钟计，
   剩余 800 家需十余小时，本轮未展开。
4. **机构名未经实地核验**：huatuan.asia 属会名录存在少量命名不一致（如「吉玻惠安公会」与「吉玻惠安泉港公会」），已保留原始写法并在备注中标注。
5. **未做 OCR**：568 张海报图已下载，但 rapidocr 单张 2× 放大后约 6 秒，全量需 1 小时以上，本轮未跑。
6. **东马覆盖偏薄**：砂拉越 93、沙巴 67 个机构多为 FB-only，电话与地址缺口最大。

## 下一步建议

1. **把反查跑完**：对剩余 800 家按「州级 → 地方级」顺序跑 `fb_resolve.js`，预计可把电话覆盖率提到 30%+。
2. **补东马**：按「古晋 / 诗巫 / 美里 / 亚庇 / 山打根」逐城检索，东马会馆的 FB 活跃度其实高于西马小镇。
3. **OCR 名片照**：568 张图先按「含文字面积」排序，只跑前 100 张，性价比最高。
4. **报章交叉验证**：中国报、星洲的社团版常写「会长 XXX 表示……」，可补人名与职务，号码仍需从名表取。
