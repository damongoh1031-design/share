## 数据分层

| 层级 | 含义 |
|---|---|
| L1 | 官方渠道——逐条访问协会/总会/教区官网名录页提取，字段最完整 |
| L3 | Facebook 专页——公开专页资料栏 + 帖文海报图离线 OCR 识别 |
| L4 | 待补全——已知存在但官方渠道未列电话 |

## 口径与边界

- 只收录组织自行对外公布的联络方式；不抓取个人档案页、不推断个人身份、不拼接号码。
- 手机号多来自组织在海报/通告上自行印制的号码，属组织对外联络渠道，本表照录并标注来源。
- 电话统一归一为 `+60 A-XXXX XXXX`；手机 `01x` 校验 9–10 位，座机按区号校验（03 → 9 位，04/05/06/07/09 → 8 位，082–089 → 8 位）。
- OCR 识别的号码存在 0/8、6/5 误读风险，重要联络请对照 `poster_hits_*.csv` 中的原图核对。
- 第三辑按要求排除全部伊斯兰相关团体。

## 重新生成

各辑的采集与生成脚本在本地工作区 `_tools/` 下（`chr_crawl.py`、`youth_crawl.py`、`fb_search_*.js`、`ocr_inc.py`、`*_build.py`、`*_xlsx.py`），可按报告中的「方法与口径」复现。
