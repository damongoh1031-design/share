## 口径与边界

- 只收录组织自行对外公布的联络方式；不抓取个人档案页、不推断个人身份、不拼接号码。
- 手机号多来自组织在海报/通告上自行印制的号码，属组织对外联络渠道，本表照录并标注来源。
- 电话统一归一为 `+60 A-XXXX XXXX`；手机 `01x` 校验 9–10 位，座机按区号校验（03 → 9 位，04/05/06/07/09 → 8 位，082–089 → 8 位）。
- OCR 识别的号码存在 0/8、6/5 误读风险，重要联络请对照 `poster_hits_*.csv` 中的原图核对。
- 第三辑按要求排除全部伊斯兰相关团体。
- 第四辑收录商会、工商团体、行业公会、双边商务理事会与董总/华总体系；宗亲乡团、宗教团体、体育文艺团体不在本辑范围（前三辑已覆盖部分）。

## 第四辑补充说明

- **机构去重**：Facebook 专页名与官网名录名常不一致（如「柔佛州中华总商会 笨珍属会」与「笨珍中华总商会」），按地名与名称相似度归并，避免同一机构两条记录。
- **手机覆盖率偏低属正常**：商会的对外窗口以办公室座机为主，43 个机构有手机，另有 42 位负责人本人的手机来自官网理事会名录。
- **人名优先、双语姓名**：第四辑第二轮把重心放在理事名表，负责人由 235 扩至 1,180 位；马来西亚华人多用英文名，故新增「中英姓名对照」表（84 对，取自中总官方双语人员页）。查人时先用英文名，再回查中文名。
- **「姓名搜号码」不可行**：实测 DDG / Bing 均不索引社团领袖的个人手机（12 人样本命中 0）。个人手机只出现在商会自印名表的 `Mobile:` 栏与 Facebook 名片照里，故以名表直取为主。
- **不可达官网**：马六甲、彭亨、沙巴、吉兰丹、玻璃市、砂拉越中总官网长期 502/403，华总原域名已成停放页，这些机构改由 Facebook 专页取得联络。
