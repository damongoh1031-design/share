## 字段口径

- `category`：德教会 / 佛寺 / 佛教团体 / 神庙 / 其他宗教团体
- `tradition`：北传 / 南传 / 藏传 / 德教 / 民间信仰
- `phone_primary`：组织对外公布的主联络号（多为座机），`+60` 归一
- `phone_mobile`：手机（01x），本地社团实际使用的联络渠道
- `phone_mobile_src`：`FB专页资料栏` / `海报图OCR` —— 决定要不要先核对原图
- `phone_alt`：同组织其他已公布号码，已按州属区号过滤掉明显误读
- `poster_images` / `poster_hits`：该组织被抓取的帖子图数 / 其中含号码的图数
- `leader_name` / `leader_title`：**仅**收录组织官网公开披露的职务姓名，未披露者留空，不推断
- `confidence`：已核实(官网) > 已核实(FB专页) > 已核实(名录站) > 仅地址

## 边界

1. **只收组织自己公布的东西**：官网、总会名录、官方专页资料栏、活动海报上印的联络号码。这些号码即便实际是某位理事的手机，也是组织主动对外公布的联络渠道，本表照录并标注来源。
2. **不抓个人档案**：探测时命中的 10 个个人 Facebook 档案（标题格式 `姓名 (@handle) • Connect with friends`）全部剔除，未采集、未入表。
3. **不做号码猜测**：不从姓名推号码、不拼接、不补位。OCR 识别结果一律用马来西亚区号规则校验（手机 01x 且 9–10 位；座机区号 3/4/5/6/7/9 与 082–089 分别校验位数）。
4. 名录站（L2）数据来自公开华团登记资料，**地址/电话可能已过时**，首次拨打前建议先核对 FB 专页。

## 已知缺口

| 缺口 | 影响 | 补法 |
|---|---|---|
| 手机覆盖 29/400 | 多数组织仍只有座机 | 需逐页翻「相册」历史帖；或向德教联合总会索取属阁名录（含阁长电话） |
| 负责人姓名仅 3 条 | 无法直接"找人" | 逐家抓 `理事会`/`理事名單` 页；德教会抓 `阁长` 换届新闻 |
| 德教会 97 家，实际全马 150+ | 覆盖约六成 | 以德教联合总会属阁名录为种子 |
| 神庙（民间信仰）覆盖弱 | 大量庙宇无网站，仅 FB | 按州华人新村逐区扫 FB 专页 |
| 马佛总分支会数据 2015 年 | 电话可能失效 | 电话复核后回写 `confidence` |

