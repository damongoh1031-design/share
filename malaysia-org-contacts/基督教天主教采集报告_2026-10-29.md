## 一、用了什么策略

沿用佛教/德教会那套三层采集，只是把入口换成了教会系统：

| 层 | 做法 | 本轮用到的地方 |
|---|---|---|
| L1 | 逐条访问教区/宗派官网的名录页，按标签解析 | 天主教 6 个教区、卫理公会 TRAC、宗派总部 |
| L3 | 登录态 Facebook 专页 + 帖子海报图 OCR | 华人独立教会、「恩典」系列、卫理/神召/浸信堂会 |
| L4 | 只有名字和地址，官网未列电话 | 亚庇、古晋教区，部分 FB 专页 |

### 1.1 天主教：九个教区，六种网站结构

马来西亚天主教共 9 个教区（CBCMSB 名录）。每个教区的网站结构都不一样，只能一家一家适配：

| 教区 | 网站结构 | 结果 |
|---|---|---|
| 槟城教区 | 每个堂区一个详情页，`Tel / Email / Website / Address / Clergy` 标签齐全 | 32 堂区，**全部有电话 + 本堂神父姓名** |
| 马六甲-柔佛教区 | 前端从 `parish-data.json` 渲染，页面直出是空壳 | 直接抓 JSON，22 堂区，含神父姓名/职务 |
| 吉隆坡总教区 | 按 8 个区各一页，堂区块内联 `Phone: / E-mail:` | 35 堂区，34 有电话、32 有电邮 |
| 山打根教区 | 全部堂区挤在一个页面，`Telephone / Fax / Email / Rector` 前缀行 | 6 堂区，全部有电话 |
| 亚庇总教区 | 名录只列堂区 + `PASTORS` 名单，**不列电话** | 23 堂区（含神父姓名），归入待补全 |
| 古晋总教区 | 名录只列堂区名，连弥撒表页都没有电话 | 18 堂区，归入待补全 |
| 诗巫 / 美里 / 根地咬 | 博客或静态站，无结构化名录 | 只收总部条目 |

### 1.2 新教：官网能通的只有一部分

试了 10 个宗派总部站点，**有 4 个域名从本机直接连不上**（`tjc.org.my`、`baptist.org.my`、`presbyterian.org.my`、`sdamalaysia.org` 与 `anglicanwestmalaysia.org` 全部 `ERR_CONNECTION_TIMED_OUT` 或 502，Chrome 直连也一样，不是代理问题）。能抓的：

- **神召会（AG）** `ag.org.my` — 总部地址 + 电话 + 电邮
- **救世军** `salvationarmy.org.my` — 总部地址 + 电邮
- **巴色会（BCCM）** `bccm.org.my/contact/` — 亚庇总部，电话 + 电邮
- **卫理公会华人年议会（CAC）** `methodist.org.my` — 总部电话（堂会名录是 Google Map 嵌入，抓不到）
- **卫理公会 TRAC** `trac.org.my` — 「Find a Church」查询页，31 间堂会（含州属、崇拜语言），但**详情页返回空**，没有电话

### 1.3 Facebook：登录态搜索 + 海报 OCR

63 条中文查询（「恩典教会 <州>」×14、「基督教会 <州>」×14、「天主教堂 <州>」×10、卫理/浸信/神召/长老/真耶稣 × 若干），登录态走 `/search/pages/?q=`，命中 145 个专页。

145 个里只有一部分能用 —— 中文基督教关键词在 Facebook 上会被**台湾、香港、新加坡、日本、菲律宾**的教会淹没。过滤掉 51 个（德教会、佛教会、殡葬、书店、电视台、论坛报）+ 16 个明确外国的，剩 78 个进采集。

## 三、必须说清楚的限制

1. **天主教九个教区里，三个没有电话。** 亚庇、古晋、诗巫/美里/根地咬的官网只列堂区名与神父名，办公室电话得从《Catholic Directory》纸本或教区周报补。
2. **新教宗派官网半数连不上。** 真耶稣教会、浸信会、长老会、安息日会、圣公会的马来西亚官网从本机不可达，这些宗派只能靠 FB 层补，覆盖率明显低于天主教。
3. **FB 搜索结果被外国教会稀释。** 中文「基督教会」「恩典教会」在 FB 上大量指向台湾与香港，即使加了 78 个地名黑名单，仍会有漏网（例如只写「恩典城市」这类无地名的专页）。
4. **卫理公会堂会只到名字级。** CAC 的堂会名录是 Google Map 嵌入，TRAC 的详情页返回空，两边的电话都拿不到；这轮只补到州属与堂名。
5. **OCR 会误读。** 手机号已按 01x 9–10 位、座机按区号位数校验，但同州内仍可能把 `8` 读成 `0`，每张命中图都留了原图。
6. **负责人姓名只收官网公开列出的。** 天主教这边质量很好（本堂神父 + 职务），新教这边多数专页不写牧者姓名，留空不推断。

## 四、下一步最省力的补法

1. **《Catholic Directory of Malaysia》** —— 每年出版，九个教区全部堂区的地址、电话、神父名单都在里面，一本书解决天主教 100% 覆盖。
2. **各宗派年议会/总会的年度会友大会手册（Yearbook）** —— 卫理公会、巴色会、浸信会都有，内含每间堂会的牧师姓名与电话。
3. **对 78 个已确认的 FB 专页逐页翻相册** —— 教会海报（布道会、圣诞晚会、儿童营）底部常印「报名：01x-xxxx xxx」，这是拿到手机最直接的路。
