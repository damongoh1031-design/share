# 亚洲（中日韩）长程邮轮

## 一句话结论（TL;DR）

**2026 年中国母港是「净缩量 + 结构升级」——净减 3 艘约 3,930 床位，外资仅剩 MSC 与皇家加勒比；韩国 C-3-2 团体签不再适用于邮轮行程，日韩格局反转为「日本线回归、韩国线承压」；亚洲长线的真正入口是东南亚，不是日韩。**

口径：全谱系（4 晚短线 → 60 晚大环线）。核验日 **2026-10-06**。

## 3. 签证与政策（面向中国大陆护照）

### 3.1 日本

| 项目 | 现状 | 生效日期 | 状态 |
|---|---|---|---|
| 短期免签 | 中国大陆**不在**免签范围 | 长期 | 已生效 |
| **船舶观光上陆许可（邮轮免签）** | 乘**法务大臣指定邮轮** + **当日返船** + **限指定港**（那霸/福冈/长崎/熊本/鹿儿岛/佐世保/小樽/函馆等），制度上限 30 日、可多次上陆 | 2015-01-01 | 已生效 |
| 签证费 | 单次 3000→**15000 日元**；多次 6000→**30000 日元** | 2026-07-01 | 已生效 |
| 离境税 | 1000→**3000 日元** | 2026-07 | 已生效 |
| 免税购物 | 单店单日消耗品上限 50 万日元，未税满 5000 日元可退 | — | 已生效 |
| **免税改「先付后退」** | 取消店内即时免税与 50 万日元上限，改机场退税，须 90 天内离境 | **2026-11-01** | 已定案 |
| 免税品邮寄 | **禁止另寄**，须本人携带出境 | 2025-04-01 | 已生效 |

**🚨 三个硬约束（邮轮免签失效的三种情况）**：
1. 在日本**登船 / 离船**，或**跨夜停靠** → 上陆许可不适用，须常规签证
2. 护照上若**已贴有效日本签证** → 免签自动失效
3. **「日本→韩国→日本」单次签不够**，需两次/多次

**其他**：邮轮免签由船方/领队统一办理，**多数要求团进团出**、当日返船（部分资料称 19:00 前）。

### 3.2 韩国

| 场景 | 政策 | 生效日期 | 状态 |
|---|---|---|---|
| 济州岛 | 免签 30 天（个人/团体均可），**限岛内** | 长期 | 已生效 |
| 韩国本土（釜山/仁川/首尔） | 需签证 | — | 已生效 |
| 中国团体游客免签（一阶段） | 3 人以上、指定旅行社、整团同进同出，本土最长 15 天 | 2025-09-29 ~ 2026-06-30 | **已过期** |
| 中国团体游客免签（延长） | 同上 | 2026-07-01 ~ 2026-12-31 | 已生效 |
| 团体旅游签证手续费免除 | 仅费用减免，非免签 | 至 2026-06-30 | 已过期 |
| **K-ETA** | 中国大陆护照**不在适用范围**，不能替代签证 | — | 已生效 |

**要点**：济州免签后**不可转往本土**，否则视为非法入境；邮轮「免签」须确认航次在韩方认可名单内，并向船司索要**书面确认**；韩国无落地签，临近出发无法加急。

### 3.4 易踩坑清单

1. 日本：跨夜/登离船不适用邮轮免签；**改港可能改变入境次数需求**
2. 日本：免税品须本人携带出境，拆封/邮寄将被补税
3. 韩国：济州免签**不得转本土**；K-ETA 对中国护照无效
4. 韩国：团体免签有时限（至 2026-12-31）与组织条件，**营销名称 ≠ 资格**
5. 越南：芽庄/胡志明市需 e-Visa，仅富国岛免签
6. 台风季改港：改港/取消停靠**不改变已办签证效力**，但可能影响入境次数；**改港不自动退款**（2026-08 爱达·魔都号、海洋光谱号案例按约 1700 元统一赔偿）

## 可复用操作

### 中国护照持有人在亚洲坐邮轮的签证自查流程

```
① 是否在日本登船/离船/跨夜？ → 是 → 必须常规日签
② 是否只当日返船且停指定港？ → 是 → 邮轮免签可用（护照上不能已有日签）
③ 行程是否「日→韩→日」？ → 是 → 日本需两次/多次签
④ 韩国是否只到济州？ → 是 → 30 天免签；否则需个人签（C-3-2 已不适用）
⑤ 越南是否只到富国岛？ → 否 → 提前办 e-Visa
```

### 比价模板

```
结算总价 = 船票 + 港务费税费 + 小费(晚数 × 每人每晚) + 岸上游(项数 × 单价) + 酒水/特色餐饮 + WiFi
```

## 坑与反直觉

1. 🚨 **韩国 C-3-2 团体签已不适用于邮轮行程** —— 但很多二手攻略仍写「邮轮去韩国免签」。**济州免签 ≠ 韩国本土免签**，且济州免签**不得转本土**。
2. 🚨 **日本邮轮免签有三种失效情况**（登离船 / 跨夜 / 护照已有日签）—— 最容易在「跨夜停靠」上踩坑。
3. 🚨 **K-ETA 对中国大陆护照无效** —— 不能替代签证。
4. 🚨 **「改港不自动退款」** —— 2026-08 爱达·魔都号与海洋光谱号案例按约 1700 元统一赔偿，不是退款。
5. ⚠️ **韩国团体免签有时限（至 2026-12-31）与组织条件** —— 营销名称 ≠ 资格，必须书面确认。
6. ⚠️ **「亚洲长线」的入口是东南亚不是日韩** —— 日韩受制于航线短 + 政策波动大。
7. ⚠️ **2026 年运力净缩量** —— 外资撤离后，可选船型减少，价格未必下降（结构升级）。
8. ⚠️ **日本 2026-11-01 起免税改「先付后退」** —— 机场退税，须 90 天内离境。
