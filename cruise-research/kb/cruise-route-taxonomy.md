# 全球邮轮航线分类总表

## 一句话结论（TL;DR）

**全球邮轮航线可归为 13 个区域 / 30 条主线；价格锚点是加勒比（大众 100–200 美元/人·晚），价格天花板是极地探险（550–980 美元/人·晚），性价比洼地是换船 repositioning 航线。**

数据口径：检索日 **2026-10-06**，覆盖近 12 个月（2025-10 ~ 2026-10）。价格为**每人每晚、双人入住、含船上基础食宿、不含岸上游与机票**。

## 1. 六大核心判断

| # | 结论 | 含义 |
|---|---|---|
| 1 | **加勒比是全球运力最密集区域** | 东/西/南加勒比 + 百慕大构成北美基本盘；以 7 晚为主；大众线 100–200 美元/人·晚，**是全行业价格锚点** |
| 2 | **地中海呈「西 / 东 / 亚得里亚」三分** | 西=美食酒庄与大城市；东=希腊群岛与古迹宗教；亚得里亚=中小型船 + 古城峡湾。旺季 4–10 月，**高端与奢华船占比明显高于加勒比** |
| 3 | **价格天花板在极地** | 南极（11 月–次年 3 月，经德雷克海峡）、北极斯瓦尔巴（6–8 月）普遍 **>500 美元/人·晚**；受 IAATO 限额约束，**供给刚性 + 需求高增长** |
| 4 | **亚洲是增量最快市场** | 中国母港 2026 年重新扩张（MSC 荣耀号 2026-01-27 重返上海）；日韩短线与东南亚长线同步增长；日本环岛受樱花季 + 红叶季双高峰驱动 |
| 5 | **内河是独立赛道，不是海轮的补充** | 欧洲内河（多瑙河/莱茵河）、尼罗河、亚马逊三类：体量小、船型小、客单价高、复购强，**客户画像与海轮重叠度低** |
| 6 | **换船航线（repositioning）是性价比洼地** | 跨大西洋、巴拿马运河、西非换船线因需异地返程、海日偏多，单价明显低于同船同级常规航线 |

## 可复用操作

### 比价必须统一的三件事

1. **晚 vs 日**：Cunard / HAL / Princess / Seabourn / Regent / Silversea 用「**晚**」；**Costa 用「日」**；**日本公司用「日間」**（如「46 泊 47 日」）。「天数 ≈ 晚数 + 1」。
2. **价格口径**：大众线多为「船票 + 税港费」，**不含小费与岸上游**；奢华线（Regent / Silversea / Seabourn / Crystal）多为**全包**。
3. **结算总价**：用**同人数、同舱型、同权益**的结算总价比较，不要只看「每人起」。

### 快速判断「这条航线贵不贵」

```
每人每晚 = 每人起价 ÷ 晚数
```
- < 100 → 低于行业锚点（换船线 / 加勒比内舱 / 墨西哥）
- 100–250 → 行业主流区间
- 250–500 → 高端
- > 500 → 奢华 / 极地

## 坑与反直觉

1. 🚨 **「价格锚点」是加勒比，不是地中海** —— 加勒比运力最密集，大众线 100–200 美元/人·晚定义了全行业基准；地中海的高端/奢华船占比明显更高，直接拿地中海均价对比加勒比会高估地中海。
2. 🚨 **最低价出现在换船线，不是促销** —— 跨大西洋调遣内舱可低至 **24–40 美元/人·晚**，但代价是异地返程 + 海日多。
3. 🚨 **极地「贵」有供给刚性支撑** —— IAATO 限额导致船位供给受限，不是短期溢价。
4. ⚠️ **内河不是「便宜的海轮」** —— 客单价高、船小、复购强，客户画像与海轮重叠度低。
5. ⚠️ **「环球航线 90–180 晚」是区间不是标准** —— 各家口径差异极大，必须逐条核（见 `pacific-circle-cruises.md`、`long-voyages-over-30-nights.md`）。
6. ⚠️ **日本环岛的「双高峰」是樱花季 + 红叶季** —— 不是夏季，与加勒比/地中海的旺季逻辑相反。
