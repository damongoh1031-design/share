# Coral Princess 2027 / 2028 单船深研结论

## 一句话结论（TL;DR）

**Coral Princess 的价值不在硬件（2003 年入役，Princess 船队第二老），而在她是 Princess 仅有的两艘能过巴拿马运河旧闸的船，因此拿下 2027 环太平洋与 2028 真环球两个目的地最密集的世界航程——买她，买的是航线，不是船。**

六维加权总分 **3.65 / 5**（深研后由预判 3.50 **上调 +0.15**）。数据抓取日 **2026-09/10**。

## 3. 独特卖点三类拆分

### 3.1 ✅ 真首创（有独立来源证实）

| 卖点 | 证据 |
|---|---|
| **EnviroEngine（CODAG 燃-柴联合）推进系统 —— 邮轮业首个完全采用** | *Maritime Reporter* 2003-02 原文：「is the first in the cruise industry to fully utilize this new system」 |
| **Princess 船队首艘使用燃气轮机发电的船** | 同上 |
| 首个采用「漏斗装饰性涡轮柱」设计 | ⚠️ 单源（MHI 技术评论） |

> ⚠️ **不要误列为首创**：「Coral 级是全球首批专为巴拿马运河旧闸设计的 Panamax 邮轮」—— **未找到任何官方/权威定性支持「首批/首艘」**。官方只写「specially built to sail through the Panama Canal」，属**差异化表述，不是首创**。

### 3.2 ✅ 真差异化

| 卖点 | 说明 |
|---|---|
| **Princess 船队仅有的两艘可过巴拿马运河旧闸的船** | 官方原文：「one of only two ships in the Princess fleet specially built to sail through the Panama Canal」。硬差异：旧闸限宽 **32.31 m**，Coral 水线宽 **32 m** 恰好通过；Royal 级/Sphere 级（36–45 m）**永远无法通过** |
| 体量远小于新船 | 2,000 客 vs Sphere 级 4,310 客；官方定位「intimate ship」 |
| **双层双剧场结构** | **Princess Theater（两层）+ Universe Lounge（两层、3 个液压旋转舞台）** —— 2,000 客小船上有两个双层演艺场，业内罕见 |
| Universe Lounge 疑似 Coral 独有 | ⚠️ Island Princess 在 **2015 年改装**中拆除 Universe Lounge 与尾部酒廊以加建舱房（载客由 ~1,970 增至 2,210）。**待二次确认** |
| Coral 级与 Island 级 2015 后已非同型 | Island 2015 干船坞加建舱房，两姊妹船「no longer twins」 |
| 巴拿马运河主题讲解 | Princess 自 1967 年经营该航线，船上配运河专家全程讲解 |
| The Conservatory（温室玻璃顶泳池区） | 2 个热水池 + 1 个淡水泳池 + 池畔淋浴 + 酒吧 + 2 张乒乓球桌 |

### 3.3 ❌ 营销话术 / 被误传（重点）

| 被误传说法 | 核查 |
|---|---|

| 「Princess 世界航程最长 / 最多港」 | ❌ **夸大**。2028 为 115 晚 / 49 目的地；业界有更长者（RCI Ultimate World Cruise 274 晚、Oceania 180 天、Regent 154 晚） |
| 「Coral Princess 是最新的 Princess 船」 | ❌ **错**。2003 年入役，为船队第二老；最新为 Star Princess（2025-09-26） |
| 「环太平洋覆盖中日韩」 | ❌ **错** |
| 「2026 是 Circle Pacific 115 晚」 | ❌ **错** |
| 「Bayou Café 已更名为 Crown Grill」 | ⚠️ **部分准确**。官方 Coral 船页现列 Crown Grill（无 Bayou）；但 2026 世界航程宣传册（2024 年印制）仍写 Bayou。**判定：现行官方口径为 Crown Grill** |
| 「Coral 上有 Royal/Sphere 级的设施」 | ⚠️ **张冠李戴高发**。**The Dome、Park19、Ocean Terrace、Alfredo's、Salty Dog** 均**不在** Coral 上；Coral 的 **Universe Lounge、The Conservatory** 又不在新船上 |
| 「被宣传但从未交付的设施」 | ✅ **有行业先例，但不在 Coral**：**Sun Princess 的 Park19 三大核心设施（RollGlider / Coastal Climb / Ropes Course）2024-07 官方宣布「无法接收交付」，从未开放**。Coral 本身未查到此类设施 |

## 8. 公司稳定性

- **母公司 Carnival Corporation**：FY2026 Q3 净利 **$1.9B（纪录）** / 调整后 EBITDA **$3.0B** / 净杠杆 ≈3.3x；**S&P 2026-06-25 上调至 BBB−**
- **Princess 品牌健康度**：正在扩张（订 **3 艘 Voyager 级新船**，183,000 GT，2035/2038/2039 交付）
- 🚨 **Coral Princess 未来部署**：**2028 年 5 月之后的部署官方未公布**
- ⚠️ **「公司风险」vs「品牌风险」**：Princess 公司层面稳健，但**老船被跨品牌调配是真实存在的操作**（参照 2026-10-06 嘉年华宣布 **Cunard Queen Anne 2029 移交 P&O、P&O Arcadia 移交 Holland America**）。**「船舶长期可用性」风险 > 「公司破产」风险**
- 事故：**2025-01 诺如（CDC 128 客 + 20 员）、2025-02 诺如（69 客 + 13 员）**；2009/2011 推进故障；2020-01 机舱火灾；**无搁浅**
- 2024–2026 最高频投诉：**设施老旧磨损**

## 9. 三条行动建议

### 建议 1：先确认国籍 / 护照

- **中国 / 马来西亚护照** → 🚨 **必须提前办美国 B1/B2**（洛杉矶/劳德代尔堡登船、夏威夷/阿拉斯加停靠均为美国口岸），审理可达数月。**这是本航次最大门槛。**
- **别忘巴布亚新几内亚签证**（2/16–2/19 停靠，非公民须登船前持有效签证）—— **最容易被忽略的一项**
- **若「中日韩」是硬指标**：2027 GCP **只有日本 7 港 + 中国香港，没有韩国、没有中国大陆港** → **Coral Princess 不是答案**（应看 Crystal Serenity 2027）

### 建议 2：只考虑「阳台及以上 + Premier 套餐」

- **阳台房 $233/晚**（vs 奢华线 $450–900/晚）是本航次最大价值点；**内舱在 114 晚里会很难受**
- **必须买 Premier（$105/人/天）**：因为 **Plus 完全不含特色餐厅**，而 Coral 全船只有 2 家常态特色餐厅 —— Premier 的「无限特色餐厅 + 无限酒水 + 4 设备 WiFi + 小费」在 100+ 晚里极易回本
- ⚠️ **2026-10-13 后价格已上涨 $5/天**，且**早鸟权益（免费机票 + $3,000 OBC）已于 2025-10-31 过期**

### 建议 3：接受「买航线，不买船」

- Coral Princess 是 **2003 年的船**，**2024 年干坞只是维护性质**，**2024–2026 最高频投诉就是「设施老旧」**。**若不能接受硬件代差，请直接排除她。**
- 但要的是「一条航程把太平洋两侧跑完 + 巴拿马旧闸 + 新西兰峡湾 + 金伯利 + 阿拉斯加双冰川」，**2027 年几乎没有比她更合适的选项** —— 她 3.65 分里**观景维度 4.5 分是全场顶尖**
- 🚨 **留意品牌风险**：老船被重新调配是真实存在的操作

## 附：订舱前必须书面确认的 5 件事

1. **实际舱位面积（含不含阳台）** —— 同一房型官方有 5 套不同数字，**必须书面给出你这一间的具体面积与是否遮挡（BY/BZ、OV–OZ 为遮挡房型）**
2. **主餐厅座次归属** —— 官方与 Cruise Critic 说法完全相反，**确认你要的座次模式（Traditional / Anytime / Dine My Way）**
3. **套餐价格与生效版本** —— **2026-10-13 起 Plus $70 / Premier $105（预购）**，确认适用价格、是否已被涨价覆盖、**特色餐厅免费次数**（Premier 无限次 vs Plus 0 次）
4. **巴拿马运河闸室与改线条款** —— 确认走**旧闸（Historic Locks）**，并书面确认**干旱限闸导致改线/改期的补偿或退改政策**
5. **分段购买的权益差异** —— 若买分段而非全程，**确认分段是否享有世界航程专属权益**（参照 2026 先例：分段权益显著缩水，仅 $200 OBC/人）

## 可复用操作

### 验证「这条 Circle Pacific 是哪家的」

```
Coral Princess 的 = Grand Circle Pacific，110/114/129 晚，美国出发（1 月）
Grand Princess 的 = Circle Pacific，79 晚，澳洲出发（6 月）
```
**两者完全不是同一条航线，二手资料常把「79 晚」与「129 晚」混为一谈。**

### 长航程套餐净值换算

```
Premier 价值 ≈ 无限特色餐厅 + 无限酒水 + 4 设备 WiFi + 小费
若 WiFi 单买($27.99/天) + 小费($18/人/晚) 已 ≈ $46/人/天
→ 100+ 晚里 Premier($105/天) 的边际成本仅约 $59/天，极易回本
```

## 坑与反直觉

1. 🚨 **「环太平洋」这个名字与「中日韩」需求错配** —— Princess Circle Pacific **无韩国、无中国大陆港**。
2. 🚨 **Princess 有两条「Circle Pacific」** —— Coral 美国出发 110/114/129 晚 ≠ Grand 澳洲出发 79 晚。
3. 🚨 **Plus 完全不含特色餐厅** —— 而 Coral 全船只有 2 家常态特色餐厅。**长航程必须上 Premier。**
4. 🚨 **4 设备 WiFi 单买套餐 2026-10-13 停售** —— 4 设备改为仅随 Premier 提供。
5. 🚨 **早鸟权益已过期**（免费机票 + $3,000 OBC，2025-10-31 截止）—— 现在订没有这些福利。
6. ⚠️ **官方 Fact Sheet 的客舱数（1,545）与载客量数学矛盾** —— 实际约 1,000 间。**官方数据也会错。**
7. ⚠️ **主餐厅座次归属官方与 Cruise Critic 完全相反** —— 必须书面确认。
8. ⚠️ **「被宣传但从未交付的设施」有行业先例**（Sun Princess 的 Park19 三大设施 2024-07 官宣无法交付，从未开放）—— 但**不在 Coral**。
9. ⚠️ **老船跨品牌调配是可预测风险** —— 2026-10-06 嘉年华宣布 Cunard Queen Anne 2029 移交 P&O。**论坛传闻不是信号，官方部署空缺才是信号**（Coral 2025-05「被出售」传闻已证伪）。
