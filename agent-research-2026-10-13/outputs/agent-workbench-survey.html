结论与选型建议

最接近 WorkBuddy 形态（桌面开箱即用）

  • Cherry Studio（52.6k★，MCP+助手市场）
  • AnythingLLM（67k★，RAG+Agent，桌面/Docker 双形态）
  • DeepChat（MCP+ACP 智能体接入）

能力最全能（bash + 自动化 + Computer Use + MCP 全占）

  • Agent Zero（19.4k★）：Docker 内 XFCE 桌面 + 任意 bash + 子代理 + 定时任务 + MCP
  • OpenHands（90.8k★）：沙箱终端任务闭环 + MCP，浏览器 Agent

编程任务优先

  • 终端：Gemini CLI / Crush / Qwen Code（MCP+无头，可进 CI）
  • IDE：Cline / Continue / Void（Roo Code 已归档，慎入）
  • 长任务：Plandex（计划-执行分离，可回滚）

操控本机 GUI（Computer Use）

  • Agent-S：Linux 桌面 OS 级 GUI 操控第一梯队
  • Cua：跨 OS 虚拟机 + fleets，做集群/评测
  • browser-use：浏览器级最流行，可被 MCP 封装后喂给任意 Agent
组合建议：桌面 Cherry Studio/AnythingLLM 日常交互 + Agent Zero 跑自动化长任务 + MCP 统一接入 bash/browser/CUA 工具链。Flowise、Roo Code 仓库已归档，AgentGPT/TaskWeaver/SuperAGI 等 legacy 项目已停止维护，未列入正表。
