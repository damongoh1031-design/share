为什么用「npm 下载量」而不是 star 数

DSH 插件绝大多数通过 npm 分发，dsh plugin add 每次安装/更新都会产生下载计数。它是真实使用行为的代理指标，而 star 数会被「多平台通用项目」严重污染——本榜单中星标最高的 tt-a1i/archify（★83,106）实际周下载仅 3.1 万，因为 DSH 只是它的一个集成分支。

三个关键事实：

  1. 单一插件吃掉近四分之一流量。billion-context 一个插件 130 万周下载，占整个榜单 548.7 万总量的 23.7%，是第二名的 4.9 倍。这是典型的「一个刚需插件定义整个生态」现象。
  2. 前 10 名占一半以上。48 条榜单里，前 10 名拿走 54.7% 的下载量，第 25 名之后基本跌到 6 万/周以下。
  3. 作者集中度比插件集中度更高。前 48 名中，MichengAI 一人占 11 席，zhu1090093659 占 7 席。两者合计 18 席，占榜单 37.5%。

DSH 生态还很年轻（2026 年 8 月开源），原生插件几乎没有时间积累 star。真正高频使用的插件星标普遍在两位数到三位数，而下载量已达十几万。反过来，几万 star 的项目往往只是「顺手支持了 DSH」。两者的相关性接近于零。

五、为什么是它们？六大驱动力

把 TOP 48 按「解决的问题」重新归类后，可以清晰看到六条主线。它们不是随机分布，而是直接对应 DSH 官方能力的缺口。

驱动力 1 省 Token / 控成本 —— 唯一的第一刚需

DSH 通过 API 计费，长会话的成本会随上下文线性膨胀。任何能直接降低 token 消耗的插件，都会立刻变成刚需。

代表：billion-context（130 万/周，断层第一）、dsh-context（15.4 万，上下文可视化）、dsh-cost-meter（10.8 万）、Balance-Whale-Widget（18.5 万）。

为什么它能断层第一：billion-context 官方描述「省 5 倍 token」且支持「几十亿 token 单会话」——同时命中「省钱」和「超长会话」两个痛点。其余插件多是监控和可视化，只有它是直接省钱。省钱类插件是唯一能突破生态早期天花板的品类。

驱动力 2 官方 UI 太简陋 —— 供给量最大的品类

DSH 官方只提供一个基础外壳，界面能力极度克制。而「UI 增强」是市场里插件数量最多的分类，达 810 个，占 23 类之首。

代表：dsh-codex-ui（26.6 万，第 2）、DSH-better-sidebar（23 万，第 3）、dsh-web-all（11.8 万）、dsh-TUI（4.6 万）、dsh-genui（3.6 万）。

为什么：用户带着「对标 Claude Code / Codex」的预期来，第一眼看到的却是极简界面。把界面补成「像样的开发工具」是最直接的价值交付——装了立刻看得见，不需要学习成本。

驱动力 3 对标 Claude Code / Codex 的功能补位

DSH 的定位就是对标这两者，用户会拿它们的既有功能逐项比对，缺什么就催生什么插件。

代表：dsh-rewind（2.6 万，Claude Code /rewind 语义）、dsh-code-review（6.9 万，/review）、dsh-simplify（8.3 万，/simplify）、dsh-btw（9.3 万）、dsh-task-board（14.9 万）、dsh-automation（12.4 万，cron 定时）。

为什么：这是一条「已有心智模型」的迁移路径——用户不需要理解新概念，只要看到熟悉的命令名就会装。命令名本身就是最强的获客文案。

驱动力 4 模型能力缺口 —— 视觉与搜索的桥接

DeepSeek V4 系列 API 只能处理纯文本，粘贴截图 AI 完全看不懂；原生联网搜索范围也有限。这是模型层的硬缺口，必须由插件补。

代表：modlens（9.7 万，★4,239，把图片转结构化 JSON 证据）、dsh-vision-router（3.5 万）、modsearch（4.2 万）、dsh-free-search（4.6 万，7 个搜索引擎自动回退）。

为什么：modlens 的关键差异是不只做 OCR——它保留元素间的位置关系和语义，所以前端开发能直接丢截图让 AI 检查还原度。这类插件是「模型做不到、插件替它做」，价值最硬，也最容易形成口碑。

驱动力 5 场景延伸 —— 从「电脑上的工具」到「随时可用的助理」

用户不满足于坐在电脑前用 DSH，希望手机上、IM 里、远程服务器上都能用。

代表：dsh-remote-web-ui（15 万，扫码远程操控）、dsh-ssh（12.3 万）、dsh-im-connect（14.1 万，微信/企微/钉钉/飞书/QQ/Telegram）、dsh-im（6.2 万，9 种渠道）、dsh-pocket（Cloudflare Quick Tunnel 公网访问，免自建服务器）。

为什么：DSH 常跑长任务，用户希望「出去吃饭时掏出手机还能看进度」。远程类插件解决的是使用场景的物理限制，一旦用上就回不去，粘性极高。同时这也是安全风险最高的一类——远程二维码/公网地址/访问密码切勿分享。

驱动力 6 整活与皮肤 —— 高下载 ≠ 高实用

娱乐类插件（138 个）下载量不低，但性质与前面五类完全不同：靠社区传播而非功能价值驱动。

代表：dsh-pet（15.4 万，第 9，★仅 16）、dsh-deep-whale 鲸鱼娘皮肤（3.9 万）、dsh-dream-skin（3.5 万）、dsh-wallpaper-engine（4.9 万）、以及 dsh-deepcel（伪装成 Excel）、dsh-liang-skin（推理强度「滑动变祖器」）、dsh-ads（往界面塞 2005 年风格弹窗广告）等纯整活项目。

为什么：视觉冲击力强、截图可传播、零使用门槛，所以能快速冲量。但要注意：dsh-pet 以 ★16 排进下载量第 9，说明这类下载里有大量「装一次看看就卸」的行为。下载量高不必然代表留得住。

六、头部玩家的两种打法

打法 A：矩阵策略 —— MichengAI（11 席）

不追求单个爆款，而是用十几个小切口、单功能插件覆盖全场景：会话管理（codex-ui / archive-manager / btw）、技能（skills-manager / agency-agents）、代码（code-review / simplify）、集成（im-connect）、自动化（automation）、趣味（codex-pet / pua）。

为什么有效：每个插件只解决一个明确问题，描述里全是具体功能点，命中率高；装了一个之后自然会被推荐装下一个，形成内部导流。

打法 B：全家桶策略 —— zhu1090093659/dsh-web（7 席）

一个 monorepo 拆出 7 个包：skill-explorer、remote-web-ui、task-board、git-graph、ssh、web-all、dsh-pet，共享 ★8,707 的仓库星标。

为什么有效：共享仓库热度，任何子包被搜到都会带动其余；dsh-web-all 提供「一键全装」，进一步拉高整包下载量。本质是把单个插件的获客成本摊薄到 7 个产品上。

反观 omdsh-dev（3 席）和 liustack（2 席），走的是「少而精」路线：better-sidebar 单点做到 23 万周下载，modlens + modsearch 两个互补插件覆盖视觉与搜索。

七、长尾现状：市场还在极早期

市场共有 4,644 个插件，但官方榜单 48 条就覆盖了 548.7 万周下载。对比「最新收录」板块的实际情况——

  • 最新收录的 24 个插件里，绝大多数星标为 0、周下载量为 0（如 dsh-thinking-highlight、dsh-session-titler、dsh-pixel-ui 等）；
  • 有数据的极少：benrong2048-boop/dsh-prompt-polish ★3，aa2246740/dsh-dragndrop-attachments ★1 / 290 周下载。

这说明了什么

DSH 生态 2026 年 8 月才开源，供给爆炸但使用高度集中：4,600+ 插件中真正被广泛使用的不足 50 个。这意味着：

  • 选插件要盯榜单，不要逛长尾——长尾里 90% 是玩具或刚发布的实验品；
  • 榜单变化会很快——生态处于窗口期，今天的冷门可能下周爆发；
  • 但也意味着兼容性风险高——DSH 官方在快速迭代（9 月 29 日发布 v0.2 预览版并提供桌面安装包，10 月 3 日加入实验性 Claude Code Mods 兼容层），很多插件跟不上版本，装之前要留意版本要求。

八、如何自己判断插件是否真流行

  1. 看周下载量，不看 star。star 会被多平台项目污染（archify ★83,106 但仅 3.1 万周下载）。
  2. 看作者是否成矩阵。同一作者多个插件同时上榜（如 MichengAI 11 席），说明该方向被反复验证，踩坑概率低。
  3. 看描述里有没有具体数字。「省 5 倍 token」「支持 30+ 厂商模板」「7 个搜索引擎」这类可验证的量化承诺，通常比「增强体验」之类的空话靠谱。
  4. 看分类。当前下载量集中在：会话与消息、UI 增强、用量与计费、技能包、远程与移动端、视觉与多模态。这些是真实痛点所在。
  5. 警惕纯视觉类的高下载。皮肤/桌宠类传播性强但留存低，别把下载量等同于实用价值。
  6. 留意版本要求。市场详情页会给出 ^0.1.7 这类版本约束，装前先确认自己的 dsh 版本满足。

安全提醒

插件是第三方代码，尤其会操作浏览器、Shell、文件和远程访问的插件风险最高（dsh-ssh、dsh-remote-web-ui、dsh-browser 等）。安装前务必查看仓库来源和声明的权限范围。建议只装有刚需的插件，并用 Git 管理本地 DSH 配置以便回滚。
