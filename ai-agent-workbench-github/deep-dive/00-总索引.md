## 三、本轮档案新挖出的关键事实（概览报告里没有的）

这些是逐项深挖后才浮现的**格局级变化**，对选型影响很大：

| 事实 | 说明 | 影响 |
|---|---|---|
| **OpenHands 已改名 Agent Canvas** | 原 OpenDevin → OpenHands → Agent Canvas，Docker 镜像为 `ghcr.io/openhands/agent-canvas` | 按老名字找部署文档会踩坑 |
| **Open Interpreter 已 Rust 重写** | 从 Python 版转为 Rust 核心，定位也在调整 | 老教程的 API 可能失效 |
| **Suna → Kortix** | 项目更名，许可证为自定义（NOASSERTION） | 商用前必须逐条读协议 |
| **Devika → Opcode** | 疑似项目转向/停更，2025-09-25 后无提交 | 不建议新项目采用 |
| **Flowise 已归档** | 2026-08-13 归档停更 | 曾热门，现不建议新采用 |
| **Roo Code / Void 双双归档** | D 类 IDE 插件赛道正在洗牌 | 2026 年选 IDE Agent 要避开这两个 |
| **Bytebot 已归档** | 2025-09-12 归档 | 桌面容器 Agent 路线受挫 |
| **B 类四强只有 Langflow 是纯 MIT** | n8n 非 OSI、Dify/FastGPT 附加条款、RAGFlow 是 Apache-2.0 | 商用合规首选 Langflow |
| **MCP「破 10 万 Server」口径存疑** | 与官方 Registry ~9,652 相差一个量级 | 引用生态规模时需注明口径 |
| **Mem0 基准无第三方复现** | 自报 LOCOMO 成绩，且有中文硬编码 / v3 静默丢记忆问题 | 上生产前必须自测 |

- Dify / AnythingLLM 的 releases API 抓取失败 → 版本号未定

- Browser Use / Langfuse 安装命令来自通用知识

> **原则**：只报告可核实信息。凡未能一手核实处，一律显式标注，不做推测性填充。

## 五、怎么读这 6 份档案

- **想选型** → 先看本索引第二章速查表定位 2-3 个候选，再进对应档案看"局限与风险"和"适合谁"
- **想上手** → 直接跳每个项目的「快速上手」代码块（安装命令 + 最小示例 + 部署方式）
- **想评估风险** → 看每个项目末尾的「局限与风险」+ 本索引第三章的关键事实表
- **想理解范式** → 看每份档案开头的"边界说明"与"两条路线"框架，理解各类之间的分野
