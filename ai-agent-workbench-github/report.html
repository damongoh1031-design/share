1三个最关键的判断

如果只读三句话，读这三句。

重心从「框架」转向「运行时 + 协议」

2026 年最热的不是某个编排框架，而是 OpenClaw（39.2 万 Star，GitHub 历史星标第一）这种「本地优先的个人 Agent 运行时」，以及 MCP（工具连接标准）与 A2A（Agent 间协作标准）。框架层反而在收敛——微软已把 AutoGen 与 Semantic Kernel 合并。

可视化平台跑出四强，但许可证是最大的坑

n8n（20.7 万）、Dify（15.8 万）、Langflow（15.6 万）星标量级远超其他，加上字节 Coze Studio 入局。但四家中 只有 Langflow 是纯 MIT；n8n 是 Sustainable Use License（非 OSI 开源），Dify / FastGPT / Coze Studio 都是「基于 Apache 2.0 附加条件」的自定义许可。

2026 年出现一波明显的「停运潮」

49 个项目中 已有 5 个停止维护或归档：Flowise（2026-08 归档）、Roo Code（2026-05 停运）、Void（已弃用）、Bytebot（2025-09 归档）、Devika（2025-09 后无提交）；Aider、bolt.diy 也进入停滞/维护模式。选型第一步是看活跃度，不是看 Star 数。

62026 年五大趋势

① 从「框架」到「运行时」

竞争重心从「怎么编排」转向「跑在哪里、记得住什么、连得上什么」。OpenClaw 的 Gateway 网关架构、Suna 的每会话沙箱、Letta 的记忆操作系统，都是运行时层的创新。

② 协议层完成标准化

MCP（Anthropic → Linux Foundation 旗下 AAIF）+ A2A（Google → Linux Foundation）构成「下层连接工具、上层连接 Agent」的双层标准栈。任何不支持 MCP 的工作台在 2026 年都算生态落后。

③ 沙箱隔离成为分水岭

从 OpenClaw 的「裸奔」到 E2B 的 Firecracker microVM 硬件级隔离，安全边界正在成为通用工作台的核心竞争力，也是监管关注焦点。

④ 记忆成为下一个差异化战场

Letta 的 OS 式分层记忆 vs Mem0 的事实抽取中间件，两条路线尚未分出胜负。基准数字的「罗生门」（厂商自报 vs 第三方质疑）说明这个领域还不够成熟。

⑤ IDE 插件赛道洗牌

Roo Code 停运、Void 弃用、Aider 停滞，而云端 Agent 兴起——说明「VS Code 插件」这一形态可能正在被「云端沙箱 Agent」取代。

⚠️ 必须知道的安全风险（OpenClaw）

  • 工信部 2026-03-12 发布安全预警；国家互联网应急中心列举密钥泄露、重要信息误删、功能插件（Skills）投毒、隐私泄露等风险。
  • 提示词注入：网页/邮件中的隐藏恶意指令可诱导其泄露密钥或执行高危操作。
  • ClawJacked 远程控制漏洞：诱导用户访问恶意网页即可远程控制本地 Agent。
  • 权限失控：默认系统级权限，可能误删文件/生产数据，造成不可逆损失。
  • 建议：务必跑在独立虚拟机/容器中，用 E2B 等硬件级隔离方案「戴安全锁」，并严格审查第三方 Skills。
