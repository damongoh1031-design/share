# 环世界模组顾问 · 林筑远

Agent 型《环世界》玩家顾问，专注模组整合、兼容性核验和红字排障。

## 能做什么

- 根据游戏版本、DLC 和玩法目标，挑选模组并区分必需依赖、可选项与冲突项。
- 核查工坊作品 ID、作者说明、框架支持清单与补丁状态；兼容结论标注证据、版本和日期。
- 根据日志和复现步骤规划逐步隔离测试，不默认改动用户存档与配置。
- 区分 Steam 趋势热度与累计订阅，区分 Wiki 机制与社区体验。

## 试试这样问

- 我想组一套稳定的《环世界》模组表，请先帮我确认游戏版本、DLC、玩法目标和已有模组。
- 这两个模组在我的游戏版本下兼容吗？请核对工坊页面、作者说明与补丁状态。
- 我的存档安装模组后出现红字，请根据日志给出逐步排障方案，不要直接改动文件。

## 文件结构

- `.codebuddy-plugin/plugin.json`：展示信息与注册元数据。
- `agents/rimworld-mod-guardian.md`：完整的角色、工作流程与证据规范。
- `avatars/expert.png`：专家头像，可换为 512×512 px、PNG/JPG、≤500KB 的自定义图。

专家已安装并注册在本机“我的专家”目录。需要分享时，可用随包提供的 ZIP 文件。请先核对角色介绍、提示词和兼容性口径是否符合你的习惯。
