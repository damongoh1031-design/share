# 诈骗号码「第三方举报接口」实测报告

> 实测时间：2026-10-05 14:10–14:20（GMT+8）
> 方法：对每个候选端点真发 HTTP 请求（OPTIONS / GET / POST 空 body），只探接口存在性与契约，**不提交任何内容**

---

## 一、结论速览

| 平台 | 有公开举报 API？ | 实测证据 |
|---|---|---|
| **ScamGuards** | ✅ **有，且实测可用** | `POST https://scamguards.app/api/submit` → `Allow: OPTIONS, POST`，`X-Matched-Path: /api/submit`，JSON 响应 |
| **Truecaller** | ❌ 无公开 API | 仅内部端点 `filter-store4-{eu,noneu}.truecaller.com/v4/filters`（GET/POST 均 **400** = 存在但缺参数/鉴权）。`api.truecaller.com` DNS 不存在 |
| **CallApp** | ❌ 无 | `s.callapp.com/callapp-server/{report,feedback,spam}` 全部 **404**（对照：`csrch` 返回 525，说明是限流不是不存在） |
| **Whoscall / Gogolook** | ❌ 无（企业 API 是**查询向**） | `api.whoscall.com` → 404；`gc.whoscall.com` / `api.gogolook.com` DNS 不存在 |
| **MCMC CRP**（政府） | ❌ 无 | `aduan.mcmc.gov.my` 及 `/api/*` 全部 **403**（Cloudflare 拦非浏览器请求） |
| **Tellows** | ❌ 无 | 查询端点 200 可用；`/basic/rate.php`、`/api/v1/rate` 均 **404** |
| **Should I Answer** | ❌ 无 | `shouldianswer.net/api` 恒返回 `{"success":false,"error":"Invalid URL"}`，不接受号码参数 |
| **Hiya** | ❌ 无公开入口 | `api.hiya.com` → 404 |

**一句话**：**只有 ScamGuards 提供了可直接调用的公开举报 API。** Truecaller / CallApp / Whoscall 的举报入口**只在 App 内**，其内部接口使用违反 ToS。

## 二、ScamGuards `/api/submit` —— 完整接口契约

> 依据：实测响应头 + 开源仓库 `github.com/nicuk/scamguards` 的 `app/api/submit/route.ts` 源码

### 端点

```http
POST https://scamguards.app/api/submit
Content-Type: application/json
```

### 请求体（JSON 模式）

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `scamType` | ✅ | string | 必须在下方枚举内，否则 400 `Invalid scam type` |
| `dataPoints` | ✅ | array | `[{"type":"phone","value":"0102422713"}]`，**至少 1 个**，否则 400 |
| `description` | ❌ | string | 自由文本叙述，**用于可信度评分**（写得越具体分越高） |
| `platform` | ❌ | string | 如 WhatsApp / Telegram / Facebook |
| `country` | ❌ | string | 默认 `"MY"` |
| `amountLost` | ❌ | number | 损失金额（本次为 0 / 不填） |
| `reporterHash` | ❌ | string | 格式必须 `rh_` + 32 位十六进制，否则被服务端置 null |

### 带证据的 multipart 模式（**推荐**）

`Content-Type: multipart/form-data`，字段同上（`dataPoints` 改为 **JSON 字符串**），另加：

| 字段 | 说明 |
|---|---|
| `evidence` | 文件（截图等）。上传成功 → `isVerified = true`，**可信度提升** |

### `scamType` 合法值（源码 `lib/constants.ts`，共 12 个）

```
collectibles_scam       precious_metals_scam    ecommerce_scam
macau_scam              love_scam               investment_scam
parcel_scam             job_scam                loan_scam
mule_recruitment        phishing                other
```

> ⚠️ `macau_scam` = **电话冒充**（冒充银行/政府/执法）。贷款类选 `loan_scam`，投资类选 `investment_scam`。

### `dataPoints[].type` 合法值（共 11 个）

```
phone  email  bank_account  whatsapp  telegram
ewallet  social_media  website  crypto_wallet  name  company
```

### 号码归一化规则（源码 `lib/utils/normalize.ts`）

```
0102422713  →  60102422713     （去非数字；0 开头 → 60 + 去掉首位的剩余）
+60 10-242 2713  →  60102422713
```
服务端自动归一化，**提交时给原始格式也能匹配**。

### 限流与冷却

| 观测 | 值 |
|---|---|
| 速率限制 | `X-Ratelimit-Limit: 5` |
| 冷却 | **60 秒**——`{"error":"Cooldown active","message":"Please wait 60 seconds…","retryAfter":60}` |
| 超限响应 | HTTP **429** |

### 提交示例（curl）

```bash
curl -X POST https://scamguards.app/api/submit \
  -H "Content-Type: application/json" \
  -d '{
    "scamType": "loan_scam",
    "country": "MY",
    "dataPoints": [{"type": "phone", "value": "0102422713"}],
    "description": "Unsolicited call offering a loan. Caller did not identify any company. Call received within the last 3 days. No loss incurred. Suspected loan scam.",
    "amountLost": 0
  }'
```

带证据：
```bash
curl -X POST https://scamguards.app/api/submit \
  -F "scamType=loan_scam" \
  -F "country=MY" \
  -F 'dataPoints=[{"type":"phone","value":"0102422713"}]' \
  -F "description=Unsolicited loan offer call. Suspected loan scam." \
  -F "evidence=@calllog.png"
```

### 成功后的效果

报告**立即生效**，无需注册、无需登录。之后任何人搜这个号码都会看到你的警告。仓库 README 原文：*"Your report is live immediately."*

### 配套接口（同属 ScamGuards，实测可用）

| 端点 | 方法 | 用途 |
|---|---|---|
| `/api/submit` | POST | 提交举报 |
| `/api/search` | **POST** | **验证是否入库**。body：`{"inputs":[{"type":"phone","value":"0102422713"}]}` |
| `/api/dispute` | POST | 号码持有人申诉误标 |
| `/api/recent-reports` | GET | 最近举报流 |
| `/api/stats` | GET | 平台统计 |

**`/api/search` 返回样例**（实测，举报提交后立即查询）：
```json
{"analysis":{"status":"suspicious","confidence":75,
  "summary":"The information you searched has appeared in 1 previous report(s). Please exercise caution.",
  "factors":[{"factor":"Found in 1 report(s)","impact":"negative"},
             {"factor":"1 verified report(s) with evidence","impact":"negative"}]},
 "reportCount":1,"verifiedCount":1,"disputedCount":0,
 "scammerProfile":{"confidenceScore":60,"heatLevel":"LOW","message":"First report in our database"}}
```

> ⚠️ `/api/search` 是 **POST**，用 GET 会返回空 —— 这是最容易踩的坑。

## 三、为什么 Truecaller / CallApp / Whoscall 没有公开接口

| 平台 | 原因 |
|---|---|
| **Truecaller** | 举报走 App 内的 `filter-store` 服务，鉴权用 `installationId`（App 内设备凭证）。**官方无举报 API**；`developer.truecaller.com` 只提供「验证自己的用户」（Number Verification / SDK），2026-04-01 起已转为**商业收费模式**。企业向的 Truecaller for Business 是让商家**登记自己的来电显示名**，不是举报他人 |
| **CallApp** | 举报纯 App 内 UI 行为，无对外端点（`report`/`feedback`/`spam` 全部 404） |
| **Whoscall / Gogolook** | 企业向产品 **Asi** 是**查询侦测**（输入号码/域名 → 返回风险分），原文 *"Check domains and phone numbers instantly"*；**不是提交举报**。举报仍是 App 内「回报」功能 |

### 内部接口的红线（重要）

Truecaller 的 `filter-store4-*.truecaller.com/v4/filters` **确实是举报端点**，但它：
1. 需要 App 内 `installationId`（无法通过公开途径合法获取 —— OTP 注册路径已于 2026-02 被 Truecaller 后端封堵）
2. 使用属**冒用他人账户凭据**，违反 ToS 且有法律风险
3. **批量提交虚假举报**可能构成对平台的滥用

→ **不要走这条路。** 想用 Truecaller，只能在 App 内手动举报。

## 四、实务建议

| 你的目的 | 该用什么 |
|---|---|
| **程序化 / 批量提交** | ✅ **ScamGuards `/api/submit`** —— 唯一可用 |
| **让号码进官方库（Semak Mule）** | PDRM 报案（无 API，只能人工） |
| **让号码被真正封锁** | MCMC CRP 门户（无 API，人工填表） |
| **让最多人看到（马来西亚）** | Whoscall App 回报（唯一与 PDRM 官方库互通） |
| **企业级批量防诈数据** | Gogolook Asi（商务洽谈，**查询向**） |

### 合规边界

- ScamGuards 是**第三方社区数据库**，不是官方机构。提交不等于官方立案。
- 提交内容**公开可见**，措辞必须用「疑似」。
- 单次提交有 60 秒冷却，速率上限 5。**不要脚本轰炸**。
- 若要同时走官方链路（MCMC / 报案），ScamGuards 只是**补充**，不能替代。
