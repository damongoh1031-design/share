# 马来西亚：如何通报诈骗号码

> 调研日期：2026-10-05 ｜ 覆盖官方渠道 6 条 + 众包平台 8 个
> 核心结论：马来西亚存在**两条互不替代**的通报链路。官方链路（997 / 报案 / MCMC）能真的封锁线路；众包链路（Whoscall / Truecaller / CallApp）能让号码在全网被标红。**唯一的重叠点是 Whoscall —— PDRM 授权它直接读取 Semak Mule 官方库。**

---

## 0. 一句话结论

| 你的目的 | 走哪条 | 具体入口 |
|---|---|---|
| 钱已被转走 | **官方**（最紧急） | 打 **997**（24h，通话即报案） |
| 没损失，只想让号码被封 | **官方** | MCMC CRP（`aduan.mcmc.gov.my`）+ telco 客服 |
| 没损失，想让别人接电话时看到警告 | **众包** | Whoscall App 回报（**首选**，与官方库互通） |
| 想让号码进官方 Semak Mule 库 | **官方** | 只能通过**警方报案**，没有自助入口 |
| 想同时做两件事 | 两条都走 | 众包 30 秒搞定，官方走 MCMC 或报案 |

**关键事实**：马来西亚**没有**"输入号码 → 自助提交进官方库"的入口。Semak Mule 是**查询**库，号码入库存靠警方录入。

## 1. 官方渠道（有强制力）

### 1.1 NSRC 997 —— 国家诈骗应对中心

| 项 | 内容 |
|---|---|
| 号码 | **997** |
| 时间 | **24 小时**（2025 年 9 月起；旧资料写 8:00–20:00 已过期） |
| 归属 | 2022-10-14 成立；**2025-07-16 起由 PDRM 主导**，CCID 日常运营，新增 139 个岗位 |
| 核心变化 | **2025 年 9 月起，打 997 这通电话本身即视为报案**，不必再跑警局。2026-03-04 政府发言人重申"不需要另行报案，997 足够" |
| 组成 | NFCC + PDRM + BNM + MCMC + 银行 + 电信商 |
| 受理 | 网络金融诈骗：钱在不知情下被转走 / 被诱骗线上转账（钓鱼、澳门骗局、恶意软件） |
| **不受理** | ① 银行账户被冻结（找银行）② 案件跟进（找办案警官）③ 一般投诉（找 MCMC） |

**打 997 前先准备好**：本人账号、每笔转账的日期/时间/金额、**收款账号与银行**、骗子号码或链接。记下报案编号。

**官方数据（说明为什么必须快）**
- 2025 全年：报案损失 **RM542,000,000**，实际返还受害者仅 **RM6.7M**（约每损失 RM81 拿回 RM1）
- 2026 Q1：NSRC 接 **55,619 通电话**、**11,486 份报告**，扣押 RM4.2M，返还 RM1.9M
- 2026 年 1–7 月：扣押 RM7.94M，其中 **65%（RM5.16M）已返还** → **能冻住的钱大多能拿回，问题在于冻得太少**

**安全提醒**：**NSRC 只接电话，从不主动外呼**。任何自称"NSRC 官员"打给你的都是骗子（ABM/AIBIM 2024-05-14 已发警告）。

### 1.2 PDRM 报案 —— 号码进官方库的唯一路径

- 就近警局（balai polis）商业罪案组报案
- 在线：`ereporting.rmp.gov.my` ｜ SFRV2：`sfrv2.rmp.gov.my`
- **CCID 直拨：03-2610 1559**（Menara KPJ, Bukit Aman）
- **作用**：报案后号码/账户会被录入 **Semak Mule**，供全国人查询 → 这是号码"进官方库"的**唯一合法途径**
- 带齐：与骗子的全部聊天截图、转账凭证、骗子号码/账号/社交主页

### 1.3 MCMC（SKMM）—— 号码封锁的执行方

**官方指定入口（2026-07 通讯部长 Fahmi Fadzil 议会书面答复原文）**
- **Consumer Redress Portal (CRP)**：`aduan.mcmc.gov.my`
- 投诉邮箱：`aduanskmm@mcmc.gov.my`（旧资料写 `aduan@mcmc.gov.my`，两个都在流通）
- **WhatsApp 服务**（官方答复提到，具体号码未在公开页面列出）
- 热线：**1-800-188-030**（周一至周五 8:30–17:30）
- 受理：冒充政府机构/银行/执法部门的诈骗号码、假网站、假社交账号

**⚠️ MCMC 的流程是三级递进，不能一步到位**
```
先找 telco → 未解决 → CFM（aduan@cfm.my / 1800-188-030 / cfm.my）
          → 仍不满 → MCMC（aduan.mcmc.gov.my）
```
**⚠️ 刑事管辖在 PDRM**，MCMC 只做协助（要求平台删内容、封网站、技术取证），依据《1998 通讯与多媒体法》第 588 号法令 +《2025 网络安全法》第 866 号法令。

**MCMC 执法实绩（2022-01-01 → 2026-06-30，议会答复原文）**
| 项目 | 数量 |
|---|---|
| 封锁可疑诈骗电话 | **25 亿** 通 |
| 封锁垃圾短信 | **30.4 亿** 条 |
| 终止涉诈电话线路 | **190,429** 条 |
| 向平台提交删内容请求 | 275,787 条（**95% 被删**） |
| 2026 年 1–7 月收到诈骗电话投诉 | **158** 宗 |

另：**2024-09-01 起**，telco 必须封锁含超链接、索要个人信息、或带回拨号码的短信。

### 1.4 Cyber999 / MyCERT（CyberSecurity Malaysia）

| 渠道 | 详情 |
|---|---|
| 在线表单 | `mycert.org.my/portal/online-form?id=7a911418-9e84-4e48-84d3-aa8a4fe55f16` |
| 邮箱 | `cyber999@cybersecurity.my` |
| 热线 | **1-300-88-2999**（8:30–17:30）；紧急（DDoS/钓鱼/数据泄露）**+6019-266 5850** |
| App | Cyber999 Mobile（Google Play `my.cyber999.mobile`，**无 iOS 版**） |

**⚠️ 定位**：官方页面把 Cyber999 定义为"**计算机安全事件**的国家报告点"，**原文未把"诈骗电话/短信"列为受理类别**。适合报钓鱼网站、恶意软件、数据泄露，**不适合作为电话诈骗的首选举报口**。

### 1.5 电信商（Telco）—— 最快能封号的一层

| 电信商 | 举报方式 |
|---|---|
| **CelcomDigi** | 客服 IVR 内置 "Report A Scam" 选项；Celcom **019-6011111** / Digi **016-2211800**；在线 `store.digi.com.my/support/report-a-scam`、`celcom.com.my/support/report-scam`。涉及银行账户会被转介 997 |
| **Maxis** | 官方页面直接推荐装 **Whoscall** 识别诈骗电话；自建 AI 反诈防火墙 |
| **U Mobile** | 2025-12 宣布成为**全马首家在全网络层级启用诈骗防护**的运营商 |

**短信类**：收到可疑商业短信，回 `OUT` 到同一短号，并保留短信向 CFM 投诉（MCMC FAQ 原文）。

### 1.6 Semak Mule（查询库，非举报入口）

- `semakmule.rmp.gov.my` ｜ CCID/JSJK 平台
- 三个类别：**银行账号 / 电话号码 / 公司名**
- **⚠️ 号码必须用本地格式**（`0123456789`，0 开头、无连字符）。用 `+60...` 会**静默漏命中**
- **⚠️ 无记录 ≠ 安全**：新开钱骡账户还没有报案记录。官网自带免责声明

## 2. 众包平台（通报后靠用户量生效）

### 2.1 Whoscall ★ 马来西亚首选

**为什么首选**：它是马来西亚**唯一与官方库打通**的众包平台 —— PDRM 授权它整合 **CCID Semak Mule 数据库**（Gogolook 马来西亚市场总监原文）。你在官方报过案的号码，会同时出现在 Whoscall 里。

**App 内回报步骤**（官方客服原文）
```
打开 Whoscall → 首页右下角「回报」
→ 输入号码 → 填写名称与信息 → 提交
```
或：`Number lookup → 输入号码 → 点 Report`

**要点**
- 举报后**需经系统确认**，不会立刻显示标记
- 回报是**赋予号码名称与信息**（帮下一个接电话的人判断），不只是"标红"
- **Report & Reward**：回报可赚积分、解锁徽章
- **Scam SOS**：一键联系银行 + 在线报案（分地区可用）

**误标申诉**：号码被错误标记时，凭**电话账单 / 号码申请书**等持有者证明申请删除。**只能删除标记，不能修改标记**。邮箱 `service@gogolook.com`

**马来西亚官方合作**：与 PDRM 联合行动 **"Scam Free Malaysia 2025"**，免费发放 **100 万份**一年期 Premium（优惠码 `PDRMLawanScams`，活动期至 2025-08-31）。数据：2025 年前 4 个月诈骗标记来电总数同比**下降 7.6%**。

### 2.2 Truecaller

**App 内步骤**
```
搜索号码 或 点号码详情 → Block and report
→ 可补公司名 + 标签（如 sales）+ 匿名/实名评论 → 提交
```
网页端 `truecaller.com/reverse-phone-number-lookup` 查询结果页也有 block & report 选项（需登录）。

**要点**
- **需多人标记**，号码才会显示 `possibly spam` / `blocked by Truecaller`。单人举报只对自己生效
- **误报修正**：号码详情 → `unblock` / `not spam`（会降低 spam score）
- 企业向：**Truecaller for Business** 有 Spam Management 模块
- 社区反馈板：`community.truecaller.com/forums/forum/18-report-spam-scam/`
- **⚠️ 未发现 Truecaller 与马来西亚政府有本地合作**（与 Whoscall 的关键差异）

### 2.3 CallApp

- App 内标记（来电详情页举报为 spam）
- **Block Common Spammers**：可自动屏蔽"**数百万用户已举报为 SPAM**"的号码 —— 说明有用户举报机制在跑
- 支持 Block List（单个号码 / 号码段）、高级屏蔽（国际号、非通讯录号）
- **⚠️ 帮助中心未公开"如何举报"专文**，举报入口在 App 内 UI；也没有网页举报表单
- **⚠️ 合规提醒**：其非公开接口（`s.callapp.com`）的使用违反 ToS。**只做只读单点查询，不要批量抓取**

### 2.4 其他平台可用性（实测口径）

| 平台 | 举报入口 | 马来西亚覆盖 |
|---|---|---|
| **GetContact** | `getcontact.com/send-report` 表单（邮箱/电话/国家/平台/版本/主题/附件）—— **这是投诉表单，不是号码库入口** | 有用户量，但举报不直接改标签 |
| **WhoCallsMe** | `whocallsme.com/Phone-Number.aspx/<号码>` | ✅ **实测唯一有真实用户举报文本**的众包站（含马来西亚号） |
| **Tellows** | `tellows.de/basic/num/<号码>` 可提交 | ❌ **马来西亚零覆盖**（实测 5/5 空，含已知 329 次举报的号） |
| **Should I Answer** | 有提交入口 | ❌ 无马来西亚覆盖 |
| **Hiya** | App 内 | 美国为主 |
| **Sync.ME** | — | ❌ 实测端点失效 |
| **junk-call.com** | 有表单 | ❌ **页面是 SEO 模板**，非真实举报（对照实验证伪） |

| 站点 | 性质 | 能否提交举报 |
|---|---|---|

| **scamreport.asia** | 社区风险举报平台，有"十大诈骗电话号码/银行账号"榜（带警方报案数列） | ✅ 可提交 |
| **scamguards.app** | 社区数据库，`/submit` 提交（2 分钟、匿名、免注册） | ✅ 可提交 |
| **scammeralerts.net** | 反诈意识门户 | 意识宣传为主 |

## 3. 两条链路的关系（为什么 Whoscall 值得优先）

```
你向警方报案
   → 号码录入 CCID Semak Mule（官方库）
       → Whoscall 获 PDRM 授权，直接读取 Semak Mule
           → 全国 Whoscall 用户在来电时看到标记
```

**这意味着**：
- 在马来西亚，**"官方通报"和"众包通报"不是二选一** —— 走官方报案，众包侧会自动同步
- 反过来**不成立**：只在 Whoscall 回报，**不会**进 Semak Mule，警方不会知道，号码不会被封
- **最优组合**：紧急走 997 → 报案进官方库 → Whoscall 侧自动生效；若只想快速警告他人，Whoscall 回报 30 秒即可

## 4. 常见误区

| 误区 | 事实 |
|---|---|
| "打 997 之后还要去警局报案" | 2025 年 9 月起**不需要**。997 通话即报案。但 MyGovernment 页面（2026-07-31 更新）仍写"需另行报案"—— 以部长声明为准；若银行/保险要求书面报告，先问清要求 |
| "Semak Mule 可以举报号码" | 它是**查询**库。入库存只能靠**警方报案** |
| "MCMC 能直接查诈骗" | 刑事管辖在 **PDRM**（刑事法典）。MCMC 只做协助、封锁、删内容 |
| "Semak Mule 没记录 = 这号码安全" | ❌ 新钱骡账户还没有报案记录。官网自带免责声明 |
| "举报一次号码就被封了" | 众包平台需要**多人标记**才生效；官方封号需 MCMC + telco 走流程 |
| "向 Cyber999 报诈骗电话最对口" | Cyber999 是**计算机安全事件**报告点，官网原文未列电话诈骗为受理类别 |
| "号段能看出是哪家运营商" | 马来西亚 2008-10-01 起实施 **MNP 携号转网**，号段≠当前运营商 |
| "CallApp / Truecaller 网页版能举报" | 网页版是引流页，**数据与操作都在 App 内** |

## 5. 按场景的推荐动作

**场景 A：刚接到诈骗电话，没损失**
1. 挂断，不要回拨
2. Whoscall App 回报号码（30 秒，马来西亚首选，与官方库互通）
3. Truecaller 顺手也标一次（覆盖不同用户群）
4. 若冒充政府/银行/执法：`aduan.mcmc.gov.my` 提交（附截图），或打 telco 客服
5. 短信类：回 `OUT` 到短号 + 保留短信向 CFM 投诉

**场景 B：钱已经转出去了（时间就是钱）**
1. **立刻打 997**（24h）—— 通话即报案，记下编号
2. 同时打**银行 24h 反诈热线**要求资金召回 + 冻结自己账户（kill switch）
3. 保留全部证据（聊天、通话记录、假网站）
4. **不要再接任何"帮你追钱"的电话** —— NSRC 从不外呼

**场景 C：想让号码进官方库，让别人查得到**
→ 只能走 **PDRM 报案**（就近警局 / `sfrv2.rmp.gov.my` / CCID 03-2610 1559）

**场景 D：自己的号码被误标**
- Whoscall：凭账单/申请证明 → `service@gogolook.com`（只能删，不能改）
- Truecaller：号码详情 → `not spam`
