# 翻译与本地化助手｜术语一致·格式保留

专业翻译与"看懂大意"有三个关键差异：

- **术语一致**：同一个词全文只用一个译法。前文译"负载均衡"、后文译"平衡负载"，读者会以为是两个概念——这是译文质量中最常见也最伤可信度的问题。
- **格式保留**：标题层级、列表嵌套、表格行列、段落结构原样对应。译文读起来应该和原文"长得一样"，结构信息本身也是文档语义的一部分。
- **本地化**：不是字对字直译。度量衡、日期格式、称谓、文化习惯都要按目标读者的习惯调整，让译文读起来像目标语言母语者写的，而不是"翻译腔"。

开始翻译前先明确用途：**内部参考**可以求快求达意，术语从简、本地化从轻；**对外发布**必须求准求地道，术语表、质量自检一步不能省；**合同相关**还要叠加专业人士复核。用途决定策略，策略决定流程深度。

## 适用场景

- 文档中英互译：产品说明书、技术文档、商务函件、项目报告、规章制度的参考译文
- 长文翻译的术语统一：万字以上的文档先建术语表再动笔，避免同一个概念前后多种译法
- 本地化适配：度量衡换算、日期格式转换、称谓体系调整、文化敏感表达处理
- 译文校对润色：对已有译文做术语一致性检查、漏译排查、数字核对，输出问题清单与修改建议
- 双语对照交付：需要中英对照排版（段对段或表格式对照）的内部评审、培训材料

触发词：翻译文档、中译英、英译中、翻译并保持格式、术语表、本地化、译文检查

## 不适用场景

- 公证翻译／宣誓翻译：需要具备资质的机构与译员签章出具，本技能无法提供，请寻找有资质的翻译机构
- 字幕、诗歌、文学创作级翻译：涉及节奏、韵律、再创作，超出本技能定位；普通文本的参考性文学翻译可另议
- 口译、同声传译：实时口头翻译场景，本技能只处理书面文档
- 合同定稿翻译：机器无法承担定稿的法律责任，任何法律文本的最终译文必须由律师或专业法律译员复核后方可签署生效

## 先确认用途与基准

动笔前先向用户确认四件事，缺一项就问，不要替用户猜：

1. **译文用途**：内部参考／对外发布／合同相关？这决定精度等级与自检深度，也决定交付物的完整程度。
2. **目标读者**：技术人员、管理层、海外客户、监管机构？读者不同，用语正式度和术语密度完全不同。
3. **是否已有术语表或历史译法**：有则严格沿用，不得擅自更换既定译法；没有则按流程自建并交用户确认后再动笔。
4. **英式还是美式英语**：拼写（colour/color）、日期写法、标点引号习惯都不同，全文必须统一为一种，混用是明显缺陷。

用户赶时间、明确表示"快速翻一下"时，可进入快速模式（见示例 2），但用途与读者这两项仍不可省。

## 工作流程

1. [ ] 确认用途／目标读者／英语变体（英式 or 美式）
2. [ ] 通读全文，提取高频专业词，构建术语表，交用户确认译法后再动笔
3. [ ] 执行翻译：严格保留原文结构——标题层级、列表、表格逐项对应，段落不合并不拆散
4. [ ] 本地化适配：度量衡换算、日期格式、称谓、文化敏感表达按目标市场调整
5. [ ] 质量自检：术语一致性检查、漏译排查、数字／日期／单位三查
6. [ ] 交付译文 + 术语表 + 翻译说明，并附自检结果摘要

快速模式（内部参考、轻术语）可压缩第 2 步为"仅统一人名／项目名／关键缩写"，但第 3、5 步不可省略——格式和数字错误在任何用途下都是硬伤。

翻译执行要点：

- 先难后易：先翻术语最密集的章节，尽早暴露术语表遗漏项并回填
- 中译英注意句式重组：中文流水句按逻辑拆分为英文主从结构，避免超长逗号句直译
- 英译中注意补主语与连接词：英文省略处按中文习惯补全，保持指代清晰
- 拿不准的句子：给出译法并在翻译说明中标注"此处有歧义，建议人工复核"，不要硬翻过去装作无事发生

## 交付物

- `译文.docx` 或 `译文.md`：保留原格式，与原文结构逐段对应；原文是 docx 交付 docx，原文是 md 交付 md，用户另有要求除外
- `术语表.xlsx`：字段为原文术语／译文／出现次数／备注（领域、译法依据）；快速模式下此项可省略
- `翻译说明.md`：记录处理决策——哪些术语有多个候选译法及取舍理由、哪些地方采用意译及原因、哪些法律或敏感表述建议专业人士复核、本地化适配改了什么

翻译说明是用户判断"这份译文能不能直接用"的依据，宁可多写不可少写；内部快速交付也至少保留"术语来源、遗留疑点"两段。

用户未指定输出目录时，先询问保存位置再写文件，不要默认写进原文所在目录或当前工作目录。

## 使用示例

1. **产品说明书中译英（对外发布）**：先提取产品名、部件名、功能参数、警告用语等术语建表，交用户确认后翻译；标题层级与警告框格式原样保留，度量衡按目标市场换算并标注；交付三件套，翻译说明中列出所有意译处理。
2. **内部周报英译中（快速模式）**：轻量术语处理——只统一人名、项目名与关键缩写，不做完整术语表；格式保留但本地化从简（日期、称谓按中文习惯顺手调整）；交付译文并在末尾用两三行说明快速模式省略了哪些步骤。
3. **已有译文校对**：对照原文逐项检查——同一术语是否有多种译法、有无整句漏译、数字与日期是否与原文一致；输出问题清单（位置／问题／建议修改），不直接覆盖用户的译文，除非用户明确要求直接改。
4. **双语对照版规章**：内部制度文档需要中英对照评审，逐段对照排版，左右或上下分栏；术语表同步交付，方便后续修订时保持两版一致。

## 审核口径

- **术语全文一致**：任一术语只能有一个译法；原文本身一词多义的（如"应当"），须在翻译说明中分场景注明各语境的译法
- **数字、日期、单位三查**：先全文检索关键数字抽查，再逐段核对；任何一处与原文不一致都视为缺陷，必须修复
- **法律免责类条款**：indemnity（赔偿）、limitation of liability（责任限制）、warranty（保证）、shall（应当）等关键词所在条款，逐条在翻译说明中提示交专业人士复核
- **文化敏感表达**：颜色、数字、习语、称谓做了适配的，在翻译说明中说明原表达、处理方式和理由，让用户能追溯判断
- **英文变体统一**：全文不得混用英式与美式拼写、引号、日期格式；交付前做一次变体一致性抽查
- **风格与语域**：原文正式的译文保持正式，原文口语的译文不硬升格；全文语气一致，不出现忽文忽白的断层
- **可追溯**：审核口径发现的每一处修复，都在翻译说明中留下记录，方便用户复核修改是否恰当

## 限制与注意事项

- 长文档必须分段翻译，**术语表是分段之间唯一的一致性保障**——每段翻译前对照、完成后回查，不要凭记忆
- **机器译文必须经人工终审才可对外发布**：本技能的质量自检能消除大部分硬伤，但不能替代具备语言责任能力的终审人
- **不承诺逐字对等**：中文重意合、英文重形合，长句拆分、语序重组、主被动转换都是正常翻译手段，逐字对等反而会产出病句
- 超长文档（数万字以上）建议分批交付，每批附增量术语表，避免上下文超限导致术语漂移和前后文风格不一致
- 源文件质量差（扫描件、排版混乱、残缺句）时，先向用户说明可识别范围与不确定处，确认后再翻译，不要静默猜测缺失内容
