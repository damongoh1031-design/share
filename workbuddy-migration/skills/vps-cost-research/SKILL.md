# VPS 真实成本调研方法论

## 为什么需要它

VPS 定价是这个星球上最会骗人的定价之一：大字标价是「首年折后月均」，小字写着「需 3 年预付」，续费价藏在结账页，磁盘/带宽配额藏在脚注。**用户真正想知道的是"我实际要付多少钱"，而官网从不直接回答这个问题。**

## 铁律：必须核验的五件事

对每个候选方案，**缺一项就不算调研完成**：

1. **续费价**（最重要）。促销价几乎总会涨。实测案例：
   - IONOS VPS M+：$5（仅前 3 个月）→ **$14**（+180%）
   - Hostinger KVM 1：$6.49 → **$11.99**（+85%）
   - 腾讯云 4核4G 秒杀 ¥38/年 → **无同价续费套餐**，次年按原价
2. **预付年限**。看到 "as low as" 或 "from" 就去点订单链接看 `billingcycle` 参数。Exabytes 的 RM45/月实际是**3 年预付**折算。
3. **机房城市**（不是国家）。很多"马来西亚 VPS"实际路由到新加坡。必须看官方是否列出具体城市名。
4. **流量配额与超额限速**。OVH 亚太区 VPS-1 标"不限流量"，但脚注写着**月配额 500GB，超额限速 10Mbps**。
5. **含税口径**。马来西亚 SST 8%、德国 VAT 19%、Hetzner 官网是净价。**本地商反而可能因超过 RM500k 门槛必须代收 8%，比小国际商更贵。**

## 统一口径再比较

- **年付价一律折算月均**（`年价 ÷ 12`），否则年付商看起来贵得离谱。
- **标明汇率假设**（写进报告里，别让用户猜）。
- **区分"标价"与"实付"**：含税、含 IPv4、含设置费之后才是实付。
- 输出表格列固定为：`vCPU | 内存 | 磁盘 | 流量/带宽 | 折月价 | 续费价 | 机房 | 风险备注`

## 抓取技巧（踩过的坑）

- **JS 渲染的定价页抓不到数字**：Hetzner `/cloud/`、VMRack `/pricing`、LightNode `/pricing`、阿里云定价页。→ 改用第三方核价文章交叉验证，并**在报告里注明"该数字来自第三方、未从官网直取"**。
- **官网 404 的定价页**：RackNerd `/pricing/`、`/cheap-vps/` 都 404 → 价格只能从第三方汇总页拿。
- **年付特价常放在独立 store 子路径**：DediRock 首页只显示月付（$12.99），便宜的 4GB 年付档（$54.99/年）在 `billing.dedirock.com/index.php/store/the-i9-dream`。**首页看到的价格未必是最便宜的档。**
- **LowEndTalk `categories/offers/` 列表页是超低价年付圈最实时的一手行情**——帖子标题里直接写规格+价格。
- **机房城市列表常在非定价页**：RackNerd 的 12 个机房城市写在 `racknerd.com/kvm-vps` 正文里，定价页没有。
- **国内云厂商的"境外"档是隐藏性价比点**：腾讯云轻量"境内"和"境外"价格相同但配置不同，境外含新加坡/东京/首尔/硅谷/法兰克福。**做东南亚/海外部署时优先查这个。**
- **测评博客比官网更完整**：国内云厂商的活动规则藏在细则里，51CTO / CSDN 的实测文反而把配置和续费规则写全了。
- **知乎文章 WebFetch 可直抓正文**，但正文里大量 `zhida.zhihu.com/search?...` 内联链接会污染输出，需人工过滤。

## 判断来源质量

- **联盟营销识别**：链接带 `aff=` / `ref=` 参数就是推广内容。**实测：一篇给某厂商满分并排第一的知乎文章，通篇没写价格，而该厂商实际比国际商贵 2.3 倍。** 排名与佣金相关，与价格无关。
- **警惕"行业基准"数字**：有文章称"新加坡主流 2核4GB = $15–30/月"，但同期 Vultr/Linode 是 $20–24，年付商能压到 $5。**基准区间被刻意挑高，用来衬托它推的方案。**
- **区分事实与预测**：数据中心"规划中/预计投运"不等于已运营。

## 延迟与地域

- 查延迟用 WonderNetwork（有具体城市实测页，如 `/pings/Kuala%20Lumpur`）、CloudPing、厂商 looking glass。
- **关键洞察（东南亚）**：吉隆坡↔新加坡 RTT 仅 **6–10ms**，柔佛↔新加坡 2–8ms——**"优先东南亚"实际等于"新加坡机房"**，不需要为本地机房付溢价，除非有数据驻留/行业监管硬要求。
- 参考值：KL 本地 1–5ms｜新加坡 6–10ms｜雅加达 20–30ms｜香港 37.8ms｜曼谷 58.7ms｜东京 75–90ms｜美西 180–220ms。

## 回答"本地厂商会不会更便宜"

**结论通常是"更贵"，且能给出倍数和成因。** 结构性原因：
1. **带宽成本**：非一级枢纽的本地 transit 要回程到枢纽（新加坡 100G IP transit 中位价 $0.26/Mbps，亚太最低），叠加 ISP 寡头。
2. **规模与电价**。
3. **产品形态**：本地商主卖 managed + cPanel，不是裸 VPS，同内存档可贵 10–15 倍。
4. **税**：本地商超门槛必须代收数字服务税，反而有劣势。

## 反向建议（最容易被忽略、但最有价值）

**当用户主动降配省钱时，先算一下降配到底省多少。** 实测：腾讯云轻量境外 2核2G ¥99/年 vs 2核4G ¥199/年——**一年只差 ¥100（$14）**。为省每月 $1.17 牺牲一半内存和全部余量，不划算。**在年付商上降配几乎省不到钱；只有在按小时计费的主流云上（Vultr 2GB $10 vs 4GB $20）降配才真省一半。** 这条结论多次直接改变了用户的决定。

## 资源可行性核算（自托管应用）

判断某配置能否跑某个应用时：
1. 找**官方文档**的单项数值（如 Open WebUI 嵌入模型约 500MB/worker、Whisper 约 500MB、SQLite 默认 512 连接 × 约 64MB 页面缓存）。
2. **逐项相加**：系统 + 运行时 + 各应用 + 反向代理。
3. **明确标注这是工程估算，不是同机实测**，并给出验证命令（`docker stats`、`free -h`）。
4. 注意官方数字的**版本时效**：Open WebUI "调优后约 200MB" 来自 v0.3.10，当前 v0.8.x 更重——必须标注这一点。

## 当用户问「买硬件（SBC / 迷你主机）替代 VPS」

这是同一个问题的另一条路径（"我实际要付多少钱"），但要换一套框架。

### 先拆三个门槛，别急着列型号

**① 公网 IP / CGNAT —— 能绕过，不是障碍。**
马来西亚实测：Unifi 大多是大内网 IP、NAT 严格；TIME 通常可申请公网 IPv4。但**根本不用靠运营商**——Cloudflare Tunnel 免费、不需公网 IP、自动 HTTPS、隐藏源站。只给自己用则 Tailscale。**结论：CGNAT 不该成为买不买的决定因素。**

**② 上传带宽 —— 基本不是问题。**
Unifi 1Gbps 上传约 500Mbps（非对称），TIME 对称 1Gbps。**文本类应用（如 Open WebUI）的真正瓶颈是 LLM API 响应速度，不是上传带宽。**

**③ 可靠性 —— 这条绕不过，也是与 VPS 最本质的差异。**
VPS 挂了厂商负责；硬件挂了你自己负责。故障源：停电、ISP 故障、SD 卡磨损、电源老化、**家人拔插头**、人在外地无法处理。
**最关键：如果监控（Uptime Kuma）也放在同一台机器上，机器挂了它自己也死了，你收不到任何告警——一片安静。**

### 铁律：ARM SBC 的内存是焊死的，这是 2026 年的决定性差异

**2026 年正在经历 DRAM / LPDDR4 涨价潮。实测：树莓派已连涨三轮**——2025-10 提价 5–10 美元；2025-12 再涨并新推 1GB 版（变相降配）；**2026-02 第三轮：2GB +$10、4GB +$15、8GB +$30、16GB +$60**；2026-07 因 LPDDR4 再调价。

**买 ARM SBC，内存涨价成本 100% 由用户承担且无选择。买 x86 迷你主机，内存走标准 DDR4 SO-DIMM 插槽——可用闲置内存、可二手淘、可先 4GB 后加。**

### 同价位 x86 迷你主机全面优于 ARM SBC（用于服务器场景）

| 理由 | 说明 |
|---|---|
| **内存可换可升级** | 见上。这是最有价值的一条 |
| **x86 原生兼容** | Open WebUI 有 arm64 镜像，但**周边工具链**（1Panel 应用商店、各类 exporter、小众工具）arm64 常缺失或滞后；**99% 的教程和报错答案都假设 x86** |
| **存储** | x86 迷你主机通常有 M.2 NVMe + SATA；ARM SBC 靠 eMMC/SD 卡。**SD 卡跑 SQLite 是灾难**（会磨损、突然损坏、丢数据） |
| **总账** | SBC 标价是裸板价，还要另买电源（必须官方规格，手机充电器会降频损坏）+ 散热 + 外壳 + 存储 + UPS，额外 ¥340–980，**常超过板子本身** |

**N100 实测行情**：准系统闲鱼 480–550 元、整机 950–1300 元、双 2.5G 网口版约 510 元；待机 5–7W、满载 <20W；单通道 DDR4 笔记本内存槽（8G 约 180 元、16G 约 380 元、128G SSD 约 88 元）。
**二手 8 代 i5 迷你主机（联想 M710q/M720q、戴尔 OptiPlex Micro、HP ProDesk Mini）4GB/8GB 仅 ¥300–600**，4核8线程，多线程强于 N100——**比任何 4GB ARM SBC 都便宜且更快**，代价是功耗 15–35W、成色水深。

### TCO 对比要给「3 年总账」，并说清 SBC 不省钱

实测对比（马来西亚场景）：VPS 腾讯云轻量境外 2核4G ¥199/年 × 3 = **¥597**；N100 全套 ≈¥760。**SBC 贵约 27%。**

**那为什么还买？因为买到的东西不同**：数据自己掌握、无续费陷阱、无需实名、可跑本地模型、硬件可复用、无月费焦虑。**要打平需用 4–5 年以上。** 只想先跑起来试试 → VPS 更省事。

### 电费核算（马来西亚 TNB，别凭感觉估）

半岛家庭电价自 2025-07-01 起改为 RP4 四项结构（适用至 2027-12），**旧五段阶梯已废除**：能源费 27.03 + 容量费 4.55 + 网络费 12.85 = **44.43 sen/kWh**（1,500 kWh 及以下；超过则能源费变 37.03）；零售费 RM10/月；AFA 每月重算（2026-09 = +3.67）。
**三条豁免线**：≤600 kWh 免零售费 + AFA + 8% 服务税；≤300 kWh 再免 1.6% KWTBB。
**节能奖掖 EEI（关键）**：按全月用电量所在档位取一个费率乘以**全部**用电量——1–200 kWh 档 **−25.0 sen/kWh**、251–300 档 −22.5、551–600 档 −9.0、901–1000 档 −0.5、>1000 无。

**⭐ 必须算「边际电价」而不是标称费率** —— 这是最常被算错的地方：

| 家庭月用电 | 边际电价（每多 1 度） |
|---|---|
| ≤300 kWh | **≈22 sen/kWh** |
| ≈400 kWh | ≈27 sen |
| ≈600 kWh | ≈36 sen |
| >600 kWh | **≈48–52 sen**（AFA + 8% 服务税 + KWTBB 同时生效） |

→ **同一台服务器，低用量家庭和高用量家庭电费差一倍多。** 报价时必须给多档，别只给一个数。
→ 换算公式：**年 kWh = 瓦数 × 8.76**；一台 10W 设备 ≈ 87.6 kWh/年 ≈ RM 19–42/年（视档位）。
→ **TNB 官方账单对照**（可直接引用）：100 kWh→RM19.43；200→RM38.86；300→RM65.79；600→RM215.98；1000→RM509.01；1500→RM777.84。
→ **⚠️ 600 kWh 悬崖**：超 1 kWh 账单从 RM215.98 跳到 RM258.10（**+RM42.12**），三项豁免同时失效。

**省电的真实杠杆**：1.0 HP 冷气约 750W，**开 1 小时 = 服务器跑 28 小时**。要省电费该动空调，不是动服务器——这个对比能有效纠正用户的关注点。

### 电费对比：常见机型的实测功耗（同口径）

**横向对比优先找「同一测试台测多台机器」的评测**（如 LinuxLinks 的 SBC 功耗系列），比拼凑各家数字可靠得多。

| 机器 | 无头待机 | 轻载 | 满载 |
|---|---|---|---|
| Ryzen 5 5600G 整机（MatX） | **27 W** | 28–37 W | 65 W（CPU 封装）/ 整机 100–130 W |
| Intel N100 迷你主机 | 6.5–12 W | 12.9 W | 20–30 W |
| Raspberry Pi 5 | **3.5 W**（关机仍 1.7 W） | 4.9 W | 8.8 W（极限 16 W） |
| Orange Pi 5 Max (RK3588) | **2.4 W** | 3.9 W | ≈18.7 W |

**三个必须讲清的点**：
1. **N100 的「6W TDP」是 CPU 封装散热预算，不是整机墙上功耗。** 实测整机 8–12W，因为内存/NVMe/网卡/风扇/电源适配器损耗全部另算。
2. **ATX/MatX 平台有物理待机下限，降不到 N100 水平。** 5600G 待机 27W 里 **CPU 封装只占 3–5W**，其余是主板 VRM(6–9W)、2 根 DDR4(3–6W)、SSD、机箱风扇、**ATX 电源转换损耗(4–7W)**。N100 用 19V DC 直供 + SoC 一体化 + 焊死 LPDDR，这些损耗项根本不存在。
3. **⚠️ 限 PPT / Curve Optimizer 不能降低待机功耗**（只影响满载）。**换 GE 低功耗版 CPU 待机也几乎不变**——别给这两个建议。

**有效的降电费手段**（合计省 5–8W）：关机箱风扇(+2~3W)、内存降回 JEDEC 1.2V(+1~2W)、BIOS 开 C-states/ASPM、关 Wi-Fi/蓝牙/音频、换 80PLUS 金牌电源(省 2–4W)、`powertop --auto-tune`。

**「每瓦性能」反转结论**：N100 用 1/3 待机功耗换 1/3 性能；Pi 5 用 1/8 功耗换 1/7 性能 → **三者能效比基本持平**。SBC 省电只是因为它算得少，不代表更先进。

**已有硬件时不要建议换机**：把「省下的电费」和「换机成本」相除算回本周期。实例：5600G 换 N100 每年省 RM 37–80，硬件 RM 590–810 → **回本 7–22 年**，超过机器服役年限。**结论应是「什么都别买，只做免费调优」。**

### 硬件方案必备清单（必须写进交付物）

1. **电源**：必须官方规格（如 5V/4A），别用手机充电器
2. **电压**：马来西亚 240V vs 中国 220V → **选 100–240V 宽压适配器**，只需换英标(G型)插头；廉价 220V-only 在 240V 下可能烧毁
3. **存储优先级**：M.2 NVMe > eMMC > SD 卡
4. **UPS**：强烈建议，防断电损坏数据库
5. **BIOS 设 AC Power Loss = Power On** —— 否则停电恢复后机器不自启，而用户不在家
6. **公网访问**：Cloudflare Tunnel（绕开 CGNAT + 80/443 封锁）

### 价格可信度（务必诚实标注）

**淘宝、京东商品页需登录且价格由 JS 动态加载，抓取必然失败**（京东返回空白价格区或"已下柜"）。SBC 价格只能基于官方活动公告、第三方评测引用和同类行情做**数量级估算**，必须明确标注"非实时抓取价，下单前自行核对"。**绝不要编造精确价格。**

**电价类查证必须两个独立来源交叉**：大量马来西亚电价文章未更新到 RP4（实例：trexon.my 2026 年仍在用旧的五段阶梯 21.8/33.4/51.6/54.6/57.1 sen）。SolarCompare.my 与 calculatormalaysia.com 两个来源一致给出新结构，后者还明确提示「旧五段表已废除，任何还在用它的计算器会把 300 kWh 账单**高估约 17%**」。**最终以 myTNB 官方账单为准。**

**汇率要标注**：CNY→MYR 约 0.62（2026-10），换算结果需注明是估算。

## 交付物格式

- 深色主题自包含 HTML 报告（用户环境是 dark theme）。
- 结构：结论卡（3–4 张）→ 延迟/地域表 → 全量对比表（按折月价排序）→ 可视化条形图 → 陷阱清单 → 具体建议 → **来源与核验说明（含"未核实"项与数据局限）**。
- **必须诚实标注数据缺口**（"官网 JS 渲染未取到，标记为未核实"），而不是编一个数字填上。
