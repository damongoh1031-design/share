# 六维加权评分模型 · 细则与基线

## 一、模型定义

### 六个维度（5 分制，5 = 同级最优，3 = 行业中位，1 = 明显不合格）

| # | 维度 | 权重 | 5 分的含义 | 关键判据 |
|---|---|---|---|---|
| ① | **WiFi / 流媒体** | 15% | 环球航次**免费赠无限 Premium**，官方明确支持 streaming + 多设备 | ① 基础档能否流媒体 ② 目标航次有无免费升级 ③ 几台设备 ④ 是否 Starlink |
| ② | **舱房大小与性价比** | 20% | 面积同级最大 **且** 每人每晚单价同级最低 | 面积口径（含阳台？）+ 是否套房 + 浴缸/衣橱 + **每人每晚** |
| ③ | **美食丰富度** | 20% | 特色餐厅多、**全免费、无配额**、菜单轮换 | 餐厅**数量** + 免费范围 + **配额** + 近期口碑 |
| ④ | **船上节目** | 20% | 每晚多场百老汇式驻船秀 + 顶级讲座 | 剧场座位数 + 制作秀数量与**频率** + 讲座规格 |
| ⑤ | **船上观景** | 15% | 环绕甲板/全景观景厅 **且** 航线有 4+ 天命名风景巡航 | **硬件分 × 航线风景内容分** |
| ⑥ | **生活便利** | 10% | 免费自助洗衣 + 酒水/小费已含 + 自由入座 + 无正装夜 + 无排队 | 洗衣 + 座次 + 着装 + 客流 + 航次礼包 |

## 四、单价口径对齐（比单价前必做）

### 四个必须统一的变量

1. **舱位等级**：起价通常对应最低房型（内舱或海景），**不等于阳台房价**。Oceania 的 $76,199 是「每人起价」，阳台房实际更高。
2. **含税口径**：Seabourn 2028 的 $77,999 标「含 all taxes, fees」，2027 的 $89,999 未标。
3. **币种**：Cunard 英镑 / HAL 美元 / Oceania 美元 / Seabourn 美元。**报告必须写明汇率假设。**
4. **已含礼包**：见下。

### 名义单价 → 净单价

| 船 | 名义每人每晚 | 已含礼包 | 估算净单价 |
|---|---|---|---|
| **Seabourn Quest** | 🚨 **$621** | ✅ 商务舱机票 + 酒店 + 专车 + 行李递送 + $10k OBC + 无限洗衣 + 流媒体 WiFi（约值 MYR 8–12 万/2 人） | ✅ **约 $380–450** |
| Crystal Serenity | $548 | 酒水 + 小费 + 洗衣 + 商务舱补贴 $1,500/人 + $1,500 船上消费金（**❌ 不含岸上游与机票**） | ~$520 |
| Oceania Vista | $423 | 小费 + 特色餐厅 + 免费洗衣 + 全环球 Prestige（无限酒水 + 签证 + 行李） | ~$420 |
| Silver Dawn | ~$521 | 酒水 + 小费 + 洗衣 + 全套房管家 | ~$500 |

> **⚠️ 但「净单价」的前提是「你确实会用到那些礼包」。** 若客户另有里程票、不需要专车，Seabourn 的性价比优势就消失了。

### 每人每晚公式

```
每人每晚 = 每人起价 ÷ 总晚数
```

## 五、评分纪律（四条）

1. **每一维都要能指出「扣分的那一条具体事实」**。不能凭印象给分。
2. **深研后必须回改预判分，并写明修正原因。** 本项目 15 艘中 7 艘分数发生显著变化（Crystal Serenity / Cunard Queen Anne / Oceania Vista / Star Princess / **Viking Vesta** / **Coral Princess 3.50→3.65** / **Cunard Queen Victoria 3.60→3.68**）。
3. **同分不代表同适合**。必须附「破平局表」（见上文关键事实表）。
4. **前置条件不满足时，分数没有意义**。第 ⑦ 条优先于一切。

## 六、工具

`scripts/score.py` —— 输入六维分数与权重，输出加权总分与排名；并可选检查「母国停靠」前置过滤。

```bash
python scripts/score.py --scores "4.5,4.0,4.0,3.0,4.0,5.0" --name "Seabourn Quest 2027"
python scripts/score.py --file ships.csv          # CSV: name,wifi,cabin,dining,show,view,conv,home_stop
python scripts/score.py --weights "20,20,20,20,10,10" --scores "..."
```
