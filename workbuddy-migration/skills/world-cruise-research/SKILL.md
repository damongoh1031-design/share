# 环球邮轮深度调研方法论

## 为什么需要它

邮轮是「一次性大额、信息极不对称、营销话术密度极高」的消费品。一艘船 140–244 晚的环球航程，2 人总价常在 **MYR 55 万–110 万**，而官网给的信息量远不足以决策：

- **「World Cruise」是营销名，不保证绕地球一圈**。已核实：Crystal Serenity 2027 全程不出太平洋；Seabourn Quest 2027 是「迈阿密往返的太平洋环线」，连地理环球都不成立。
- **「All-Inclusive / 全含」至少要拆三层**：标准票价、加购套餐、航次专属套餐。同一家船，「买全程」与「买分段」的含金量可能完全不同。
- **「免费特色餐厅」要追问「免费几次」**。Oceania 入门房 4 家特色餐厅**各只能吃 1 次**（244 晚也一样）；Crystal 139 晚里 Umi Uma / Osteria 各只免费 3 次。
- **舱房面积口径不统一**（含阳台 vs 不含阳台），差 30% 以上；**同一房型名不同子类面积相同但价差可达数千美元**。
- **船公司财务好 ≠ 品牌健康**。Carnival 财务是行业最强（S&P BBB- 投资级），但 Seabourn 品牌正在连续卖船且无新船订单。

因此**「客户真正想知道的是『我实际要付多少钱、实际会过上什么日子』，而官网从不直接回答」**。

## 何时使用

触发信号（任一即可）：

- 「深度研究 XXX 邮轮」「以 {船名 + 年份} 为主题，深入研究所有资讯」
- 「对比这几艘船的环球航线」「哪艘最值得买」
- 「船上生活好不好」「WiFi 能不能看流媒体」「舱房够不够大」「吃得丰富吗」
- 「价格划不划算」「我实际要付多少钱」
- 用户已给出偏好权重（如「船上生活优先」），需要按权重重算排名
- 需要**单船全维度报告**或**多船横向评分排名**

**不适用**：单程 7 天以内的短航次（信息量不足，直接查官网即可）、纯价格查询。

## 第 0 步（不可跳过）：锁定客户画像

**评分模型完全依赖客户画像，画像错了整份报告都错。** 开工前必须确认或明确假设：

| 要素 | 为什么要问 | 本项目实例 |
|---|---|---|
| **国籍 / 护照** | 决定签证门槛，且**决定「是否停靠母国」这条前置过滤** | 马来西亚 → 申根免签但**美国要 B1/B2**；**马来西亚停靠是决定性变量** |
| **人数与关系** | 影响舱房选择与「设备数」判断 | 2 人情侣 → WiFi 设备数按 2 人算 |
| **计价币种与汇率** | 报告里必须写明汇率假设 | **MYR，1 USD ≈ 4.09**（2026-10） |
| **优先级排序** | 决定权重，直接决定第一名是谁 | 从「奢华全含」转向「**船上生活优先**」 |
| **航程长度偏好** | 影响「海上日绝对天数」的容忍度 | 140–244 晚 |

> ⚠️ **若客户未明确优先级，先用默认权重出结果，并在报告里附「权重调整后的第一名会变」的对照表**——这比追问更快，也更有说服力。

## 第 0.5 步（2026-10-07 新增）：先做「船队时效核查」

> **为什么必须加这一步**：2026-10-07 用户指出「有几艘新船没有记录到，比如 Silversea 的」。核查后发现，我们做了 8 轮单船深研、细节很扎实，**却漏掉了 9 艘新船**——因为**单船深研是「按船查」，没人负责「按公司查船队」**。详见 `references/pitfalls.md` 第九类（**坑 40–64**，含跨品牌通则：餐厅名张冠李戴 / 氢燃料电池误报 / 「新船更大」不成立 / 「全含」冠军误判 / 票制会改 / **被宣传但从未交付的旗舰设施** / **第三方资料落后于船的翻新** / **品牌旗舰卖点被安到姊妹船上** / **官网「天数」口径 ≠ 过夜数** / **品牌的「未来技术」被安到现役船上** / **「亚洲母港」被误当成「中文服务」** / **品牌的中国母港标准不能推定适用于环球船** / **票价与 WiFi 方案会静默改版，必须核对生效日期而非当前页面** / **老船跨品牌调配是可预测的品牌风险** / **「全含」不含岸上游与机票，边界必须逐项核实** / **同航次双口径晚数源于行程改版** / **奢华线「World Cruise」可能完全不出太平洋** / **重生品牌的权益在完整航程与分段间差异巨大** / **同港口来源时间冲突应判为排期错误** / **翻新≠重建，「老旧评价」有保质期**）。

**触发信号**（任一即可，不必等用户提）：
- 用户说「资讯是不是最新的」「有新船吗」「XX 公司现在有哪些船」
- 距上次核查 **超过 6 个月**
- 报告要覆盖**下一年度的环球航次**（执行船每年可能换）

**做法：三路并行**（与第 1 步的四路独立）

| 路 | 负责范围 |
|---|---|
| **甲** | **目标公司全船队**：在役逐船（船名/级别/交付年/GT/载客/船员）+ **已售/已移交品牌**的船 + **在建与已下单**（船名/船厂/交付期/GT/载客） |
| **乙** | **同层级其他公司的船队与在建**（奢华线 / 主流线各一遍）—— 用于横向可比 |
| **丙** | **下一年度环球航次由哪艘船执行**（逐公司逐年核实）+ **品牌归属变动**（母公司新闻稿/投资者关系页） |

**必须遵守的三条**：
1. **船厂新闻稿是最可靠的新船来源**（Fincantieri / Meyer Werft / Chantiers de l'Atlantique），比船公司自己的页面更新得快。
2. 🚨 **「官方行程页没列某港口」≠「不停靠」，但也不能当「有停靠」**——二手汇总的停靠港**一律标「未核实」**。
3. 🚨 **「新船」不等于「更好的环球船」**：实测 **2027/2028 没有任何一条环球航次由全新船执行**；且 **Silversea Nova 级取消了传统环绕甲板**，对「观景」维度是**减分**。

**产出**：把结果写进 `references/verified-facts.md` 第六节（船队时效清单），并回改所有受影响的交付物。

## 第 1 步：四路并行调研（单船标准动作）

**每艘船固定派 4 个独立调研 agent 并行**，各自只做一块、互不越界。这样能避免单点来源偏差，且便于交叉验证。

| 路 | 负责范围 | 必须产出的关键项 |
|---|---|---|
| **A** | 规格 / 舱房 / 公共设施 / 基本福利 | 船级、吨位、载客、客员比、船旗、**最近一次干坞翻新时间与内容**；全部房型面积；WiFi（档位 / 是否支持流媒体 / 设备数 / 价格）；酒水 / 小费 / 自助洗衣是否含 |
| **B** | 餐饮 / 船上节目 / 票价包含政策 | 完整餐厅清单 + 是否免费 + **配额**；剧场座位数；驻船制作秀数量与频率；讲座项目规格；票价包含的三层结构；座次与着装（**是否有正装夜**） |
| **C** | 航线 / 海上天数 / 天气 / **停靠港（尤其客户母国）** | 🚨 **先核实「哪艘船执行」这个前提**；航次名、总晚数、出发/结束港、是否往返；**是否地理环球**；分段清单；风景巡航逐项；海日总数/占比/最长连续；**客户母国与邻国停靠**；改线风险；逐月天气 |
| **D** | 价位 / 社区口碑 / 公司财务 / 客户国注意事项 | 每人起价（USD + MYR）、每人每晚、房型阶梯、隐性成本；Cruise Critic 编辑+会员、TripAdvisor、cruiseline.com、Reddit；**近 2 年是否有品质下滑讨论**；母公司财务与评级；**品牌自身的船队/新船动向**；签证 / 疫苗 / 保险 |

**并行要点**：
- 四路 prompt 都必须写明**客户画像与汇率**，否则 agent 无法换算。
- 四路都必须要求**标注来源可信度**，并要求**「遇到冲突把双方都列出来，不要擅自选一个」**。
- 四路都必须要求**明确列出「查不到 / 未核实」的项目**——**这比编一个数字有价值得多**。

## 第 2 步：客户最常问的 14 个维度（单船报告骨架）

这是本项目 10 艘船反复验证过的模板，**报告章节按此排布**（实测约 22–24 章）：

1. 价位（含房型阶梯 + 每人每晚 + 2 人合计）
2. 设施
3. 船上节目
4. 餐厅与食物内容
5. 房间（面积 / 配置 / 定价陷阱）
6. 下船景点
7. 航线景点
8. 航线经过哪里
9. 在海上多少天
10. 路线怎样走
11. 天气
12. 整体体验
13. 注意事项（**客户国专章**）
14. 社区 / 用户回馈

**追加的三项（本项目演化出来的，价值很高，建议默认包含）**：

- **基本福利专章**（WiFi / 酒水 / 小费 / 洗衣）——客户的第一优先项，且**最容易被二手资料写错**。
- **公司稳定性专章**（破产时间线 / 收购方 / 信用评级 / 杠杆 / 到期债 / 新船订单）。
- **开篇「关键修正」专章**——把本轮推翻的上一轮结论**写在最前面**，不要藏在文末。
- **⭐ 独特卖点专章（2026-10-07 新增）**——客户常直接问「它有什么独特卖点」。**必须把卖点分成三类，不要混为一谈**：
  1. **真首创**（有独立来源证实，如「全球首艘 X」需船厂新闻稿用现在时确认）
  2. **真差异化**（不一定是首创，但确实与同级不同，如「每间套房配管家」）
  3. **❌ 营销话术 / 被误传**（如「氢动力邮轮」实为预留设计；「空间比全球第一」实为品牌内第一）
  > 🚨 **这一章的价值恰恰在于第 3 类。** 实测 Silver Ray 的「氢燃料电池」被多家专业媒体误报为已实现；「Otium 是 Nova 级独创」也是错的（首发于 Silver Dawn，全船队项目）。**不做这个区分，报告就只是官网宣传的复述。**
- **🆕 中文语言环境专章（2026-10-07 新增）**——当客户是**华语旅客**（中国大陆 / 台湾 / 香港 / 马来西亚 / 新加坡华人）时必做。🚨 **必须拆成三层评估，不能笼统问「有没有中文服务」**：
  1. **第一层 官方语言服务**：中文船员/礼宾、中文日报与菜单、中文娱乐、中文岸上游（⚠️ 官方普遍不公开，大量「未取到」是正常的）
  2. **第二层 社交语言环境**：**同船旅客语言构成 + 船员实际中文能力**（🚨 **最重要，也最难查** —— 「有中文菜单」不等于「有人跟你讲中文」）
  3. **第三层 渠道语言**：订舱、客服、行程文件（✅ 最容易查，**也最容易误导**）
  > 🚨 **三条必须建立的识别原则**：① **「有中文官网」≠「船上有中文服务」**（只证明销售能力）；② **「亚洲餐厅」≠「中餐」**（多为西化融合菜）；③ **「日文服务」≠「中文服务」**（日本母港船官方语言是日文）。
  > 🚨 **本项目实测结论**：19 艘欧美系环球船里，**第一层全部为「无」或「未取到」**；只有 MSC / Viking 有完整中文渠道，且**都绑定在中国母港船 / 中国合资船上，不覆盖跑环球的那艘船**（见坑 56）。
  > ⚠️ **对马来西亚/新加坡华人客户**：他们的**生存层**（点菜、问路）通常没问题（英语可用），**真正的短板是社交层** —— 长航程客群以欧美为主，讲座/酒会/餐桌闲谈全英语，隔阂体现在「归属感」而非「点菜」。

## 第 3 步：六维加权评分模型（+1 条前置过滤）

### 权重（默认，可调）

| 维度 | 权重 | 为什么 |
|---|---|---|
| ① WiFi / 流媒体 | **15%** | 长航程刚需，但只影响「能不能用」 |
| ② 舱房大小与性价比 | **20%** | 每天待 10 小时以上；「面积 × 天数」是巨大差异 |
| ③ 美食丰富度 | **20%** | 140+ 晚要吃约 450–730 顿，菜单重复是长航程第一大抱怨 |
| ④ 船上节目 | **20%** | 海上日占比 30–64%，这是「会不会腻」的决定因素 |
| ⑤ 船上观景 | **15%** | 被动享受，但决定「每天醒来想看什么」 |
| ⑥ 生活便利 | **10%** | 是乘数不是加数——不便利会被长航程放大 |

### 🚨 第 ⑦ 条：**停靠母国 —— 这是前置过滤条件，不是加分项**

**这是本项目最重要的一条方法论修正。**

已核实：**Seabourn Quest 2027 / 2028 全程零马来西亚、零新加坡、零亚洲停靠**，而它的六维得分并不低（3.98）。**分数高 ≠ 适合客户。**

> **正确用法**：把「是否停靠客户母国 / 邻国」当成**第一道闸门**，先过滤掉不满足的，再在剩下的里比分数。
>
> **为什么重要**：它同时决定三件事——**家人能否上船探访**、**能否中途上下船（分段）**、**能否顺路回国**。
>
> **建议**：**每份单船报告固定输出「停靠母国对照表」**，并在评分报告里单列这条前置条件。

### 输出格式

排名表列固定为：`排名 | 船/航线 | ①WiFi | ②舱房 | ③美食 | ④节目 | ⑤观景 | ⑥便利 | 加权总分`

并在报告里附 **「把某一项权重提到最高时，第一名是谁」** 的对照表——**结论一定会变**，这是最有说服力的交付方式。

详细评分细则、权重调整表、15 艘已评分船基线见 `references/scoring-model.md`。
可用 `scripts/score.py` 直接算加权分。

## 第 4 步：判断来源可信度（分级 + 黑名单）

### 分级

| 标注 | 含义 |
|---|---|
| ✅ | 官方 / 多源已核实 |
| ⚠️ | 单一来源或存疑 |
| ❌ | 已证实为错误 |
| 🚨 | 高风险提示 |

### 优先级

**官方 > 维基百科 / CruiseMapper / CruiseDeckPlans > 主流邮轮媒体 > 旅行社代理页 > 论坛 > 内容农场**

### 🚨 邮轮领域的低质 SEO 内容农场黑名单（一律标 ⚠️，且不可作为唯一依据）

`cruisezoom`、`nauticalflock`、`cruisebooking`、`360Cruising`、`cruiseprodigy`、`travelvient`、`ticketing-info`、`specrizy`、`guidebookbali`、`cruises.to`、`oceaniacruisesale`、`cruiseping`、`cruiselobster`、`cruiselookup`

### 三条实战判据

1. **「官方 FAQ 优先于第三方甲板图」**：实测 CruiseMapper 称 Seabourn Quest「无自助洗衣设施」，与官方 FAQ「有免费 launderette」直接矛盾 → **以官方为准**。第三方甲板图在「设施有无」这类问题上不可靠。
2. **联盟营销识别**：链接带 `aff=` / `ref=` 参数即推广内容，排名与佣金相关、与事实无关。
3. **页面被 JS 反爬时不要放弃**：Cruise Critic 会员评分 / TripAdvisor / cruiseline.com 常抓不到 → **明确标为「未取到」**，不要用第三方转述替代。

## 五条铁律（缺一项不算调研完成）

1. **先核实「哪艘船执行这个航次」**。同公司同名航次跨年份可能是完全不同的船与航线（Seabourn：2026 是 Sojourn 129 天、2027 是 Quest 145 天、2028 是 Quest 约 120 天，三条毫无关系）。
2. **核实「是否真的地理环球」**，而不是只看有没有「World Cruise」这个词。问：出发/结束港是否同一城市？最远到哪？是否绕地球一圈？
3. **把「全含」拆三层**：标准票价 / 加购套餐 / **航次专属套餐**。并确认**分段购买是否享有专属套餐**。
4. **把「免费餐厅」追问成「免费几次」**，把「免费 WiFi」追问成「能不能流媒体 + 几台设备」。
5. **区分「公司风险」与「品牌风险」**：母公司财务强 ≠ 该品牌健康。

## 交付物格式

- **中文** Markdown 报告，单船约 **22–24 章、40–55 KB**；文件命名 `{船名}_{年份}_单船深度研究.md`。
- 开篇固定为 **「开篇必读：N 处关键修正」**，把本轮推翻的结论写最前面。
- 全文逐项标注 ✅ / ⚠️ / ❌ / 🚨；**冲突原样并列**；**末尾固定「数据冲突与未核实清单」**。
- 结尾固定 **「给你的三条行动建议」**（含「订舱前必须书面确认的 5 件事」）。
- 多船对比时，另出一份 **评分与推荐报告**，并**每次单船深研后回改该报告**（保持单一事实来源）。
- 可用 `show_widget` 出 2 张图：① 关键数据卡 + 分维度条形图；② 航线结构 SVG 图（含母国停靠与改线风险标记）。
