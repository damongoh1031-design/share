# Rovos Rail（非洲之傲）全面介绍

**Pride of Africa · 世界最豪华列车之一** · 调研更新：2026-10-13

> **一句话定位**：1989 年由 Rohan Vos 创立，用修复的**爱德华时代木镶板车厢**跑遍南部非洲 12 条线路。全车 **36 间套房 / 最多 72 客**，**着装正装**（区别于金鹰的休闲），**野味餐**是招牌。短线 2 晚，长线达 **16 晚穿越非洲大陆**。

## 二、三档套房

列车由修复的爱德华时代车厢组成，全部套房 **en-suite 独立卫浴 + 空调 + 迷你吧 + 保险箱 + 每日整理 + 24 小时客房服务**。

| 房型 | 面积 | 布局 | 卫浴 | 定位 |
|---|---|---|---|---|
| **Pullman Suite** | **±7㎡**（76 sq ft） | 日间沙发座，夜间转双床或双人床 | en-suite，含淋浴 | 入门豪华 |
| **Deluxe Suite** | **±10-11㎡**（118 sq ft） | 含**独立休息区**、大观景窗 | 全套卫浴带淋浴 | 中档 |
| **Royal Suite** | **±16㎡**（173 sq ft） | **占半节车厢**，含私人休息室 | **维多利亚浴缸 + 独立淋浴** | 顶级 |

> ⚠️ Deluxe 面积两个口径并存：官方 PDF 写 **±10㎡**，代理页写 **11㎡（118 sq ft）**。以官方 PDF 为准。
>
> **单一入住（Single Occupancy）统一加价 +50%**——单人出行明显更贵。

## 四、旗舰线路逐日行程

### 4.1 Pretoria → Victoria Falls（3晚/4天，最经典短线）

| 天 | 行程 |
|---|---|
| **D1** | **10:00** 从 Pretoria Rovos Rail Station 出发，穿越 Warmbaths、Nylstroom，跨越 **Tropic of Capricorn（南回归线）**；13:00 午餐、16:30 下午茶、19:30 晚餐，夜行至 Messina / Beitbridge 办理津巴布韦边境手续 |
| **D2** | 全天车上休憩，经 Rutenga、Somabhula 前往布拉瓦约（Matabeleland 首府）；在 **Mpopoma 车上过夜** |
| **D3** | 出发后经**世界最长直线铁路段之一（114km）**沿万基国家公园东缘行驶；抵达 Kennedy 站，转乘 4×4 敞篷车前往 **The Hide camp 游猎**（45,000+ 大象、狮、豹、非洲野狗、400+ 鸟种，含丛林 sundowner）；晚餐后至 Thompsons Junction 过夜 |
| **D4** | **07:00** 发车，**10:00 抵达维多利亚瀑布**，散团 |

**反向（VFA→Pretoria）**结构类似，D2 有 **05:00 早叫 + 晨间游猎**。

**4晚版（Pretoria→VFA）**额外增加：D2 前往 **The Ranch Conservancy**（1,000 公顷，游猎 + 午餐）；D4 **Matobo 国家公园**（萨恩岩画 + Cecil John Rhodes 之墓「世界之景」）。4 晚版 **18:00 出发**（3 晚版 10:00 出发）。

### 4.2 Cape Town ↔ Pretoria（3晚/4天）

| 天 | 行程 |
|---|---|
| **D1** | **10:00** Pretoria 出发，穿越 Witwatersrand 金矿带与 Highveld；19:30 正装晚餐 |
| **D2** | 抵金伯利，参观 **Diamond Mine Museum + Big Hole**（世界最大人工挖掘） |
| **D3** | 穿越 **Great Karoo** 半沙漠；午餐后可在 Whitehill Siding 下车，**步行 5km 进入马奇斯方丹**（1890 年维多利亚村，Lord Milner Hotel、老爷车博物馆）；随后穿 4 条隧道（最后一条 13.5km），下行 ±750m 至 Worcester |
| **D4** | 穿越 **Hex River 谷**（酒乡）；**15:00 抵开普敦** |

## 六、注意事项

### 6.1 着装（最易踩的坑）

| 场合 | 要求 |
|---|---|
| **白天** | 智能休闲：整齐长裤、衬衫、**适合游猎的舒适鞋** |
| **晚间** | **正装（formal）**：男士西装外套 + 领带；女士鸡尾酒裙或等同 |
| 全部晚餐 | 官方行程表逐日标注 `Dress: Formal` |

> 这是与 **Golden Eagle Danube Express（informal 休闲）**、部分欧洲豪华列车的**最大区别**。行李务必带正装。

### 6.2 儿童政策

- **0-2 岁：不得乘车**
- **3-9 岁：付成人价 75%**
- **10 岁以上：全价**
- **13 岁以下不建议乘长线**
- 车上**无托儿设施与儿童活动**

### 6.3 预订与付款

- 直接售卖：官方 rovos.com、central.res@africantravel.com、+27 (0)87 551 2837；或授权代理（Train Safaris、Palace Trains、Luxury Train Club）
- **可整列包车（private charter）**；events train 可租作日间活动（最多 250 人）
- 建议提前 **6-12 个月**，Royal Suite 与旺季（6-10 月）更早
- 单一入住（SO）**+50%**
- 拼程（短线 + 长线）享 **5% 折扣**

### 6.4 季节选择

| 目的 | 最佳时间 |
|---|---|
| **游猎（万基、克鲁格、Etosha）** | **4-10 月旱季**（动物集中水源、植被稀疏） |
| **冬季开放车游猎体验** | 6-8 月（凉爽、清晰） |
| **维多利亚瀑布最壮观** | **2-5 月**（赞比西河丰水期，水量最大） |
| Durban 线 / Golf Safari | 有季节性停运，查官方班期表 |

### 6.5 其他

- **边境与签证**：津巴布韦（Beitbridge）、赞比亚、坦桑尼亚、博茨瓦纳、安哥拉等需相应签证，务必提前办妥
- **护照**须交 Train Manager 或 Administration Deputy 保管（边境手续用）
- 行程**视铁路运力可能改经博茨瓦纳**（官方明确提示）
- 出发/抵达时间为近似值，官方声明**不保证**
- 车上**无广播无电视**，公共区域不建议用手机——刻意数字排毒
- 部分线路（Dar / Copper Trail）**才配随车医生**；短无医生

## 七、适合谁 / 不适合谁

| ✅ 适合 | ❌ 不适合 |
|---|---|
| 想用最舒适方式看南部非洲野生动物的人 | 不愿带正装/拒绝 dress code 的人 |
| 有 2 周 + 假期想「一次走透非洲」的人（Dar 线 16 晚） | 只想要 2-3 天短途打卡者（最短 2 晚，但精华在长线） |
| 情侣（Honeymoon 主题线）、结伴友（双床） | 带 0-2 岁婴幼儿的家庭（禁止乘车） |
| 摄影爱好者（车尾开放式观景车） | 需要车上娱乐设施者（无电视无广播无健身房） |
| 铁路/复古车厢爱好者（爱德华时代修复车厢） | 预算敏感者（短线 R50,000-124,000，长线 US$18,000-31,500） |
| 高尔夫爱好者（Golf Safari 5 座名场） | 追求现代极简风格者（装饰为维多利亚时代复古） |
